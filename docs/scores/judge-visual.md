# judge-visual 的独立打分表（视觉设计师）

> 独立性声明：本表在未阅读其他打分员文件（`docs/scores/` 下他人产出）的情况下完成；依据 `docs/brief.md` §5、三份 `docs/concepts/hybrid-{a,b,c}.md` 与三份评审意见（critic-fun / critic-feasibility / critic-player）。未改方案文件，全按桌面键鼠口径。

## 打分口径（视觉）

低多边形＋程序化材质里，“高级感”只有三个来源：构图、配色、发光与几何；后处理不进 MVP、阴影默认关、真 SpotLight ≤2，无体积光可借。我的三条标准：① 静帧能否 3 秒说清“少女乐队 × 幸存者”；② 状态是否长在几何与颜色上而非 HUD 上；③ 资产能否只用实例、顶点色、CanvasTexture 生成。七维都打，Polish 与 Theme 压得最重。

## 逐维依据（视觉口径）

1. Fun：A 的屏息—释放最干净；B 前四分钟画面不动；C 九十秒一次人浪，画面一直在长。
2. Theme：A 台上没有“少女”，只有规则和灯；B 机制最像乐队、画面最不像；C 的荧光棒与人浪一眼就是题材。
3. Originality：A 的“停”是品类反转，不是视觉反转；B 的“舞台即六弦琴”是独占符号；C 的“看即招灾”落在屏幕上仍是范围光效。
4. Depth：A 四次编曲，第三局退回固定答案；B 靠调弦、找回顺序、断弦位置；C 的八张卡一局拿完，构筑是假的。
5. Polish：A 路径最清单化（假光化、CSS 过曝、台唇几何），天花板也最低；B 有一帧最便宜最值钱，但构图风险最高；C 的网格＋荧光棒几乎零贴图出高级感。
6. Feasibility：A 音频能降到节拍器；B 有预渲染缓冲主路径；C 的血条视觉还没定型。
7. Scope：A 的 MVP 最小；B 范围最大但有“三弦一队友”底线；C 每件都便宜，收敛清楚。

## 排名与首选

- 排名：1) Hybrid C《谁在听》 2) Hybrid B《松手》 3) Hybrid A《暖场》
- 首选：Hybrid C《谁在听》
- 与第二名的差距是否显著？不显著。C 领先的 0.3 来自 Polish（9 比 7），0.2 来自 Theme（8 比 7），B 在 Originality 反超一分（0.2）。若 C 的 overdraw 与血条在 M5 第一周没定型、Polish 掉到 7，两案只差 0.5。C 的冠军应由“90 秒门＋一张不配字幕的截图”确认。

## 首选理由（150–250 字）

C 是三案里唯一“画面自己会把玩法讲出来”的一案。1008 个座位是一张现成的点阵构图：观众不是模型，是顶点色加实例——点亮、褪色、唱化、人浪都是同一批像素换颜色，不需要贴图与骨骼。序曲第 40 秒最后一排亮起一根荧光棒，是全项目最便宜的开场镜头；2:00 的人浪则是唯一能一帧说清“我在养一屋子人”的画面。更值钱的是它把可读性写成了美术规范：三色、一拍一事件、出现第四种高饱和色即 bug——这条纪律在七人团队里比任何概念都管用。它的死法同样视觉：光锥 overdraw 与“目光—危险条”会把画面糊成一团，这两项是 M5 的生死项。但赌这个，比赌 B 那把可能被读成木板的琴，更容易看到成品。

## 会主动再玩 3 局吗？

- Hybrid A：否。两局之内我会把 4:12 的过曝与白闪看爽；第三局还是同一座台、同一套灯、同一种白，变化只在时间轴上。
- Hybrid B：是，但前提是第一张图就成立。每局调弦不同，弦的形变与灰→彩的节奏都不同，我愿意为再拍一张“31 人半空变彩”开三局；但若三十秒内那把琴被读成木板，第二局我都不开。
- Hybrid C：是。座区分布每局不同，人浪形状就不同，我会为了养出更大的一片再来三局。但第三局之后若八张卡仍是一局拿完，我会停：画面在长，选择没长。

## 三案共同的视觉缺口

三案都没解决“四个人在屏幕上怎么被认出来”。1280×720 下人影高约四十像素，没有脸可用：A 的三名队友是炮台加规则，B 的是灰白人形，C 的是三根线。剪影系统（发型、乐器轮廓、站位）是 M4 必须补的一项。

## 给制作人的一句话

先定那一帧，再定 HUD：冠军案必须在 M4 锁死一张三秒内说清“少女乐队 × 幸存者”的截图（C 是光锥下的一片荧光棒，B 是 31 人半空变彩），所有光效与 UI 都为它让路；做不出这一帧，M5 的玩法与美术会互相拆台。
