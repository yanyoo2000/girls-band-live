# judge-musicfan 的独立打分表

> 独立性声明：本表在未阅读其他打分员文件的情况下完成，依据 `docs/brief.md` §5 的新 rubric、`docs/templates/judge-score.md`、`docs/concepts/hybrid-a|b|c.md` 与三份评审。我的视角是音游 / 乐队粉丝：先问“音乐与节拍有没有真的进入操作”，再问“成员有没有魅力、Livehouse 有没有气味、程序化音源能不能听”；不因为“有乐队”自动加分，也不以难度扣分。

## 我的三条判据

1. **音乐是不是动词**：玩家的操作是否改变和声、节奏或声部，而不只是给伤害加一个数字。
2. **台上是不是人**：角色能否被一句话记住；三案共同的弱点是“队友＝规则／线／弦”。
3. **声音能不能做出来**：零素材、WebAudio、单文件下，原创音乐与音效有没有可信且可降级的路。

## 分差从哪来（音乐视角）

- **A《暖场》**：节拍是裁判，不是乐器。16 步表把 BPM、8 小节乐句、鼓棒最高点做成真规则，音频可降级成节拍器，所以 Feasibility 9、Polish 8；但一局只选 4 次编曲、砸 3–5 次，其余时间在落拍推人潮，音乐不会因我而变调。鼓手＝秒表、贝斯＝护栏、吉他＝贼，乐队感最薄，Theme 6、Depth 5。
- **B《松手》**：舞台就是乐器，最有“我在弹”的幻觉，也是唯一让我想截图的单帧（31 人同帧松开、半空变彩），因此 Originality 9、Theme 8。但敌人无声、队友一根根找回，前四分钟像一个人的后摇；Karplus-Strong 有两条路却必须过音色门，Feasibility 7。它是我最想讲给别人听的一案，不是最想连打的一案。
- **C《谁在听》**：光＝注意力＝混音台，四区各唱根、三、五、七音，观众真的替你和声；2:00 的人浪把噪音唱成新观众，Theme 9、Polish 9。5 条总线、8–12 声部池让“千人合唱”不必采样，Feasibility 8。扣分在演奏感：玩家没有跟拍动作，若光不跟和声就退化成灯光秀，Fun 8 而非 9、Depth 6。

## 排名与首选

- 排名：1) C《谁在听》 2) B《松手》 3) A《暖场》
- 首选：**C《谁在听》**
- 与第二名差距：**0.5 分，不算显著**。C 胜在乐趣、主题、完成度三项的合力；B 用原创性和“最强单帧”紧咬，但前四分钟的音乐密度与“乐队＝一个人”的读法拖住了它。若 M4 只允许一个 60 秒 demo，我判断差距会放大。

## 首选理由（150–250 字）

我选 C，因为三案里只有它把“台下”做成了乐器：四区分别唱根、三、五、七音，光移到哪一区，哪一区的和声就亮，2:00 的人浪把噪音唱成新观众——这是唯一让我“听”出自己做了什么、而不只是看到的瞬间。它对乐队粉丝的甜点是“被看见”与“合唱”，不是贴一张乐队皮：人气即血、安可消耗观众、空场结局，都把“有没有人在听”写成了规则。音效上它有最便宜的可行路径（5 条总线、8–12 声部池），千人合唱不必采样。扣分项是演奏感仍弱：光与观众之间需要一条“跟拍才有效”的硬规则，否则会滑成灯光秀。

## 会主动再玩 3 局吗？

- **A**：是，但只到第三局。6:30 短、失败 30 秒重开，“再砸准一次”足够拉我回去；第三局后四次编曲开始重复，固定谱面把“演奏”变成背板。
- **B**：是，但会隔天玩。为了再听一次三十一个音同帧松开、再试一组调弦；每局 10–12 分钟且前段无鼓无队友，连续三局会累。
- **C**：是，会连玩三局。第一局学养人、第二局试人浪、第三局冲 800 人；9–12 分钟偏长，但“我养出来的场子”是唯一让我主动再开一局的循环。

## 给制作人的一句话

最容易被忽略、却会决定成败的一点：三案都容易把音乐做成“系统时钟＋氛围”，只有 C 让观众真正发出和声；若选 C，请把“光的移动必须跟拍或跟和声才有效”写进 M4 验收——否则少女乐队只是皮肤，玩家听到的仍是一段不会回应的伴奏。
