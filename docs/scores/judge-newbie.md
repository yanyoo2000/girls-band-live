## 我先立的七个锚（新手版）

| 维度 | 我问自己的问题（不是评审的问题） |
| --- | --- |
| 乐趣 Fun | 前 3 分钟我知不知道该干什么，并且做对过一次？ |
| 主题 Theme | 不看介绍，我能不能一眼看出这是少女乐队？ |
| 原创 Originality | 这个动作我在别的游戏里做过吗？ |
| 深度 Depth | 明天我还会再打开吗？ |

| 范围 Scope | 我会不会玩到一半发现后面没做完？ |

## 每个分数背后的一件事

- **A 6.7**：0:50 我按住空格，全场静音——三案里最快的一次"哇"，键位只有 WASD＋空格＋左键，6:30 一局最像"我能玩得完"。但 2:30 鼓手把鼓棒停在半空、前排"嘁"了一声，我不知道自己早了 0.1 秒还是 0.3 秒：判定圈没有标尺。名场面 4:12 也锁在"砸准"里，我记得的是羞耻，不是爽。Depth 5 是全表最低：同一首 6:30 的歌，第 2 局我就知道它什么时候来。
- **B 6.6**：Originality 9 是全表最高——"舞台是一把走音的六弦琴、走位就是弹奏、越玩越穷"，我没在任何游戏里做过。但前 2:40 没有鼓、没有第二个人、没有一句台词，我第一分钟以为音频坏了；俯视一把巨吉他在我眼里先是一块木板。我承认它最酷，也承认我会在 2:40 之前关掉它。Fun 5 不是不理解，是"我进不去"。
- **C 7.3**：鼠标本来就是我的东西，不用学键位；40 秒时最后一排亮起一根荧光棒，那不是提示，是邀请，我会自己把光移过去；0.4 秒"拉停"让我第一次做对就看得见，不考时机。它的坑也很新手——90 秒没有敌人我会问"就这样？"；而且 HUD 一边说"人气＝血量、不显示数字"，一边写"观众数从 187 跳到 307"（`hybrid-c.md:66` 与 `:91`），我根本不知道自己还剩多少命。

## 排名与首选

- 排名：1) Hybrid C《谁在听》 2) Hybrid A《暖场》 3) Hybrid B《松手》
- 首选：Hybrid C
- 与第二名差距显著吗？不显著（7.3 对 6.7）。C 的优势全押在"第一次打开"上；若 90 秒门实测失败（新手不主动移光），它会掉到 A 后面。B 只要把第一个高光从 2:40 提到 1:00，就可能直接反超 A。

## 首选理由（150–250 字）

我选 C。它是我唯一不用看教程就会操作的一案：鼠标在我手上，把光放到人身上，人就亮了、跟着唱，0.4 秒我就知道我做对了——新手要的就是"立刻算数"。A 的"按住—松手"我也懂，但它把最爽的一下押在 0.12 秒的判定上，而判定圈没有标尺；第一天我砸不准，就只记住那声"嘁"。B 要我先记四个动作，再接受"我会越玩越弱"，是双重门槛。C 还有别人没有的东西：失败是"空场，你一个人把剩下的段落弹完"，它不骂我。第一次玩就输的人愿意再开，靠的不是难度，是"它没让我难堪"。代价是一局 9–12 分钟，比 A 长一倍。

## 会主动再玩 3 局吗？

- Hybrid A：**否**。第 2 局我就知道 4:12 会来，也还是砸不准；同一首歌让我在同一个地方犯同一个错。再开的理由是它短（20 分钟能打三局），不是它变了。
- Hybrid B：**否**。第 2 局我会记得"2:40 才开始有趣"，前 150 秒变成忍耐；第 3 局我会去找跳过开场的办法。它值得记住的是那一帧，不是那三局。
- Hybrid C：**是，但会分两天打完**。我想知道我能不能把台下的座位坐满，而每局养出来的场子不一样。缺点是一局 9–12 分钟，三局半小时——对完全新手，这是"今晚只玩一局"的量。

## 给制作人的一句话

三案都花力气设计"输得好看"（冷场／弦尽／空场），却没有一案设计"输完 3 秒内告诉我刚才哪里错了"。新手不怕输，怕不知道为什么输——请把失败归因当 P0，别当结算页的一行小字。
