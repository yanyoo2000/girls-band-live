- **试玩员**：playtester-09-streamer（独立试玩，未读任何其他试玩报告，只读 `README.md` 的「给玩家」段）
- **对象**：线上版 <https://yanyoo2000.github.io/girls-band-live/>（v1.0.0，无 `?dev` 参数）
- **环境**：Chrome（DevTools MCP 独立上下文）× 1600×900 CSS / DPR 2；另做 1280×720 一档对照
- **时间**：2026-10-28，局内实际推进约 30 分钟（3 局 9:30 + 1 局短局），另含弹窗/等待

> 结论先给：**这是一部"氛围/叙事"很强、但"直播可用性"很弱的作品。**

## 一、首印象：从点「开始演出」到第一次能讲点什么，我用了 26 秒

| 时间 | 画面（截图） | 主播视角的第一反应 |
| --- | --- | --- |
| 启动 | 标题页「谁在听 / WHO'S LISTENING」+「点击开始」+「第一次点击会解锁声音」 | 气质对了。像 Livehouse 海报，能当直播缩略图（`01-boot-title.png`） |

| 0:00 进演出 | 黑场、观众席剪影、四个剪影乐手、顶栏五段落、底部一根**没有图例**的「目光—危险」条、屏幕中间一行 **10px 灰字**「Esc 暂停 · Tab 看构筑」 | 我的观众会问："这是加载画面吗？"（`03-show-start-dark.png`） |

**前 30 秒里，游戏没有告诉我：光在哪、我能改什么、怎样算赢、观众为什么该看。**

我作为读过 README 的人知道"光=目光=人气=血量"，但**画面上找不到这句话的任何一个视觉证据**。

## 二、局数与结果

| 局 | 打法（我的真实操作） | 结束 | 评级 | 关键数据 |
| --- | --- | --- | --- | --- |
| 1 | 直觉打法：**按住左键按节拍点亮**（按下就是束光）+ 大幅扫光 | 完成终曲 9:30 | **C**「只剩一盏灯」 | 峰值 90 / 终场 78 / 转化 115 / 烧死 424 / 转化率 21% / 离场 52 / 空位 690 / 四区 **63-8-0-7** |
| 2 | 第二局改策略：**全程不按左键**（只用散光扫）+ 选「引线/黑潮/第二排」 | 完成终曲 9:30 | **C**「只剩一盏灯」 | 峰值 120 / 终场 120 / 转化 116 / 烧死 718 / 转化率 14% / 离场 0 / 空位 648 / 四区 **98-8-7-7** |
| 3 | 再演一场（同构筑倾向），验证「安可/静默/终曲」 | 完成终曲 9:30 | **C** | 峰值 120 / 终场 120 / 转化 119 / 烧死 651 / 四区 98-8-7-7 |
| 4 | 短局流程验证：暂停面板、失焦、回照、720p、Tab | — | — | 见问题 4/5 |

**三个必须知道的实测事实**

1. **第一局 4:58 就「空场」**（`08-empty-house-toast-4m58.png`：全屏白雾 + 「空场。只剩你还在弹。」+「跳过剩余演奏」按钮）。
   但**它不是败北**：之后靠「第二排 +5 人/30 秒」把人数从 0 拉回 78，仍以 C 收尾。
2. **两局观众峰值 90 / 120，占 768 席的 12% / 16%**。游戏的最大数字卖点是「768 席」，我玩了两局半，
   **屏幕上永远是 80% 以上的空座**——这是"卖点与画面不一致"，直播时观众第一句就会问"人呢？"
3. **四区永远是 98-8-7-7 这种形状**。因为光一次只能照一个方向，我的鼠标一辈子待在左前方，
   **「合唱墙（四区各≥40）」在正常打法里不可达**——卡池里最像"大招"的那张，我拿了两局也没见过它生效。

## 三、3 个最好的点（也是我唯一愿意截图发出去的地方）

### 1. 结算页「散场之后」——这是全作最强的一屏，建议当宣发主视觉
`13-results-C-run1.png` / `12-results-C-run2.png`：
评级卡（C / 只剩一盏灯）+ 8 个真实数据（峰值/终场/转化/烧死/转化率/被覆盖/离场/空位）+ 第二排空位 + 安可 + 裂缝 + 时长
+ **四区人数条形图** + 四句后台台词（「许燎：吉他断了 0 次。她一句都没漏。」「邵砚：鼓敲断了 0 次；从头到尾她一次都没停。」）。
- 主播价值：**这是天然的下播图**，一句话就能讲完这局（"我今晚只点亮了 120 个人，评级 C"）。
- 叙事价值：后台台词把"角色"立起来了，这是全作唯一让我觉得"她们是四个人"的地方。

### 2. 卡牌的结构与"代价"写法，适合让弹幕投票
`05-core-cards.png`：核心/通用/支援分类 + 「进化钥匙」角标 + 效果/代价分行（代价用琥珀色）+ 顶部「第 1 / 10 次选择」。
- 主播价值：**「第 N/10 次选择」是天然的直播进度条**；三张卡正好对应三种观众投票口径（稳/贪/搞事）。
- 文案质量：`代价：黑观众不可被烧。`、`代价：错拍没有加成。` 这种写法干净、可念。

### 3. 主题真的落进了机制（不是贴皮）
光=目光=人气=血量；四区=四声部；养人即招灾；空场后还有「只剩你还在弹」的独奏结局。
- 主播价值：这是我能对着镜头讲 3 分钟设定的一句话卖点，**比很多吸血鬼幸存者 like 的"贴图换皮"高级**。
- 使用体验：`序曲 → 主歌 → 副歌 → 桥段 → 终曲` 的五段提示是清楚的，观众能跟着段落走。

## 四、5 个问题（severity / 复现 / 证据 / 期望）

### P1【high】前 30 秒没有"钩子"，第一个事件是"读 9 行字"
- **现象**：点「开始演出」后 26 秒内没有任何引导、没有目标、没有一次成功反馈；0:26 直接弹三选一。
  唯一提示是 10px / 1.57:1 的「Esc 暂停 · Tab 看构筑」，等于不存在。
- **复现**：线上版 → 开始演出 → 不做任何操作 → 录 0:00–0:30。实测第一次三选一在 **0:26**，第二次 **1:08**。
- **证据**：`03-show-start-dark.png`、`04-first-upgrade-at-26s.png`；HUD 提示实测 `font-size:10px`、对比度 1.57:1。
- **期望**：序曲 0–15 秒做一次**强制小教学**：「移动鼠标，把光撒到台下 → 前排站起来」，
  玩家只要成功一次（画面立刻有 3–5 个人举灯）再放开手；**第一次三选一推到 1:00 之后**，
  或干脆把"今晚走哪条路"的核心三选一**前移到主菜单**（点「开始演出」之前选），演出中不再开场就打断。

### P2【high】画面暗到不适合直播：观众区平均亮度 13/255，中位 10–12
- **测量**（PIL，取画面中部去掉 HUD 的 230–1230 行）：常规 gameplay 帧 **mean 12.5–13.9 / p50 10–12 / 只有 1.0–2.1% 的像素 > 80/255**；
  终曲 22.2，静默 13.2，空场白雾 41.4（就是那团白）。
- **复现**：任取一局中途截图统计即可（脚本见下）。1600×900 下前排观众/荧光棒只有 15–30px 的小色块，720p 直播再压一档就只剩黑。
- **证据**：`07-crowd-mid-show.png`、`14-720p-legibility.png`；统计命令（PowerShell，Python + Pillow）：
  ```python
  im = Image.open(shot).convert('L'); a = np.asarray(im)[230:1230, :]
  print(a.mean(), np.percentile(a, 50), (a > 80).mean() * 100)
  ```
- **期望**：整体曝光 +1.5～2 档；给"有人/无人"座椅做硬对比（哪怕是底部一排反光条）；
  设置里加一档 **「直播亮度」（比"高对比"更狠，牺牲氛围换可读）**；并给光斑加**可见的地面光池**。

### P3【high】核心因果在画面里不存在：束光烧人 / 散光养人 / 回照 都只能靠猜
- **现象**：
  - 第一局我按"音游直觉"**按住左键打节拍**（按下即束光），4:58 空场；
  - 第二局我**全程不按左键**，峰值翻到 120。**差别巨大，但画面没有任何"烧/养"的区别反馈**；
  - 「回照」没有按键、没有提示，我按 README 试"把光收到脚下"（指针移到舞台中心）后**画面上看不出进入了回照**（`26-recoil-test` 序列无可见护盾圈），HUD 也没有形态指示。
- **证据**：`08-empty-house-toast-4m58.png`（空场是全屏白雾，看起来像 bug 而不是"我失去了他们"）、`06-beam-and-sticks.png`（束光只有一个很淡的锥形，座位上没有亮区）。
- **期望**：① 束光命中观众 → **立刻**可见的"后退/发红/掉落"；散光 → "抬头/举灯"的增量动画；
  ② 回照给一个明确的**按键**（如右键）+ 脚下的护盾圈 + HUD 形态图标（散/束/回三态）；
  ③ 空场前 10 秒给一次"人气见底"的明确警报（数字或人数条），而不是最后全屏白雾。

### P4【medium-high】直播交互死角：失焦不暂停，暂停会被静默禁用
- **现象 A**：把焦点移走（`window` 派发 `blur`）后 6 秒内游戏照跑（实测 `t:476 → 482`）。
  主播切去读弹幕 / 看 OBS / 回一条超管消息，回来人已经散了。只有**整个标签页被隐藏**时音频才降到 12%。
- **现象 B**：**Esc 和 Tab 在某些时段完全不响应，也没有任何文字解释**——实测 t≈2:30 按 Esc 两次、t≈3:36 按 Tab，
  都打不开暂停面板；同期 HUD 上有「贝斯线断了」「安可未用」两个徽标（我怀疑与"可安可/低人气"窗口有关，未能确认触发条件）。
  对照：t≈1:07 时 Esc 正常打开「演播暂停 / 停在 1:07 · 序曲」面板。
- **证据**：`10-silence-boss.png` 中可看到「安可未用」徽标；暂停面板本身可用时是清晰的（`暂停面板 / 演播暂停 / 停在 1:07 · 序曲`）。
- **期望**：① 提供**「失焦自动暂停」开关**（默认开）；② 任何"暂停被禁用"的场景必须在画面上写一句
  「安可窗口内不能暂停，按 R 使用安可 / 等待 6 秒」；③ 音频在失焦时也降（现在只对 `visibilitychange` 生效）。

### P5【medium】局内没有任何可播报的仪表，结算却把数据全给了
- **现象**：局内 HUD 只有：五段落条、一根无图例的「目光—危险」条（`aria-label` 才写了"左：被光照亮的人。右：循光而来的噪音。"）、
  「核心/卡牌 chips」、「账」的一排点、以及「安可未用」徽标。**没有人数、没有血量、没有四区分布**。
  而结算页把四区人数画成了条形图（98-8-7-7 一眼就看懂）。
- **主播后果**：我无法对观众说"我们现在 120 人 / 已经烧了 700 只"；观众也没法跟着紧张。
  **每次只能靠结算才知道自己玩了什么。**
- **期望**：把结算的"四区人数"搬进局内做成**四根小柱**（非数字，符合美术方向）；
  人气做成"亮座比例"环或观众席整体亮度；让 `aria-live` 播报这些（现在只播报"升级选择/安可未用"）。

### 另见（不计入 Top5，但对直播有影响）
- **P6【low】三选一密度**：实测第 1/2/3/4/5/6/7 次分别在 **26s / 68s / 115s / 140s / 204s / 258s / 300s**（5 分钟 7 次），
  每次都暂停演出。两次 2:00「人浪」都被弹窗占用，**我没有看到过清晰的人浪画面**（不可截图）。
- **P7【low】没有可传播物料**：结算页没有「保存/复制成绩图」，没有种子展示、没有回放、没有一键隐藏 HUD。
  我作为主播要发成绩，只能整屏截图。
- **观察待确认（可能是我误读）**：局 2 结算点「再演一场」后，新一局在 1:07 的暂停面板里显示
  `停在 1:07 · 序曲 · 引线`，HUD 也沿用了上一局的 chips（`失真饲料 / 反向灯 / 越吵越亮`）；
  局 3 的数据（峰值 120、四区 98-8-7-7）与局 2 完全一致。但从局 3 结算再点「再演一场」时，HUD 显示「未定核心」。
  **建议按此路径复现确认**：结算页「再演一场」→ 新局 1 分钟内按 Esc 看构筑是否残留；若是 HUD 快照延迟，也建议修（主播会以为带构筑开场）。

## 五、最想优先改的 3 件事（按"对传播的影响"排序）

1. **把前 30 秒做成钩子**：15 秒内让玩家用鼠标把光撒到台下、看见 3 个人站起来（一次成功的因果闭环）；
   核心三选一前移到主菜单或推迟到 1:00；卡面压到「1 行效果 + 1 行代价」。
   → 直接解决"直播第一分钟没人看懂"。
2. **"看得见"**：整体曝光/对比 + 地面光池 + 烧 vs 养的差异反馈 + 回照按键与形态指示 + 空场前的明确警报（替代全屏白雾）。
   → 直接解决"720p 直播全黑、观众不知道发生了什么"。
3. **直播适配三件套**：失焦自动暂停（默认开）/ 暂停永不被静默禁用（禁用必须写原因）/ 局内非数字仪表（四区小柱 + 亮座比例）+ 结算「保存成绩图」。
   → 直接解决"主播没法边播边讲、下播没东西发"。

## 六、是否再玩 / 是否推荐

- **再玩**：愿意再玩 **1–2 局**，动机是我想验证「回照/独奏」和「合唱墙」能不能真的打出来（=你看，卖点需要玩家自己赌一把才可能看到）。
  但**不会连着播**：每局 9:30、前 5 分钟 7 次读卡、画面全黑，播 3 局观众会走。
- **推荐给观众**：
  - ✅ 推荐给 **氛围向 / 音乐向 / 独立游戏尝鲜** 的观众，卖点讲法："你只有一束光——照台下他们为你燃烧，噪音也循光而来。"
  - ⚠️ 不推荐给 **想看爽快战斗 / 想看数字成长** 的幸存者 like 观众（没有数字、观众峰值只有 1/6 座位）。
  - ❌ 不建议当 **主内容**（暗 + 无仪表 + 频繁暂停）；适合**切片**：结算页、空场独奏、终曲「放下光」。
- **适合的切片标题**（我能想到的传播点）：`我把 768 个座位唱空了` / `只剩你还在弹` / `今晚我只点亮了 120 个人`。
  —— 文案已经很强，**缺的是一屏能证明它的画面**。

## 八、限制声明（必须读）

1. **AI 无听觉**：不评价音乐/音效听感，所有"声音"相关结论均不涉及。
2. **输入为合成事件**：指针 `pointermove/pointerdown/pointerup` 与键盘事件由 CDP/JS 合成（真实监听在 `#root`/`window`，已验证生效），
   **不是真人手感**——不评价 0.15s 光惯性、节拍判定等手感项。
