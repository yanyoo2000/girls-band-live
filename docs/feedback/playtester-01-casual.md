# 试玩反馈 01：休闲桌面玩家

- 试玩员：playtester-01-casual（休闲桌面玩家画像：每周玩 1–3 次单机小游戏，不玩硬核 roguelike，习惯"先乱按 30 秒再看说明"）
- 版本：线上版 https://yanyoo2000.github.io/girls-band-live/ （v1.0.0，无 `?dev` 参数；仅诊断用的一个 `?dev=1` 标签页未参与评分）
- 日期：2026-10-28
- 视口：1600×895 CSS（2880×1800 物理，DPR 1.8），Chrome，Windows

## 测试方式与限制（先读）

- 我是无人值守的 AI 试玩员，**指针移动 / 左键 / WASD / E / Space / Esc / Tab 都由 Chrome DevTools 合成事件注入**，不是真人手部操作。因此「光有 0.15s 惯性跟手」这类**手感**无法评价，我只评价「能否看懂、能否做成」。
- 浏览器标签在后台时游戏会被节流（失焦冻结/降速），所以用 `Page.bringToFront` 把标签切到前台后按 1:1 跑。9:30 的整局是真实跑完的（约 9 分钟）。
- 全程 console 无报错；网络仅文档与静态资源请求。
- 未读任何其他试玩报告 / docs/qa/playtest* / docs/feedback/*，只读了 README 的「给玩家」段。

## 局数与时长

| 局 | 结果 | 时长 | 关键操作 |
| --- | --- | --- | --- |
| 1 | 空场（"只剩你还在弹"）→ 跳过 → 结算 C | 4:02 | 移动光、按住左键扫观众席、3 次三选一、结算、再演一场 |
| 2 | 空场 → 结算 C | 1:28 | 按住左键扫场、1 次三选一、结算、再演一场 |
| 3 | **完成终曲**，结算 C（峰值 74、转化 156、烧死噪音 653） | 9:30 | 散光扫场 + 短点燃、静默段、终曲长按 Space、结算 |
| 4 | 进行中按 Esc 暂停（用于验证暂停/构筑/Tab） | 2:17 暂停 | Esc、Tab、WASD、暂停面板 |

合计实际游玩约 30 分钟（含菜单、选卡、结算页停留）。

## 首印象

1. 启动页极简、暗场、标题排版很好，一句「你只有一束光」很抓人，**3 秒内知道这是"乐队 × 灯光"的游戏**。
2. 主菜单右侧四名队友剪影卡片 + 左下"散场之后 · 最佳"记录，气质统一，像一款有作者的独立游戏，不像 AI 拼的 demo。
3. 点「开始演出」后第一反应是**"我怎么这么黑？"**：舞台和乐队看得见，观众席像一片黑色阶梯，找不到自己的光、也不知道该照哪。第一分钟基本在"瞎扫"。

## 三个最好的点

1. **结算页「散场之后」是全场最高光**：评级卡（C·只剩一盏灯）、真实数据（峰值/终场/转化/烧死/被覆盖/离场/裂缝/时长）、四区人数条形图、"今晚有 156 个人第一次站起来；第二排还空着 53 个位置"的后台角色一句话。它把一局的数字翻译成了情绪，我愿意截图分享，也愿意为了"再来一次让数字变好"重开。
2. **升级三选一的结构与美术**：效果 + 代价 + 「进化钥匙」标签 + 1/2/3 数字键 + "不能重抽"，卡面信息分层清楚，有仪式感；`Esc 不会跳过这一次选择` 这种防误触说明很贴心。
3. **主题真的落地了**：四区=四声部（根/三/五/七）、光=目光=人气、养人招灾、裂缝、人浪、终曲"放下光"——不是把吸血鬼幸存者换个皮，而是"注意力地图"这个点子贯穿到了卡池、结算文案和后台台词里。

## 问题清单（按严重度）

### P1 `high` 新手按直觉玩 1.5–4 分钟就会「空场」，且画面不告诉玩家为什么

- 复现：线上版 → 开始演出 → 按住鼠标左键在观众席扫动（这是我在"照向台下"时的第一直觉）→ 约 1.5–4 分钟出现「空场，只剩你还在弹。」，只能点「跳过剩余演奏」。
- 期望：① 序曲 30 秒内用强提示教会"不按键=照亮养人 / 按住=束光烧噪音"；② 束光第一次覆盖到观众时，观众/光斑给出"他们不是噪音"的即时反应（颜色/抖动/一句提示）；③ 人气快速下降时给可视化预警，而不是等观众全没了才提示。

### P2 `high` 光的位置在画面上几乎不可辨（尤其散光）

- 复现：开始演出 → 把鼠标移到观众席任意位置 → 画面没有可见光斑/照亮圈（底部只有一个白色小点），无法判断"我现在照的是哪一区、照到了谁"；只有无障碍文本（如"前左区，热度合唱"）能说明状态。
- 期望：散光也应有清晰的照亮区域（弱一点的光斑/轮廓/被照亮座位的明暗差），束光和回照形态在画面上明确可辨（光柱/颜色/半径变化），让玩家"看画面就能玩"。

### P3 `high` 「散光养人 vs 束光烧人」的互斥关系没有任何教学，且与直觉相反

- 复现：① 按住左键扫观众席 → 人气快速下降直至空场；② 松开左键只移动鼠标扫同一片观众席 → 四区热度文本从"热度灭"升到"热度抬头/热度合唱"。两局空场都是"按着左键玩"造成的。
- 期望：把这条核心规则做成序曲的强制小教学（或第一张卡的说明里明确写"散光唱化、束光烧穿"），并在 HUD 上区分两种形态（当前形态名称/颜色）。

### P4 `medium` 四区状态只存在于无障碍文本，画面上只有角落小色块

- 复现：演出中看四角"前左/前右/后左/后右"标记 → 只有颜色；"有人在等你 / 被噪音覆盖 / 过热点 / 热度合唱"这些关键状态只在读屏文本里。休闲玩家不会开读屏，等于**不知道哪一区还有人来、哪一区被噪音占了**。
- 期望：把这些状态做成画面语言（等待=空座微光/荧光棒、覆盖=暗块、过热=红边/闪烁），或在角标上加可视化热度环（不显示具体数字也符合"只能读画面"的设计）。

### P5 `medium` HUD 提示「Tab 看构筑」与实际行为不一致

- 复现：演出中按 Tab → 没有构筑面板；暂停面板打开时按 Tab → 焦点在"继续演出/重新开始/设置/回主菜单"之间移动（这是 README 已知限制 10 的现象，我独立复现）。
- 期望：Tab 真正打开/关闭构筑查看，或删掉这条提示（现在它让我在演出中按 Tab，结果焦点跑到了看不见的地方）。

### P6 `medium` 空场后「暂停（Esc）」被禁用，Esc 按了没反应

- 复现：空场状态（「空场，只剩你还在弹」）→ 按 Esc → 无暂停面板；右上暂停按钮为 disabled；唯一出路是「跳过剩余演奏」→ 结算。
- 期望：空场态也允许 Esc 暂停/回主菜单/重新开始，别让玩家在"已经输了"的状态里只有一条被动的路。

### P7 `low` 静默段右侧出现 5 个无说明图标（链接/静音/插头/电源/刷新），插线（E）没有教学

- 复现：6:30 静默段 → 右侧出现一列图标（红/黄色）；HUD 文本才写"贝斯线断了/鼓线断了"；按 E 无可见反馈，结算页才知道"贝斯断了 1 次"。
- 期望：首次断线给图文提示"靠近队友按 E 插线"，并让图标有 tooltip/文字（不用鼠标也能读）。

### P8 `low` 失败/空场结算的语气过于中性，玩家不确定"我输了吗"

- 复现：空场结算标题写「再亮一会儿 · 空场完成」，正文「今天，只有你听见了。」，评级 C「只剩一盏灯」。
- 期望：保留诗意副标题的同时，给一句明确的结论（如"这一场没留住人"），并提示"下次试试散光扫场/别按住左键"。

### P9 `low` 关键术语密度偏高（对休闲玩家）

- 复现：升级卡里出现"完美窗口 +40ms（80ms → 120ms）""单区热度上限 3 → 4""合唱波伤害 ×1.5""转化 / 被覆盖 / 离场为累计人次"。
- 期望：首次出现时附一句白话解释（如"完美窗口=踩在拍点上的那一瞬"），或提供"简化卡面"开关。

### P10 `low` 画面整体偏暗，观众席几乎全黑（可能受显示器/环境光影响）

- 复现：启动后不操作，观众席区域（画面上半）几乎纯黑，只能靠彩色荧光棒辨认"有人"。
- 期望：提高基础环境光/增加"亮度"设置项（现有设置只有音量/画质/减少动态/高对比等，我没找到亮度）。

## 最想优先改的 3 件事

1. **让"光"看得见**：光斑/照亮区域/三形态在画面上可辨，让玩家不用读屏文本就知道自己在照哪、照到了谁（对应 P2、P4）。
2. **序曲教学 + 束光误伤反馈**：把"散光养人、束光烧人"变成 30 秒内必学的规则，并给即时反馈，阻止新手 1–4 分钟空场（对应 P1、P3）。
3. **提示一致性**：Tab 要么真能看构筑要么别提示；空场态允许 Esc；断线图标给文字与 E 的提示（对应 P5、P6、P7）。

## 评分（1–10）

| 维度 | 分数 | 理由 |
| --- | --- | --- |
| fun / 想继续玩 | **5** | 卡池、结算、终曲都有记忆点；但前两局"莫名其妙空场"的挫败感太重，第三局学会散光后才开始有意思 |
| theme / 主题表达 | **8** | Livehouse、四声部、光=目光=人气、后台台词，完成度高且不换皮 |
| clarity / 可理解性 | **3** | 开局不知道做什么、光不可见、散光/束光无教学、四区状态只在读屏文本、Tab 提示不对 |
| performance / 稳定性 | **8** | 启动快、帧率稳、无 console 错误；大窗口下无异常（后台标签被节流属浏览器行为，前台正常） |

## 是否再玩 / 是否推荐

- **愿意再玩 1–2 局**：想试「回照/独奏」和「引线/招灾」两条完全不同的核心，也想验证"散光扫场能不能把人数养到 200+"。但**不会连续玩很多局**，除非把教学和光的可见性修好。
- **推荐给**：喜欢音乐/氛围、愿意读卡面的朋友；会加一句"别按住左键，那是烧人不是看人"。
- **暂不推荐给**：纯休闲、只想乱按两下的人——他们大概率会在第 2 分钟空场然后关掉。
