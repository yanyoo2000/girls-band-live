# 试玩反馈 06：完全新手

- 试玩员：playtester-06-newbie（独立试玩，完全新手视角）
- 对象：公开线上版 <https://yanyoo2000.github.io/girls-band-live/>（未加 `?dev`）
- 环境：Windows / Edge（Chrome DevTools MCP 连接），视口 1440×900 CSS，DPR 2；系统 `prefers-reduced-motion: reduce` 生效
- 独立性：只读了 `README.md` 的「给玩家」段，未读 `docs/qa/playtest*`、`docs/feedback/*`、GDD、源码或其他试玩报告
- 输入说明：见文末「限制与未验证」。前两局的合成 `pointermove` 没有真正移动光，第三局用受信任的 hover 验证了「光可移动」；因此本报告**不评价手感与数值平衡**，重点评价新手可读性、失败归因与前三分钟
- 规模：3 局（2:58 结算 / 9:30 完整局 / 1:45 结算），游戏内约 14 分钟，真实会话约 40 分钟；截图 12 张

---

## 一句话结论

**气质和主题是真好，但我这个新手在三局里都没搞懂「光在哪、人为什么走、我为什么输」；三次都空场，第三次只用了 75 秒。** 我愿意再试，但不会推荐给完全新手直接开演。

## 一、首印象（真实时间线）

### 0:00 启动页

黑底、巨大的「谁在听」、一句「你只有一束光。照向台下，他们为你燃烧，噪音也循光而来。」只有一个「点击开始」。
第一印象：**像一张演出海报，不像游戏**。气质很对，但我不知道要按什么、玩什么。提示「第一次点击会解锁声音」有帮助。

### 0:02 主菜单

点完「点击开始」还有第二层菜单，需要再点「开始演出」才进游戏。菜单里有：开始演出 / 今晚的曲目单 / 排练室 / 设置 / 制作名单；右侧是四位成员和「散场之后 · 最佳」记录。
第一印象：**像 Livehouse 后台，舒服**。但「开始演出」按钮上没有「第一次先看排练室」之类的提示，我差点直接开演。

> 我因为好奇点进了「排练室」，才发现有 3 页教程。**教程写得很好**：WASD、鼠标移光、按住左键束光、松开散光、点击点燃、返听、静默、终曲长按 Space 都讲了。但它是可选的，且默认路径不经过它。

### 0:20–0:30 第一次进场地

开场画面：很暗的场馆，768 个座位几乎全黑；台上有主唱和三位队友；前几排能看到少量白色/粉色人影。HUD 只有：段落条、目光/危险条、四角「前左/前右/后左/后右」、核心卡槽、一行很小的「Esc 暂停 · Tab 看构筑」。

- 我不知道我的「光」在哪。屏幕上没有光斑、没有光锥、没有准星和观众席的连接。
- 我不知道「人气」是多少（设计上说 HUD 不显示数字，我理解；但至少要有可读的形状）。
- 约 0:20 第一张「三选一」就弹出来了：**我还没走一步、没点一次鼠标，就先做构筑选择**。

### 0:30–2:08 第一局（直觉流）

我按新手直觉：**按住左键，把光压在观众席上**（我当时以为「照着他们」就是养人）。
- 画面几乎没有变化。只看到白色边缘慢慢泛起来，像过曝滤镜。
- 0:30 左右无障碍文本里出现「返听锁定了你的光。移光，或者烧掉它。」，但**画面上没有这句提示**，右侧只多了一个像刷新箭头的圆形图标，我不认识。
- 后排右侧有一根绿色荧光棒/绿色光点从开场就在，没有文字解释，我也不知道那是什么。
- 2:08 突然出现「空场。只剩你还在弹。」，暂停按钮变灰，只能「跳过剩余演奏」。
- 结算：C「只剩一盏灯」，峰值 49，转化 29，烧死噪音 1，离场 50，空位 768，裂缝 1。

**我的真实反应：我做错了什么？** 我烧死的噪音只有 1，说明我的束光基本没打到噪音；但 50 个人走了。是不是我按住左键把人烧没了？游戏没有在局内告诉我，也没有在结算告诉我。

### 第二局（照排练室打）

我按教程做：不按左键，只移光（尽量让光扫过四区），卡牌选「合唱墙 / 留人 / 第二排 / 走位 / 第一排 / 擦弦 / 节拍点燃 / 换气 / 灯下合唱 / 安可保险」。
- 前 3 分钟总共来了 **7 张**三选一（0:26、0:39、1:18、1:46、2:16、2:39、3:08），到 4:56 已经第 10 张。**我更像在玩卡牌弹窗，而不是在演出。**
- 2:16 起，吉他/贝斯/鼓线相继断了，右侧出现三个「插头」图标；没有文字告诉我「靠近队友按 E」。我一直没修。
- 4:56 第一次出现「人气告急」，弹出「安可 / 继续独奏」——这是全游戏**最清楚、最有戏剧性**的一屏，我秒懂了。选了安可。
- 8:14 终于看到观众席上出现成片的彩色人影（青/白/橙），第一次觉得「我养出人了」；但 HUD 仍然没有任何人数或四区读数。
- 终曲提示「长按 Space 放下光」，我用合成 Space 长按，底部的圆环没有可见填充（可能是输入限制）；最后仍然「空场完成」。
- 结算：峰值 90、终场 0、转化 305、烧死 589、被覆盖 281、离场 365、空位 768、裂缝 3、时长 9:30。

**第二局的困惑比第一局更大**：我转化了 305 人次，还是 0 人收场；「被覆盖 281」是什么意思？为什么安可之后还是空场？结算只说「今晚有 305 个人第一次站起来」，没有告诉我「你是怎么失去他们的」。

### 第三局（输入验证，1:15 空场）

用受信任的 hover 把光移到「后右区」，屏幕阅读器文本显示该区从「热度灭」升到「热度合唱」；再把光移到前左区（中途弹出一张卡，选完后继续），全场「热度灭」，1:15 直接空场。峰值 30、转化 11、离场 30、烧死 0。
这一局让我确认了两件事：**光确实能移动、能加热**；**但加热/离开的因果关系在画面上完全不可见**。

## 二、前三分钟判定：不知道要做什么

- **0:20**：第一张三选一出现前，我不知道鼠标要动、要往哪里动；我甚至不确定画面中心的亮点是不是我的光。
- **0:30**：返听锁定只在无障碍文本里提示，画面上是一个像刷新箭头的圆环；我不知道要移光或烧掉。
- **前 90 秒**：后排右侧一直有一根绿色荧光棒/绿色光点，没有文字，我不知道那是钩子/目标。
- **2:08**：直接「空场」，此前没有任何「你正在输」的预警；结算也没有败因。
- 我唯一做对的事（进排练室看教程）是运气：默认「开始演出」不会经过它。

所以对「前 3 分钟是否知道该做什么」，我的答案是：**不知道**。我知道自己在看一场很酷的演出，但不知道自己在玩什么。

## 四、评分（1–10）

- **fun 5**：氛围很强，安可那一刻我确实被抓住了；但三局都以「不知道发生了什么」收场，重开的动力主要是好奇而不是爽。
- **theme 8**：Livehouse、四个声部、光=目光=人气、养人招灾、后台台词，主题是真的长在机制上，不是贴皮。
- **clarity 3**：教程藏在可选菜单；局内光/热度/人数/危险几乎不可读；失败没有归因；卡牌术语密度高；结算页反而是全游戏最清楚的。
- **performance 6**：我在 1440×900@DPR2、同浏览器还开着 10+ 个本作标签页的情况下采样到 32fps，截图超时一次；console 只有 favicon 404，无运行时报错，加载很快。**这不是公平的跑分环境**，分数保留。

补充：界面**不吓人**，是「太黑 + 不给反馈」造成的困惑，不是恐怖或压迫。安可弹窗反而让我觉得被尊重。

## 五、最好的 3 点

1. **「散场之后」结算页**：C 评级卡「只剩一盏灯」、真实数据、四区条形、后台四个人的台词。尤其「今晚有 305 个人第一次站起来；第二排还空着 64 个位置。」——这是我三局里唯一被击中的一句话。它让我想再演一场。
2. **安可 / 人气告急**：4:56 弹出「安可会把人气拉回峰值的一部分……继续独奏则进入空场」。不用查攻略就懂，有戏剧性，冻结游戏的选择也让决定有重量。
3. **排练室 3 页文案**：每页只讲一件事，句子短、有画面（灰→彩→黑、返听会咬住你的习惯、静默段节拍环还在）。如果它默认出现，我的第一局不会那么茫然。

## 六、问题（severity / 复现 / 期望）

### P1（high）「光」和「人」在画面上不可见

- **复现**：任意一局，开演后 10–20 秒观察观众席；再按住左键 5 秒。除了 HUD 和屏幕边缘的白光，看不到光斑、光锥、被照亮的座位；第三局 a11y 文本已显示「后右区，热度合唱」，画面仍没有对应的高亮。
- **影响**：新手无法建立「我的鼠标 → 光 → 人」的因果，也不知道自己此刻在养人还是在烧人。第一局我按住左键很久（体感），以为在养人。
- **期望**：至少做到三选一——①观众席上可见的光池/光锥；②四区各有 3–4 格热度条，随光移动亮灭；③被照亮的人有明确的描边/颜色变化。白光边缘要与「有人正在离开」直接绑定，而不是像滤镜。

### P1（high）输了不知道为什么：三局空场，零归因

- **复现**：三局结束都只看到「空场。只剩你还在弹。」和结算数字；没有一句「因为什么」。第一局烧死噪音 1、离场 50；第二局转化 305、被覆盖 281、离场 365；第三局移光一次就 30 人全走。
- **影响**：我不知道该改什么。是束光烧人？是光离开热区？是返听？是线路断了？是「合唱墙」的 +15% 自然衰减？结算的「被覆盖/离场/空位」也没有解释。新手会把失败归因于「游戏乱杀人」然后关掉。
- **期望**：局内出现「前右区过热，人正在走」这类近失警告；结算加一行**败因**（例：「你把束光停在前右区 42 秒，该区过热 → 离场 38 人」）；首次出现「被覆盖」「离场」时给一句人话解释。

### P1（high）前 3 分钟被「三选一」淹没

- **复现**：第二局 0:26 / 0:39 / 1:18 / 1:46 / 2:16 / 2:39 / 3:08 共 7 张，4:56 第 10 张；第三局 1:15 内已 2 张。每张 3 个选项、每个 2–4 行，出现「进化钥匙」「四区人数差 <15%」「完美窗口 80ms→120ms」「热度上限 3→4」等术语，而局内没有任何数字/热度可对照。
- **影响**：我还没建立「光—人」因果就先做 10 次构筑决策；「合唱墙（四区各 ≥40 人）」这种核心我根本无法判断离它有多远。到第 5 张开始，我的选择变成「看哪个字少选哪个」。
- **期望**：第一张延后到首次转化后或 0:60；前 3 分钟最多 2 张；前期卡面一行说清「做什么」，术语进「详情/暂停」；卡面显示与当前局面对应的进度（如「四区当前约 0/0/0/0 人」或图形化）。

### P2（medium）教程藏在「排练室」，默认路径直接开演

- **复现**：主菜单点「开始演出」→ 0:20 直接弹第一张卡；「排练室」需要主动点进去，且没有「第一次必看/推荐」标记。教程也没讲 **E 插线** 和 **回照怎么触发**。
- **影响**：大多数新手不会点「排练室」；第二局 2:16 起陆续断线，到 4:12 三线全断，我只看到三个插头图标，不知道按 E，也不知道断线会怎样。回照是核心三形态之一，但局内没有任何入口提示。
- **期望**：首次启动默认进排练室（或序曲前 20 秒内嵌 3 句提示）；「开始演出」按钮加「第一次？先看 30 秒排练室」；第一次断线时弹「靠近队友按 E」并把插头图标变成文字；补一句回照的触发方式。

### P2（medium）HUD 提示与实际行为不一致，图标猜谜

- **复现**：
  - 顶部一直写「Esc 暂停 · Tab 看构筑」，字很小；空场后暂停按钮直接变灰，这行提示仍在；
  - 右侧断线/返听只有三个无标签插头和一个像刷新箭头的圆环；终曲「长按 Space」的圆环没有可见填充（可能是我的输入限制）；
  - 我不知道「返听锁定」发生时画面有没有提示：无障碍文本里有「返听锁定了你的光。移光，或者烧掉它。」，但画面上只多了一个圆环图标。
- **影响**：我会反复按 Esc 确认是不是坏了；也会把断线图标当成设置按钮。提示不一致比没有提示更伤信任。
- **期望**：首次出现时给文字标签（「线路断了：靠近按 E」「返听锁定：移光或烧掉」）；空场态把 Esc 换成「回主菜单/跳过」；长按类交互给出 0–100% 的明确进度。

（另有一条低优先级：连续三局 C，结算只说「下一次，换一条构筑试试」，没有说明 C 代表什么水平；新手很容易把 C 当成「我玩得很差」。建议在评级卡下加一句「C = 常规一晚；更高评级要把人养到四区都能合唱」。）

## 七、最想优先改的 3 件事

1. **让人看见光、看见人、看见输**：观众席光池/光锥 + 四区热度条 + 可见的人数密度/白色边缘=离场，三者至少落地两个；这是所有其他问题的前提。
2. **把序曲变成真正的 20–30 秒教学**：默认进排练室或局内三句话；第一次断线教 E；第一次返听教移光；第一次白光说「你正在失去他们」；之后再放卡。
3. **降低前 3 分钟的认知负荷**：第一张卡延后到 0:60 后，前 3 分钟最多 2 张，卡面一行说人话；同时修掉「Tab 看构筑 / 空场 Esc / 暂停面板还没有卡」这三处提示不一致，并给结算加一句败因。

## 八、是否再玩 / 是否推荐

- **是否再玩**：愿意再试 1–2 局。我想验证「回照/引线」和「终曲放下光」，也想知道 305 人那局到底输在哪。但这是**好奇**，不是「爽到想再来」。
- **是否推荐**：不推荐给完全新手/休闲乱按型玩家（大概率第 1–3 分钟空场删游戏）。会推荐给喜欢氛围、实验性机制、愿意先读 3 页排练室并忍受「看不懂」的玩家，并附一句「光很暗，先看排练室」。

## 九、限制与未验证

1. **AI 无听觉**：没有评价音乐、合唱、静默段听感，也没有开声音验收。
2. **指针输入限制（重要）**：Chrome DevTools MCP 没有原始 `mousemove`；我合成的 `PointerEvent` 能让前右区进入「过热点」、也能触发束光，但**没有真正移动光的位置**。第三局我用注入的 6 个 6px 透明 hover 目标验证了「受信任的移光可以让后右区升到热度合唱」，但只做了两次离散移动。**因此前两局的「扫光养人」实际更接近「光停在原地」**，三局空场不能当作数值平衡的证据；手感/惯性/跟手性未评价。
3. **动画被系统降低**：浏览器 `prefers-reduced-motion: reduce` 生效，`--gbl-duration-*` 全为 0s，白光脉动、卡牌动效可能与正常玩家不同。
4. **性能非公平跑分**：同浏览器开着 10+ 个本作标签页，1440×900@DPR2 下空场采样 32fps，截图超时一次；不能代表干净环境。
5. **未验证**：回照/引线的实际效果、静默段、终曲「放下光」成功分支、再演一场的构筑继承、高对比/低画质设置。终曲长按我只看到圆环没有明显填充，最后仍是空场完成，不能判断是输入限制还是交互问题。
6. 没有改代码、没有 git 操作、没有安装依赖；只写了本文件与截图目录。
