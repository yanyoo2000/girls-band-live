# 试玩反馈 10：游戏评论人

- **对象**：线上版 https://yanyoo2000.github.io/girls-band-live/ （v1.0.0，无 `?dev`）
- **视口**：1440×900 CSS / DPR 2（canvas 2160×1350）；rAF 实测 145fps
- **只读**：README.md 的「给玩家」段（第 17–101 行）；未读任何其他试玩报告、未读 `docs/qa/playtest*`、未读 `docs/feedback/*`（保持独立）
- **局数**：3 局完整（2 局空场完成 + 1 局完成终曲）+ 2 次流程验证局（暂停面板 / 三选一卡面取证）
- **真实游玩**：约 74 分钟（11:34–12:48）；游戏内时间合计约 21 分钟
- **截图**：`docs/feedback/shots/playtester-10-critic/`（10 张）
- **限制**：AI 无人值守；**无听觉**，音乐/音效听感不在本报告范围；指针与键盘为 DevTools 合成事件 + CDP 真实按键混用；手感（0.15s 惯性）与节奏判定未做真人验收。所有「不可见 / 无反应」结论都附了复现与证据，但请把「E 插线无反应」视为「输入限制或实现问题」两种可能并存。

## 二、首印象

1. **主菜单很「像样」**：标题、副题、四名成员卡（主唱·光 / 主音吉他·高频 / 贝斯·低频护盾 / 鼓·节拍）先建立乐队身份，再给「开始演出 / 今晚的曲目单 / 排练室 / 设置 / 制作名单」。有 Livehouse 的暗调气质，不是套壳。
2. **一进游戏 5 秒内弹「第 1 / 10 次选择」**：我还没看过场景、没动过、没听过音乐，就被要求做**不可撤回**的核心选择（合唱墙 / 引线 / 回照）。三张卡各 4–5 行小字 + 代价行，第一次读不完。这是首印象里最伤的一刀：**我在理解游戏之前就开始构筑了**。
3. **画面极暗，且「光」几乎看不见**：观众席是一大片黑座椅，只有被光覆盖时冒出淡白色锥体；按住左键束光，前后画面差异极小。作为玩家，我第一分钟的真实想法是「我该看哪儿？我看到了吗？」
4. **教程藏在第二项**：主菜单「排练室」三页（走位与光 / 烧与唱化 / 危险与返听）写得非常好——一句话一条规则、有示意图、还诚实地说「不想看可以跳过：这些规则在暂停面板里也能查到」。但**默认入口不在开局前**：直接点「开始演出」的玩家完全看不到这三页。

## 三、3 个最好的地方

1. **「散场之后」结算页——全游戏最有说服力的一屏。**
   评级卡（C「只剩一盏灯」）+ 真实数据（峰值 / 终场 / 转化 / 烧死 / 转化烧死比 / 被覆盖 / 离场 / 空位 / 第二排空位 / 安可 / 裂缝 / 时长）+ 四区人数条形 + 后台四句角色台词（「今晚有 92 个人第一次站起来；第二排还空着 64 个位置。」）。
   局 1 的 92 转化 vs 314 烧死 vs 768 空位，一眼就告诉我「你以为在养人，其实一直在烧人」。把失败翻译成叙事，并直接给出下一局的方向——这是评论人会给「保留」的东西。

2. **主题真正落进了机制，不是换皮。**
   「你只有一束光，决定看哪里」→ 光=注意力=人气=血量=弹药；四区=根/三/五/七四声部；养人招灾（人浪让天花板裂缝更多）；白光=「你正在失去他们」的读数；空场结局是「只剩你还在弹」。这些概念咬合得很紧，属于原创设计，而不是把《吸血鬼幸存者》的数值换个皮肤。

3. **文案与美术口径统一，且克制。**
   纸质曲目单（演出前是空白的，「这张纸只写上一场发生的事。它不会替你选歌。」）、暂停「先喘一口气」、离开确认「放下今晚？这一场不会写进记录。灯光会重新亮起，但人不会记得。」、结算「今天，只有你听见了。」——这些句子让「乐队」而不是「打怪」成立。设置页也把每项写清楚（「减少动态：关屏震、光锥脉动、人浪起伏减半」）。

## 四、5 个问题（severity / 复现 / 期望）

### P0-1 局内看不见「光」，也看不见「被照亮/被转化」的人

- **severity**：high（核心机制的因果反馈断裂）
- **复现**：
  1. 开局不按任何键，直接截图（`07-act1-front-left.png`）：光斑几乎不可辨。
  2. 按住左键 1.2 秒束光，前后画面差异极小；松手回散光也没有可见边界。
  3. 把光停在观众席（`05-empty-house.png` 之前）：只有极少数观众从黑色变成很淡的白锥，**没有出现「彩」**——排练室第 2 页承诺「灰 → 彩 → 黑。全场只有三种颜色」，实机只看到「灰 → 微白 → 黑」。
  4. 局 1 我按住左键扫过观众席，随后观众席整片变空——我不知道是我烧死了他们，还是他们自然离场了；结算才告诉我「烧死噪音 314 / 离场 99」。
- **期望**：光要有明确的「落地」表现（边界/亮度/形状，至少让人一眼看出照到了哪一排）；被转化的观众要有可区分的「彩」（与四声部对应）；未转化/已转化/离场三态必须在画面上可分辨。

### P0-2 人气（=血量）完全不可读，空场没有预警

- **severity**：high
- **复现**：三局都经历「突然空场」：局 1 6:06、局 2 3:39。局内 HUD 只有「目光」「危险」两条无刻度、无数字、无阈值的条；画面里观众的增减与条的变化对不上。局 1 峰值 58、局 3 峰值 140，但我在局内完全不知道自己在涨还是在掉。
- **期望**：至少一个「非数字」的人气仪表盘（例如舞台前观众密度、四区计数条、或条上的阈值刻度），并在接近空场时给明确预警（不只是白光滤镜）。「不显示数字」可以保留，但「读不到状态」不行。

### P0-3 三条构筑的核心操作/收益，局内不可见或不可执行

- **severity**：high
- **复现**：
  1. **引线**（局 2 核心）：卡面「指定一区作诱饵」，但局内**没有任何「指定」的入口或提示**（我没找到按键、点击区标签、或 HUD 提示）。我带着引线 + 黑潮 + 越吵越亮三张招灾卡打完整局，从未成功指定过诱饵；空场 3:39 比第一局还早。
  2. **回照**（局 3 核心）：卡面「把光收回脚下 = 独奏：3m 护盾圈 60 点……」；我把光移到主唱脚下并按住左键 2.5 秒，画面**没有护盾圈、没有护盾值、没有「独奏中」文字**，无法确认是否生效。
  3. **合唱墙**（局 1 核心）：条件「四区各 ≥40 人」，但局内没有四区人数读数；三局下来四区人数最好也只有 118/8/7/7，核心条件整局不可达（也谈不上是否达成）。
- **期望**：每条构筑的核心动作要有一个局内可执行、有反馈的入口——引线（例如 1–4 键选区 + 该区视觉标记）、回照（护盾圈 + 剩余时间/护盾值）、合唱墙（四区计数或至少「四区是否齐」的指示灯）。

### P1-4 三选一过密、卡面读不完、选卡打断节奏

- **severity**：medium
- **复现**：局 1 第 1 次选择在开局 5 秒内；第 8–10 次的选择时点分别是 3:12 / 4:00 / 4:29。**10 次选择在 4:30 内结束**，之后 5 分钟没有任何构筑推进。每张卡 4–5 行正文 + 代价行 + 卡头 3 个装饰旋钮（无信息量），第一次读根本来不及比较。选卡时游戏暂停（这点是好的），但 10 次暂停把前 4 分钟的演奏切成了碎片。
- **期望**：把 10 次选择摊到 9:30（约每 45–60 秒一次）；前 1–2 次给「推荐/教学卡」；卡面压到「1 条主效果 + 1 条代价」两行；删掉装饰旋钮。

### P1-5 提示与实际行为不一致（完成度）

- **severity**：medium
- **复现**：
  1. HUD 写「Esc 暂停 · Tab 看构筑」，暂停面板底部写「Tab 查看构筑」。实际按 Tab：焦点从「继续演出」跳到「重新开始」，**没有任何构筑面板出现**（`04-pause-panel.jpg` 为按 Tab 后）。
  2. 暂停面板「当前构筑」：局 4 我同时拥有「引线」（核心）+「黑潮」，面板只显示「黑潮」；局 5 更直接——暂停面板标题已经写「序曲 · 合唱墙」，构筑区却显示「**还没有拿到卡。第一次升级会先选核心。**」
  3. 队友线断 toast「线断了。靠近队友，按 E 插线。」：我 5 次靠近队友按 E（局 1 四次、局 3 一次），三种线（吉他/贝斯/鼓）在整局保持断线，从未看到插线成功反馈。
  4. 空场后「暂停（Esc）」按钮 `disabled`：玩家只能「跳过剩余演奏」或干等 3 分钟，无法查构筑/复盘。
  5. 局 3 我一共选了 6 张卡（回照/护盾/换气/擦弦/烧穿/独奏延长），HUD 核心标签只显示 4 个（`05-empty-house.png` 与结算前截图）：看不到完整构筑。
- **期望**：文案与行为二选一（改文案或实现 Tab 构筑面板）；暂停面板列出全部已选卡（含核心）；E 插线要能成功并有反馈（或改为自动插线）；空场后允许暂停查看构筑；HUD 核心列表支持折叠/滚动显示全部。

### 其他观察（P2，未计入 5 条）

- **相机跟随的遮挡**：局 1 按 D 侧移主唱后，画面左侧约 30% 被舞台侧结构遮挡、底部约 40% 纯黑（`06-act1-chorus.png`）。README 已知限制 4 只写了「W 边界」，我实测**横向移动同样严重**。
- **进化无「高光时刻」**：局 3 第 6 次选择副标题变成「进化：独奏会」，除此之外没有动画、音效、提示；进化是构筑的高潮，却完全无感。
- **空代价**：「第二排」的代价写作「上限受座位限制（768）」——768 本来就是全局上限，这不是代价。
- **「今晚的曲目单」易误读**：演出前显示「今晚有 0 个人第一次站起来」，第一眼像数据错误（其实是对上一场的记录，副标题有说明但很小）。
- **长按 Space 放下光**：局 3 终曲提示「长按 Space 放下光」，我按了 3 秒，圆环没有填充；9:30 自动进入「完成终曲」结算。不确定是输入限制还是实现问题，建议补一条真机验收。

## 五、最想优先改的 3 件事

1. **让光与「被照亮/被转化」可见**（P0-1）：光斑边界 + 观众「彩」+ 三态可分辨。这一条不修，后面所有机制玩家都读不到。
2. **做人气仪表盘与空场预警**（P0-2）：非数字、可读、接近危险有明确信号。配合「人气=血量」的主题，仪表盘本身可以是舞台前观众密度/四区计数条。
3. **给三条构筑各自一个局内可执行、有反馈的操作入口**（P0-3）：引线=数字键选区 + 标记；回照=护盾圈 + 剩余时间；合唱墙=四区计数/齐奏指示。

## 六、设计一致性 / 深度与重玩 / 完成度 / 推荐价值

**设计一致性**
- 主题 → 机制：**一致**。光=注意力=人气=弹药，四区=四声部，养人招灾，空场结局——概念层咬合非常紧。
- 机制 → 反馈：**断裂**。光不可见、人气不可读、构筑状态缺失（P0-1/2/3）。玩家在局内做不了「养人还是烧噪音」的决策，只能猜。
- 机制 → 难度：**不一致**。三条构筑的生存能力差异巨大：回照（独奏）9:30 完成终曲；合唱墙 6:06 空场；引线 3:39 空场。回照的护盾 60 点/每秒回 6 是明确的自保；另外两条在「看不见状态」的前提下几乎必死。这不是难度曲线，是「选错核心就输」。
- 段落 → 节奏：**不一致**。前 4:30 是「选卡模拟器」（10 次选择），后 5 分钟是「看画面」。两段割裂。
- 结局 → 主题：**一致**。空场「只剩你还在弹」/ 完成终曲「今天，只有你听见了。」——两种失败/成功都被写成了叙事。

**深度与重玩**
- 纸面深度够：24 张卡池、3 条互斥构筑、3 个进化、3 种结局形状、4 档评级（S/A/B/C）、768 席四声部。
- 实际构筑感偏弱：卡池小，两局之间重复出现「擦弦/走位/节拍点燃/换气/安可保险」；卡片没有「与当前构筑协同」的提示；三条构筑的核心条件（四区各 ≥40 / 指定诱饵 / 独奏）在局内不可读，所以「构筑」更像「随机加点」。
- 重玩动力真实存在：评级 + 「散场之后·最佳」记录（峰值 140 / 最长 9:30 / 评级 C / 完成终曲 1）+ 三条构筑差异，会让我想再开一局验证。

**完成度**
- 主菜单 / 曲目单 / 排练室 / 设置 / 暂停 / 离开确认 / 结算：结构完整、文案统一、无套壳感。排练室三页与结算页的质量超出我对「单文件 AI 产物」的预期。
- 明显缺口都在「局内」：Tab 文案、暂停面板构筑、E 插线、空场后暂停、HUD 核心截断、相机遮挡（P1-5 + P2）。

**推荐价值**
- **值得推荐（有条件）**：给喜欢 Livehouse / 乐队 / 氛围叙事的玩家，7/10；前提是先读「排练室」三页，并且能接受「第一局大概率空场且不知道为什么」。
- **不推荐**：给《吸血鬼幸存者》数值向玩家（没有数值曲线、看不到成长反馈）、以及第一次接触的休闲玩家（第 2 分钟空场，且画面不告诉原因）。

## 七、保留 / 改进 / 删除

- **保留**：「散场之后」结算页（数据 + 后台台词 + 评级卡）。它是这个项目最独特、最值得被记住的一屏，任何迭代都不要动。
- **改进**：局内可读性——光、被照亮者、人气、四区、构筑状态。这是 90% 玩家第一局的生死线。
- **删除**：三选一卡头的 3 个装饰旋钮 + 4 行正文。卡片信息应该压到「1 条主效果 + 1 条代价」。

## 九、是否再玩 / 是否推荐

- **再玩**：愿意，2–3 局。想验证：合唱墙把四区养到各 ≥40、引线「指定诱饵」到底怎么按、独奏会能否稳定 9:30、评级能否到 B。

## 十、试玩方法与已知限制

- 视口 1440×900、DPR 2；线上版（无 `?dev`），单文件部署；Network 仅 1 条文档请求（与 README 一致）。
