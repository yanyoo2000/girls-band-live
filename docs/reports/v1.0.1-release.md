## 5. 已知限制（defer，不阻塞 v1.0.1）

完整说明见 [v1.0.1-rc §7](v1.0.1-rc.md) 与 [t147 审查]（0 blocker/high）。

1. **90 秒真人门**：AC-13 / AC-H01 需 10 名外部新玩家，≥7 人在 90 秒内主动移光；当前只有 AI/脚本证据。
2. **人耳音频**：5 层音乐、12 声部合唱、12 SFX 的听感与盲听 A/B 未做；v1.0.1 只修参数/结构（空场 0.22、静默 16s、合唱 0.38、duck）。
3. **性能**：集显 3 局、1920×1080 完整、连续 3 局内存未正式测；Firefox 未实机。
4. **峰值 >300 / S-A 可达性**：9:30 峰值约 109–356；B 需终场 ≥300；S/A 阈值与峰值 >300 仍 defer（P2，待数据/产品）。
5. **2.5s 唱化**：12HP 底噪在 24dmg/s 下约 0.5s 死亡；未改 HP/伤害，避免破坏 F3/点燃手感。
6. **卡 offer 随机**：第二排 / 合唱墙 / 引线在单局可能抽不到（两张复测局均未 offer），只能由 `modifier-wiring` 单测确认；P1 调权重/进化提示。
7. **断线方位 / 点燃视觉**：断线只有文字与「按 E」，无方位箭头；点燃命中拍点主要靠音效，瞄准点无短闪（P1）。
8. **W 边界构图**：提亮后光池/观众可见，但舞台后侧画面底部仍偏暗（未专门调整）。
9. **H2 等价钩子**：1:12 荧光棒在 back-right 第一排最右端（1.7m），非 GDD 原文第 24 排。
10. **whiteout 动画峰值**：静态上限 0.85，动画峰值 0.957–1.000（表现层脉动）；`dwellRewardRatio` 负值 = 停住净损失，属预期证据。
11. **其他未覆盖**：失败卡/中断局、三构筑各一局、三进化、S/A 边界、静默可读、高对比/色觉复述未专门构造；仅桌面。
12. **命名 / 许可证**：初检无同名电子游戏；正式商标检索与项目许可证待用户。
