## 6. 冠军与 North Star

**冠军 C《谁在听》**：一束有代价的光——照向台下，他们为你燃烧，噪音也循光而来；养人—招灾—唱化—放下光。

**North Star**：让玩家在 9–10 分钟里学会一件事——你看哪里，决定谁被照亮、谁被吞掉；你养大的一屋子人，既是你唯一的声音，也是你招来的危险。一局结束时，玩家能说出「是我把这一屋子人养出来的，也是我把噪音招来的」，并想再开一局。

选择理由摘要（完整版见 `docs/decision/selected-concept.md` §7）：

1. 新权重下 Fun/Theme/Orig 共 70% 权重，C 的中位数 8/8/8，是唯一三项都 ≥8 的方案；B 为 6/7/9、A 为 7/6/7。
2. C 是唯一正反馈循环；重开动力长在循环里，而不是长在评级或调参上。
3. 3/3 评审与 6/7 打分员排序一致；不是制作人偏好。
4. C 的短板（假构筑、驻光解、HUD 矛盾、90 秒门、角色工具化）可通过规则修复，不需要重做底层；B/A 的短板是结构性的。
5. 旧权重下 C 也夺冠（7.70），规则变更没有制造冠军。
