## 0. 结论

**十份齐全，五要素齐备，可以进入 M2。**

- 10/10 文件存在，均为新版自由企划；无缺交、无空文件、无旧稿混入。
- 10/10 都给出了：标题与一句话、一个具体到画面/声音/操作的「哇」瞬间、对品类或主题的推进声明、愿意冒险的核心机制、最大风险或必须成立的前提。
- 真正的问题不是「不够大胆」，而是**十案在情绪高潮上高度同构**：几乎都指向「停电/静默 → 观众替你唱完」。这是本轮最有价值的共同发现，也是 M2 必须首先处理的结构性风险。
- 没有任何一案是「幸存者换皮」；没有发现复制粘贴、空洞堆料或现实 IP 影射。

**Top 3 惊艳点**：《满弦》的「松弦回色」、《静场》的「按住空格制造空拍」、《杂音》的「0.3 秒静默与心跳白线」。

## 2. 逐份评估

每份按七项检查：一句话、那个瞬间、前所未有、核心冒险、最大风险、可收敛种子、门禁判断。以下内容全部来自文件本身，未做补写。

### 2.1《不散场》 / LAST SET（叙事与角色关系）

- **一句话**：今晚是「空耳」的最后一场演出；怪潮从台下涌上来，你只有一首歌的时间，把四个已经决定离开的人，一个一个听回来。
- **那个瞬间**：混音台里沅的推子**自己往下滑**——没有血条、没有警报、没有「队友即将离队」提示；低频一点点消失，「你回头，她还在弹，只是把自己调小」。玩家唯一的主动键是按住 `Space`「听」：世界降到 40% 速度，地板亮成五线谱，**用走路把她的旋律走一遍，还给她**。
- **前所未有**：把「注意力/倾听」变成唯一致胜资源（从「你能杀多少」到「你能听见多少」）；关系即编曲（升级＝这一段谁做主旋律）；失败不是死，是散场；错音不重来，留成下一段动机；「缺声」代替掉血。
- **核心冒险**：要求玩家在怪潮最厚时**主动停手**；并且接受「救不回来」——没有全员存活真结局，最好的结局是四个人把最后一个音弹完。
- **最大风险**：程序化音频必须真的好听，且缺一轨真的会疼；若只是「能听的循环」，推子就只是 UI 动画。作者已写明这是项目的生死线，而非打磨项，并给出 90 秒垂直切片验证法。
- **可收敛种子**：强。作者自带最小可玩版（一舞台、一首 8–10 分钟的歌、三段「听」、两种杂音、一个静音精英）与「只保推子和听」的砍法。
- **门禁判断**：通过。是本轮把「关系」写成机制、而不是写成对白的最完整一例。

### 2.2《啸叫》 FEEDBACK（数值与构筑）

- **一句话**：四个女孩被困在一座永远满座的场馆里，台下的观众靠吞掉「有结尾的歌」活着；她们唯一的活路，是把这首四分钟的歌从头演到尾，然后让全场喊出那句「安可」。
- **那个瞬间**：2:45、第 89 小节。桥段停电，只剩贝斯与人声；按住左键给麦克风蓄「啸叫」，在整整一拍的静音里不松手；松手后五个声部按顺序各响一个音——**每个音都是台上的一个活人**；第五音落下的同一帧，舞台灯 180° 转向台下，第一次照亮 900 名观众手腕上「没能等到安可的乐队」的手环，场馆本体「满座」站起来。
- **前所未有**：游戏时钟＝音乐时钟（128 BPM / 128 小节 / 4:00）；没有 BGM，每件武器就是一个声部；升级改的是和弦（Am → Am7 → Am(add b5)），**和弦能被听见**；「被包围」变成弹药；安可值必须填到 80 才能活过歌的结尾——让想吃你的观众爱上你。
- **核心冒险**：放弃一部分自由战斗手感，一切钉在拍子上；4 分钟一局的重玩性押在曲目表、调性和场馆规则上，而不是数值。
- **最大风险**：程序化音乐必须好听，且承诺「30 秒循环不让人抖腿就砍掉企划」的一票否决验证点。
- **可收敛种子**：强。验证点极其具体、可前置；但要警惕乐理（音级、变化音、失真）对非乐理玩家的门槛，卡面必须只写「和弦名 + 增减 + 试听」。
- **门禁判断**：通过。是十案中「音乐＝数值」咬合最紧的一份。

### 2.3《满弦》 / TAUT（氛围与视听）

- **一句话**：凌晨四点半，散场后的 Livehouse 只剩你一个人和一把六根弦的巨型木吉他——冲上台的人从四面八方涌来，你唯一的手段是弹：把台下的椅子坐满，把台上的人找回来。
- **那个瞬间**（2:40，逐帧到 0.1 秒）：把 31 个敌人「卡」在最粗的低音弦上，松手——0.00s 全屏静音只剩一声心跳；0.15s 31 个音同帧松开，镜头 12 度震、红蓝色差；0.30s 31 个人被抛向半空、由灰白变回彩色；1.10s 落地、转身、走到台下坐下鼓掌；1.20s 抬头，台下已坐 400 人，有人喊你的名字。
- **前所未有**：唯一的暴力是「踩弦—回弹」；走位即弹奏；六根弦 / 四个人，找回一人点亮一根；弦会断、断弦变地形、**只有回到台上的人能替你装弦**；成长曲线向下（六音→一音）；全游戏只有一个声源（走音的吉他），敌人完全无声；整局唯一一次人声是结尾 500 人一起「啊」。
- **核心冒险**：抽掉升级菜单——成长只发生在台上、实时的、可能被打断的那几秒；敌人无声；结算把本局翻译成一段可听的曲子（P1，可降级为波形图）。
- **最大风险**：手感（形变、加厚、白闪、低频、半空变色五件事必须同帧）、声音质感（必须 Karplus-Strong/波导，而不是振荡器）、构图（30 秒内必须被认出是把吉他）。
- **可收敛种子**：极强。作者自带 P0 兜底：一舞台、三根弦、一位队友、一种敌人、一个从音孔爬出来的 Boss；并给出「只留六根弦与松手」的一句话。
- **门禁判断**：通过。机制、主题、镜头语言三者是同构的，是十案中「不可替换性」最强的一份。

### 2.4《别关灯》（玩法融合）

- **一句话**：一支叫「空场」的地下乐队，用一束只能照亮一个人的追光，跟一屋子想被听见的东西抢一首还没写完的歌——你越响，它们越多；灯一灭，你就被忘记了。
- **那个瞬间**：第 7 分钟第三次副歌后，歌被整个拔掉——声音、灯光、HUD 在同一帧全黑，只剩台下上万人的呼吸（音量由你转化过的观众数驱动）；屏幕只剩一个随心跳收缩的白点；你按空格「起拍」，把全场唯一的灯给一个人；第一声鼓砸下来，台下所有空壳同时张嘴唱出你教过的和弦；鼓手耳返：「喂……它们在跟拍。」
- **前所未有**：一束灯只能照一个人（自己 / 吉他 / 贝斯 / 鼓），每 3–5 秒重选——「选角色」被拆成每秒的按键，被留在暗处的人会掉拍；敌人不被杀，只被「请入座」；升级给你「一小节」拖进歌单时间轴，BUILD 即难度；终曲由玩家主动按下；赢＝唱完后三秒安静里有人喊安可；存档是一张越写越满的谱纸。
- **核心冒险**：两秒黑场可能什么都不是；一束灯可能深度不足；整体偏安静，而幸存者玩家要的是爽。
- **最大风险**：掉拍黑场必须给足——前 8 秒音乐上推、呼吸由人数驱动、起拍第一下必须比预期更响、起拍失败不羞辱玩家。
- **可收敛种子**：中。系统数量是本轮最多的一份（灯 / 空壳 / 观众 / 歌单 / 掉拍 / 终曲 / 安可），主线清楚但需要大量减法；作者已给「灯必须有物理、观众必须反噬」的成立条件。
- **门禁判断**：通过。想象力成立；M2 需要重点讨论它与《看向我》的近邻关系。

### 2.5《看向我》 LOOK AT ME（社区与传播）

- **一句话**：你只有一束光——照向观众，他们为你燃烧，噪音也循光而来；整场演出你只做一件事，就是决定看哪里。
- **那个瞬间**：第 2 分钟，把光甩向观众席，一整片人站起来形成人浪、撞进噪音群；噪音没有死，它们开始跟着唱、变成人，在第二排坐下举起荧光棒；观众数从 187 跳到 307；天花板又裂开一道缝（因为她的目光把噪音招来了）。
- **前所未有**：把「看」变成唯一资源**而且有代价**（注意力经济学）；台上 / 台下两张地图；烧与唱两个动词（杀 vs 转化）；失败＝演出中断，安可复活要消耗观众；「空场结局」——失去所有观众后游戏不结束，你一个人把剩下的段落弹完，黑屏一行字「今天，只有你听见了」。
- **核心冒险**：没有攻击键（只有走 + 看）；注视有代价，观众会被你的目光招来的噪音吞掉。
- **最大风险**：认知负荷与可读性。必须成立的前提写得很清楚：**前 90 秒，玩家要出于好奇心主动把鼠标移向观众席**——因为那片黑里有一根亮着的，而不是因为教程教了她。
- **可收敛种子**：强。几乎可以砍到「一束光、两排观众、一根荧光棒」仍然成立；作者还给了五个低成本传播钩子（结算显示空位、模拟评论区、程序生成应援牌等）。
- **门禁判断**：通过。是十案中「一句话可复述」与传播性最好的一份。

### 2.6《静场》 / THE BREAK（街机与短局）

- **一句话**：在一座挤满人的 Livehouse 里，你最强的招式是「停下来」——把全场按进黑暗和沉默，等人潮快要把台子吃掉的那一拍，再砸回去。
- **那个瞬间**：4:12，按住 `Space`，四件乐器一起收手；只剩一盏工作灯、一排鞋在地上摩擦、与节拍器错了半拍的心跳；鼓手把鼓棒举到最高点＝唯一合法出口；松手——1/32 拍绝对静音，55Hz 下扫到 40Hz 的底鼓砸进来，16 盏灯在 3 帧内全部过曝，前三排像被一只手掌按进地里又笑着站起来，人潮里炸开一个 mosh 洞；结算浮出 S。
- **前所未有**：幸存者的语法是「永远不停输出」，本作把「停」做成最高收益动作；16 步音序器同时驱动声音、刷怪形状与判定网格——**谱面＝刷怪表＝升级树**；没有怪物与血条，人潮是「想靠近你的液体」；镜头从台上望向观众；一局＝一首 6 分钟固定谱面＋评级＋三字母（街机契约）。
- **核心冒险**：拿走玩家在类型里最舒服的东西——「一直在做事」的确定感；手艺在「等得准」而不是「按得多」，会劝退一批熟练幸存者玩家。
- **最大风险**：空拍会不会只是「罚站两秒」——作者自己判定这是唯一能让全案归零的风险，并给出三条硬前提：静场必须是全场最忙的两秒、关掉声音也必须能玩、砸下来的 8 帧必须是全作最好的 8 帧。
- **可收敛种子**：强。作者写了完整的「如果只能留一件事」，且明确成本全在手感、不在范围；是本轮最便宜的杀招。
- **门禁判断**：通过。对品类的语法反转最彻底，且失败状态（假砸 / 冲浪）比胜利更好看，这是罕见的勇气。

### 2.7《请全体起立》（极简与单机制）

- **一句话**：在末班车之前，用四个音把一屋陌生人唱成合唱团。
- **那个瞬间**：站进贝斯手的蓝色地灯——手环亮起、蓝色从手臂爬过脸、手机灯亮，声音从「一个人在唱」变成「一屋子人在唱」；再走进吉他手的红色，蓝色不消失、红色叠上去，**第一次听见和弦的形状**；四色齐备时声音变成「和弦场」，全场手机灯同时一闪，UI 消失，只剩耳朵。
- **前所未有**：没有怪物、没有武器、没有击杀数、没有 Boss 血条；血条是「还有多少人在听」（场馆白光）；武器是你站的位置；四个音＝四个声部；合唱团替你补上你唱不到的那三个音；整场唯一按键在最后——把麦克风递出去。
- **核心冒险**：整个游戏没有「消灭」这个动词，直接违抗幸存者的肌肉记忆；作者承认前 60 秒玩家会问「怪呢？我在打什么」。
- **最大风险**：点亮第一个人的三秒必须给足（颜色爬升、手机灯、声音变宽、镜头轻推、合唱延迟半拍进来）；两百人的合唱必须听起来真的「变厚」，而不是「音量变大」。
- **可收敛种子**：极强。一个舞台、一个输入、一首歌、一团人群；作者自评「最大胆的地方，恰好是最省的地方」，并给了 InstancedMesh 与 24 个合唱声部池的具体做法。
- **门禁判断**：通过。最适合作为「最小可交付内核」的候选。

### 2.8《第一排》（长线与元进度）

- **一句话**：你打散的每一只噪音，都会变回一个观众；你唱不下去的时候，是第一排的人先开口。
- **那个瞬间**：3:47「递麦」十四秒。第一排那个由第一只噪音变回来的女孩举起「把麦克风给我们」的纸板；镜头没有切，只是**转了 180°**——你第一次从台下看自己的乐队；四十个唱不齐、会破音、慢半拍的人，用你二十秒前弹过的七个音，把噪音整片推回门口；十四秒后纸板翻面：「再来一首。」
- **前所未有**：场地会长人（击杀＝观众）；观众就是血条（厚度），不显示数字；三根乐器线＝三条系统，脱插＝主动独奏；升级卡＝你刚弹过的乐句；失败＝安静且歌被观众收下；长线＝房间 / 观众 / 曲库是存档，终场「静默场」从观众记忆里逐首删歌、你把歌教回来。
- **核心冒险**：那十四秒必须是**好玩的**，不是好看的；如果做成过场或 QTE，全案死。第二个赌注：即兴生成的 hook 必须隔天还能哼。
- **最大风险**：递麦滑成播片；hook 每场雷同；几百人 60fps；气质不能拍成 MV，要拍成现场。
- **可收敛种子**：中高。长线层（房间记忆、曲库、setlist）很重，但作者给了明确的砍法：可以砍房间、砍终场、砍到一个人，**不能砍递麦与观众记歌**。
- **门禁判断**：通过。情绪落点最准确，但收敛成本需要 M2 认真评估。

### 2.9《回声四重奏》 ECHO QUARTET（反套路实验）

- **一句话**：一场只有一个人到场的演出——她把走位录成回声，叠出三个不存在的队友，然后在停电的最后一曲里，让全场替她唱完最后一句。
- **那个瞬间**：3:07，她被「哑音」消声，麦克风哑了、那一格 VU 表归零；这时贝斯回声走完她那一圈，低频与她脚下的谱线撞在同一拍上——**她的 VU 表「啪」地亮回来**。她意识到：回声不是召唤物，是自己刚才活过的证据；台下第一次把这一句存进记忆。
- **前所未有**：空格＝回录最近 8 拍、生成 3 个回声队友（你的走位被改写成声部）；没有 HP，混音台四条声道就是血条（受伤＝乐器从歌里消失）；观众只记得你重复过的句子（观众即存档）；终曲停电、观众替你唱完；最后的胜利动作是「松手」；菜单音乐是你上一局的录音。
- **核心冒险**：反抽卡（没有三选一，构筑＝你录下的八小节）；反 Boss（Boss 是断电的十二点）；反结局（收走一切，只留一条旋律和一群人）。
- **最大风险**：音乐化层必须真的成立（把任意走位变成「想让人抖腿」的音乐）；作者明确第一个原型应是 30 秒闭眼听的 loop，而不是战斗。
- **可收敛种子**：强。一张舞台、一块踏板、四条声道、一个停电终曲即可成立；技术难点集中在音频调度与量化，作者已点到。
- **门禁判断**：通过。是十案中把「玩家是主体」反转得最干净的一份。

### 2.10《杂音》 / NOISE（新手与可读性）

- **一句话**：整座城市都在单曲循环，而你是唯一还走音的人。
- **那个瞬间**：漏拍。所有声音在 0.3 秒内被硬切到零，屏幕全黑，只剩一条 0.9 秒闪一次的白线（心跳）；敌人还在，但你看不见——只能听见塑料袋、鞋底、很多人的呼吸；唯一操作是白线闪时按空格；打回来后所有声音一次性回来，并多出一个**不是你按的**和声——系统把这段最干净的四拍变成了你的第一个队友。
- **前所未有**：玩家自己就是拍源（起拍定 BPM 且不可改，BPM＝内生难度旋钮）；空格同时承担「打拍」与「落指令」；生命是「气」；Boss 的解法是「约分」（3:4 / 5:4 / 3:2 锁相）；战利品是节奏型不是数值；暂停叫「排练」，会让台下的人走神；三章三种解法（断奏 → 脏拍 → 约分）。
- **核心冒险**：一个按钮撑起一款动作游戏；「转化」比「击杀」更上头；「缺席」当骨架；「静默」敢当失败。
- **最大风险**：可读性会被密度吃掉——1000 人同时涌来 + 一根一维拍线，是两套并行信息体系；必须成立：**一拍之内只允许一个可读事件**，做不到这条整个方案应被砍掉。次高风险是程序化音乐必须靠「音乐导演层」钳在好听范围内。
- **可收敛种子**：中。4×4 循环器＋拍线＋气＋三章＋复节拍，系统偏多；但「静默 → 心跳 → 打回来」单点可以独立成立，非常适合先做原型。
- **门禁判断**：通过。它是十案里对「桌面可读性」最认真的一份，其「三条戒律」建议升级为全项目规范。

## 3. 想象力、差异与换皮检查

### 3.1 真正的共同 DNA（不是缺点，是本轮的集体发现）

- **10/10 没有传统血条**：推子 / 混音台声道 / 弦 / 气 / 白光 / 观众厚度 / 气口。血条被替换成「你还能发出多少声音」或「还有多少人在听」。
- **10/10 有一个「黑场/静默/停电」式高潮变体**：断电、静默 Boss、空拍、黑场起拍、末班车熄灯、停电终曲。
- **10/10 失败不是死**：散场、安静、歌停、没人听了、冷场。
- **6/10 观众由敌人/噪音转化而来**（《看向我》《别关灯》《第一排》《满弦》《请全体起立》《杂音》），并同时是资源（4 案是明确血条，3 案是火力/声部，1 案是记忆）。
- **10/10 的终局都由观众完成最后一击**：拍手接完最后一段、500 人一起「啊」、递麦让观众唱完、停电后全场合唱、观众的光照回台上、安可值决定你能否活过结尾。

**这个 DNA 是好东西**：它证明「少女乐队 × 幸存者」不是贴皮，十个人独立写作却收敛到同一个命题——**演出不是独角戏，观众是共同作者**。M4 的 GDD 应该把它写成设计信条。

**但它也是本轮最大的结构风险**：十案共用同一个情绪终点，意味着「选择」很容易变成「同一款游戏的不同包装」。M2 必须先处理这件事。

### 3.2 真正拉开差异的是「主动词」，不是「情绪」

| 提案 | 主动词 | 核心资源 | 玩家每一秒在决定什么 |
| --- | --- | --- | --- |
| 不散场 | **听** | 注意力 / 声部 | 我现在要不要停手，去听谁 |
| 啸叫 | **蓄**（啸叫） | 音乐时间 / 和弦 | 我这一下松不松手，赌不赌过载 |
| 满弦 | **踩 / 放** | 弦（音域） | 踩哪根、踩多久、什么时候松 |
| 别关灯 | **照** | 光 / 观众 | 这四秒把唯一的灯给谁 |

### 3.3 近似簇与近邻风险

| 簇 | 成员 | 共同点 | 关键差异 | 近邻程度 |
| --- | --- | --- | --- | --- |
| A 光 / 注意力分配 | 别关灯、看向我 | 一束光、光照转化空壳为观众、光招噪音、观众即资源 | 别关灯的灯同时决定「这一秒谁在演奏」＋歌单编曲；看向我是纯注意力经济＋台上台下两张地图＋空场结局 | **高**（最需要 M2 二选一或明确分工） |

**结论**：十案并非换皮，但 A 簇（《别关灯》《看向我》）如果同时进入 M2 的融合池，会立刻互相稀释。M2 必须先决定：是保留「光＝注意力」，还是保留「光＝角色分配」——二者只能选一个作为主机制。

### 3.4 换皮、堆料、抄袭检查

- **换皮**：无。每一项都至少推翻了幸存者的一条默认前提（自动输出、血量死亡、敌人消失、随机地图、失败即重开、音乐只是背景）。没有一份是「把武器换成乐器、把怪换成观众」就交差。
- **空洞堆料**：无。十份都有可玩的动词、失败形状与「如果只能留一件事」的自我减法；系统多的三份（《别关灯》《第一排》《杂音》）也各自写了砍法，属于「大胆但有根」，不是清单堆砌。
- **抄袭 / 复制**：无。跨文件 25 字符以上重复行检测结果为 0；十份文风、结构、命名均独立。个别元素与既有作品有类型相似（静音机制、观众管理、节奏+幸存者混合），但没有一份复刻具体作品的角色、关卡、文案或系统组合。
- **现实 IP 风险**：正文未出现现实乐队、歌曲、艺人、动漫角色或商标。仅 `pitch-roguelike.md` 第 145 行把 `NecroDancer`、`Hellsinger`、`Hi-Fi Rush` 作为「为什么不是音游」的对照案例引用——属于正常的内部类型讨论，但**绝不可进入游戏 UI、商店文案或宣传语**（`docs/agent-handbook.md` 第 6 节已明令禁止）。`吸血鬼幸存者` 作为类型名出现在 4 份文档中，同理只可用于内部文档。

## 6. Top 3 惊艳点与最担心的 3 个风险

> 说明：本人（producer）是《不散场》的作者。为避免自评，本节的 Top 3 **不包含**《不散场》——它按同一标准在 2.1 中评估，不参与排名。

### 6.1 Top 3 惊艳点

**① 《满弦》的「松弦回色」——把机制、主题、镜头写成了同一件事。**
0.00s 静音 → 0.15s 31 个音同帧松开 → 0.30s 半空由灰变彩 → 1.10s 落地坐下鼓掌 → 1.20s 台下已坐 400 人。它同时回答了三个问题：你在做什么（踩/放）、为什么是乐队（找回的人点亮一根弦）、为什么值得讲给别人听（原来我不是在杀他们，是在让他们听见）。而且它便宜：`instanceColor` 从灰到彩的 0.8 秒插值，是全案最便宜也最值钱的一行代码。

**② 《静场》的「按住空格制造空拍」——对品类语法最彻底的一次反转。**
幸存者的肌肉记忆是「手不能停」，它要求你在最安全的时候按住空格不动，把手从键盘上拿开两秒，然后发现自己冒汗。更难的是它给了失败一个好看的样子：砸早了是「假砸」，憋过头是「冲浪」——一个「不行了」的状态，比「赢了」更好看。8 帧的砸落（1/32 静音、55→40Hz 下扫、3 帧过曝、前三排被按下去又站起）是全作的情绪核弹。

**③ 《杂音》的「0.3 秒静默与 0.9 秒白线」——最便宜、也最容易移植到任何一案的名场面。**
漏拍不是掉血，是所有声音硬切到零、全黑、只剩一条心跳白线；敌人还在但你看不见，只能听见塑料袋、鞋底、很多人的呼吸；唯一操作是在白线闪时按空格；打回来后声音一次性回来，还多出一个不是你按的和声。它证明了「让玩家什么都听不见」可以是最强的反馈，而且实现成本近乎为零——这对最终成品的性价比极高。

**紧随其后**（同样值得进入 M2 讨论）：《第一排》的十四秒递麦（玩家身份反转最干净）、《啸叫》的第 89 小节（构筑兑现最精确）、《别关灯》的黑场起拍（全黑用得最狠）。

### 6.2 最担心的 3 个风险

**风险一：高潮同构 → 融合塌缩。**
10/10 的高潮都指向「黑场 / 静默 / 停电 → 观众替你唱 / 拍手 / 喊安可」。M2 若按「情绪」而不是「动词」融合，三案很容易变成同一款游戏的三套皮肤；M3 的 7 位打分员也会失去区分度。
**建议**：M2 强制每条 hybrid 声明「高潮的代价」（谁付、付什么、失去什么），且最多允许 2 条 hybrid 共用「观众在黑暗中接住你」这一拍。

**风险二：程序化音频是共同单点故障。**
十案的核心体验都押在 WebAudio 实时合成上；至少 7 份把「音乐必须好听 / 缺一轨必须疼 / 不能像手机铃声」写成生死线。如果这一层不成立，多数方案会同时归零，而不是某一案失败。
**建议**：M3 之前插入一次 60 秒音频垂直切片（不是战斗原型）：五轨可增减、每轨可独奏、能听出「少一轨」、能让人隔天哼出来、静音也能玩。通不过就换实现路线或降级概念，不要等到 M5。

**风险三：低输入带宽 × 高信息密度。**
七份把核心操作压缩到「一个键 / 一束光 / 一根线」，但同时要求屏幕上几百人、多层音频、三色或多状态读数。这种组合要么「看不清」，要么「太浅」——两种都会杀死乐趣。
**建议**：把《杂音》的「一拍之内只允许一个可读事件」与「三种颜色」升级为全项目可读性预算，写进 M4 的 GDD 与验收矩阵；并要求每条 hybrid 通过「关掉声音也能玩」或「单屏一事件」中至少一条。

### 6.3 次级风险（不阻塞门禁，但 M2 要记一笔）

- **范围**：《别关灯》《第一排》《杂音》的系统数量明显高于其他七份；若不先定减法顺序，容易在 M4 变成「都想要」。
- **乐理门槛**：《啸叫》的和弦/音级/失真体系需要卡面降维，否则会把「好听」变成「作业」。
- **情感风险**：多案把「观众挤上台 / 人被按进地里 / mosh pit」写得很有画面，但现实中的演出拥挤事故是敏感话题；表现必须保持风格化，不做受伤、窒息、踩踏的具体描写（详见第 8 节）。
- **元进度纯度**：《第一排》的「房间记忆 / 曲库 / setlist」很动人，但要守住 brief 的 P1/P2 边界，避免把单机成品拖成长线服务。

## 7. M2 交叉讨论必须回答的 5 个问题

1. **「黑场 → 观众接住你」是必留的必然时刻，还是必须打破的套路？**
   如果是必留，请定义它的三个可变化维度（谁在黑暗里、代价是什么、玩家按了什么），并规定最多几条 hybrid 可以共用它。如果必须打破，请给出一个「不靠观众救场」的同等强度高潮。

2. **冠军的主动词是哪一个？**
   十个动词（听 / 蓄 / 踩放 / 照 / 看 / 停砸 / 站 / 递 / 留 / 起拍）必须收敛成「1 个主动词 + 最多 1 个辅助动词」。请用一句 30 秒能讲清的规则句写出来，并说明为什么另外八个动词不是它。

3. **观众到底是什么？**
   资源（血条/弹药）、乐器（可控制）、存档（记忆）、道德对象、敌人——一部游戏只能有一个主定义、一个副定义。这个定义决定了 InstancedMesh 怎么建、音频怎么混、结算怎么算。M2 必须先定它，再谈融合。

4. **音频生死线如何前置？**
   谁在什么时间做出 60 秒垂直切片？通过标准是什么（缺一轨会不会疼 / 能不能抖腿 / 静音能否玩 / 隔天能否哼）？三条 hybrid 各自的降级路线是什么？如果切片失败，是换实现、换概念，还是换冠军？

5. **一局的终点与失败形状是什么？**
   候选终点：Boss / 安可 / 停电 / 末班车 / 写完谱纸；候选失败：散场 / 安静 / 没人听 / 歌停 / 冷场。三条 hybrid 必须各有一个 30 秒可演示的「结束」与「重开理由」——否则 M3 的 7 位打分员无法评分，M4 也无法写验收矩阵。

## 8. 原创性与合规风险

### 8.1 命名撞车（不阻塞 M1，但必须在 M3 前解决）

- **角色名重复**：`小满` 同时出现在《看向我》（鼓手）、《第一排》（鼓手）、《回声四重奏》（主唱）三份企划中；`迟野`（第一排）与 `迟青`（静场）、`迟`（满弦）近似。M3 定案时只能保留一套卡司，需统一改名并做一次检索。
- **乐队名 / 场馆名**：空耳 / 空响 / 空场 / 四分之一 / 接触不良 / 三分钟热度；底噪 / 回声厅 / 半地下 / 回声仓库 / B1。语义高度集中在「空 / 回声 / 底噪」——作为气质是统一的，作为商标是危险的，必须查重后定名。
- **标题**：《不散场》《满弦》《第一排》《静场》《杂音》《看向我》《请全体起立》《别关灯》《啸叫》《回声四重奏》均为常见短语，**很可能与已有歌曲、小说、漫画同名**。这不构成侵权（标题通常不受商标保护），但发布前应逐一检索，避免宣传期撞车与搜索结果污染。

### 8.2 商标与品类引用

- 正文未出现现实乐队、歌曲、艺人、动漫角色或商标。
- `pitch-roguelike.md:145` 引用 `NecroDancer` / `Hellsinger` / `Hi-Fi Rush` 作为类型对照；`吸血鬼幸存者` 作为类型名出现在 4 份文档。二者都只允许存在于内部文档与设计讨论中，**禁止进入游戏 UI、商店文案、宣传物料**（`docs/agent-handbook.md` 第 6 节）。
- `Karplus-Strong`、`InstancedMesh`、`WebAudio` 属于公开技术名词，不构成 IP 风险；建议在 `docs/tech-spec.md` 中注明算法来源与实现方式，属于良好工程实践而非法律义务。

### 8.3 内容敏感度

- 多份企划把「人潮挤上台 / 前三排被按进地里 / mosh pit / 冲浪」写成核心爽点。现实中的演出拥挤事故是严肃的公共安全议题，**不能把窒息、踩踏、受伤做成可消费的奇观**。
- **建议红线（M4 写进 art-direction）**：全程不出现受伤、流血、窒息、踩踏；人群只用剪影与边光；「被按下去」之后必须立刻「笑着站起来」；失败画面停在空椅子与扫地的店员，不落在具体的人身上。
- 《看向我》的「模拟评论区」与《第一排》的「给第一位观众起名字」涉及生成的或玩家输入的文本：仅本地、不联网、不导出、不模仿真实平台与真人；评论必须走白名单模板（《看向我》已自证这一点）。

### 8.4 原创性结论

**十份均为原创企划，未发现抄袭或现实 IP 影射。** M3 定案后需要做一次正式的命名与撞名检索（标题、乐队名、角色名、曲名），由发行经理复核并记录。
