## 2. 根因：光为什么“完全看不见”

`src/game/store.ts` 把 `run.light.intensity` 写进 `RenderSnapshot.light.intensity`，而 **这个值只是「点燃脉冲」**（按下左键后 0.3s 内衰减到 0，见 `src/game/light.ts` 的 `ignitePulseSec`），不是常亮亮度。

v1.0.0 的 `renderer.applyLight()` 却把它当常亮系数：

```ts
const brightness = clamp(light.intensity, 0, 2) * (1 + pulse * 0.8 + flashValue * 1.8) * ...
beamAlpha = clamp(0.1 * brightness, 0, 0.3);
```

后果：**除点燃后 0.3 秒外，`brightness === 0`，地面光池与光锥 alpha 恒为 0**；观众席又只有「已转化」的座位才上色（`AudienceFrame` 不携带逐座“是否被照亮”字段），于是：

- 世界光反复测：束光前后观众席区域像素差 **0.10%**（试玩报告 0.17% 同源）；
- 灰观众（`state=1`）亮度只有 `0.72×灰`，768 座里几十人在 1280×720 是亚像素；
- 座椅顶点色是场馆黑 `#0b0d12`、环境光又低，整帧 13.9/255。

**修复原则**：光必须有“常亮底”，脉冲只做增益；光必须落在人身上（观众着色器里的世界光池），而不只是地板上一张可能被座椅挡住的贴花。

## 3. 改动（4 个文件，全部在 `src/three/`）

### 3.1 `src/three/renderer.ts`（光斑 / 光锥 / 光池 / 遮罩）

| 改动 | 数值 / 说明 |
| --- | --- |
| 常亮底 | `brightness = (0.95 + pulse*1.1 + flash*1.6) × contrast × visibility`，不再乘 `light.intensity` |
| 地面光池 | alpha `0.24×brightness`（上限 0.40），半径 = 光半径，散光正圆 / 束光椭圆（x0.82 / z1.5） |
| 光池盘（新增，1 draw call） | 抬到人群头顶 1.42m 的加法圆盘：中心 4% 亮度、边缘 52%，不被座椅遮挡，给出“光斑边界” |
| 光锥 | 底半径 = 0.4×光半径（之前 1.0），alpha `0.09×brightness`（上限 0.20）——读作“桁架下来的柱子”，不再是一团白雾 |
| 回照 | 护盾环 alpha `0.34×brightness`，随脉冲轻微放大 |
| 观众光池 uniform | 每帧写入 `uLightPos / uLightRadius / uLightBoost / uLightColor`（warm `#fff1d6`，回照 `#35e0d0`） |
| 白光遮罩 | 仍只作用于观众实例（`mix(..., white, uWhiteout × 0.3)`），舞台/乐手/噪音不受影响 |
| overdraw 估算 | 计入新增光池盘与光锥；实测 0.03–0.10（预算 2.5） |

### 3.2 `src/three/instancing.ts`（观众 / 噪音）

**观众**

- 材质新增世界光池着色器（顶点算实例世界坐标到光心的距离，片元 `mix + add`）：
  被光罩住的观众整体提亮/加暖——这是“光落在人身上”的唯一可读来源。
- 亮度基线：灰 `1.0 + 0.05×heat`（原 0.72+0.07）、彩 `0.72 + 0.12×heat`（原 0.50+0.13）。
- 姿态：坐姿 1.08×（原 1.0）、热度 ≥2 站姿 1.38×（原 1.28）——40px 下能压住椅背。
- 被噪音覆盖（`state=3`）：纯黑剪影 + 手机灯熄灭；靠更亮的椅背（见 3.4）读出“这个人被盖住了”。

**噪音**（3 常规 + 精英 + Boss）

- 每个 kind 增加 1 个 **加法描边壳**（同几何 ×1.06、`BackSide`、冷白/琥珀/靛蓝）：暗场里先看到边。
- 新增 1 个 **悬空光环** InstancedMesh（y=2.3+0.25×scale，环 0.45–0.62m）：
  噪音本体贴地只有几个像素、常被椅背挡住，光环回答“噪音在哪一排/多远”。颜色按 kind 区分（啸叫冷白、失真琥珀、返听暖白、静默靛蓝）。
- 峰值 draw call：5 实体 + 5 描边 + 1 光环 = 11；安静时全部 `visible=false` 不计。

### 3.3 `src/three/scene.ts`（曝光 / 四区标记）

- 环境光 `0.65 → 1.85`、方向光 `0.9 → 1.8`、追光 `32 → 44`、补光 `8 → 20`；暖场预设同步抬到 0.5/0.62/0.78/0.78。
- 背景与雾用「场馆黑 ×1.42」，雾密度 `0.01 → 0.0072`（后排不再被雾吃掉）。
- **四区世界标记（新增，1 draw call）**，全部合并进 1 个顶点色加法网格：
  - 每区贴地细环（半透明区界地纹，走道处可见）；
  - 每区中心 2.6m 细光柱；
  - 每区 2.95m 悬空图腾，形状与 HUD 的 ●▲■◆ 同义（圆 / 三角 / 方 / 菱形），颜色取 palette 的 zone token；
  - 中央走道十字（两条贴地细光带），把座位切成四象限。
- 静默段保留四区标记（art-direction §6），其余灯按 `setVenueLight` 压暗。

### 3.4 `src/three/models.ts`（发光底 / 椅背）

- 共享顶点色材质 `MeshStandardMaterial` 加 `emissive: #171d29`：场馆/座椅/乐手在任何灯光态下都不会掉到纯黑（这是“不靠加曝光”的兜底层）。
- 座椅顶点色 `ink #0b0d12 → #1b2029`：空场能读出 24×32 网格，同时明显低于观众，保留「人 vs 椅子」的明暗差。

## 6. 边界、已知限制、给下游的接口

**没有改的东西（避免越界）**

- `src/game/**`、`src/data/**`、`src/ui/**`、`src/styles/**`、`src/types/**`：一行未改。
- 没有新增依赖、没有外部贴图/模型、没有后处理、没有阴影、真 `SpotLight` 仍为 2 盏。

**已知限制**

1. `AudienceFrame` 只有 `state/heat/phone/tint/zone`，没有“逐座是否被光覆盖”。渲染层只能用「世界光池 + 距离衰减」近似“被照观众提亮”。若 t139 愿意加一个 `lit: Float32Array`（或 `lightRatio`），可以做到逐座精确提亮、且让 `lightCoverage` 与画面严格同源——**这是唯一建议的共享字段**，不加也能工作。
2. 光斑盘在人群上方 1.42m，是一个“投影概念”的加法盘；极端俯角/低分辨率下边缘会略硬。若要更柔，可加 1 张 CanvasTexture（art-direction 允许的程序化纹理），但会多 1 个材质与一次采样，优先级不高。
3. 噪音光环是定位层；当噪音数量很大（180）时会比较密，低画质已按 `LOW_QUALITY_NOISE=90` 截断。
4. before 1600/1920 来自线上 v1.0.0（本地 dist 被覆盖），已在 §4.5 标注。

**回滚**

- 只涉及 4 个 `src/three/*.ts` 文件；回滚 = 还原这 4 个文件（无数据/存档/存档 schema 变更）。视觉参数集中在各文件的常量区：`renderer.ts`（beamAlpha/poolAlpha/poolEdgeAlpha）、`scene.ts`（BASE_INTENSITY/BACKGROUND_LIFT/FOG_DENSITY）、`models.ts`（emissive/座椅色）、`instancing.ts`（亮度基线/光池 shader/噪音光环）。
