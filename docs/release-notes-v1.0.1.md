## 这一版改了什么

### 看得见

- **场景提亮 + 光池**：1280×720 实测全帧/观众席/舞台平均亮度 **65.02 / 54.88 / 60.04**（v1.0.0 反馈实测约 12.5–23）；光现在在地面与观众席上形成可见亮椭圆。
- **束光 vs 散光**：同一位置观众区平均亮度差 **30.62/255**，**80.84%** 像素差 ≥6；束光覆盖观众时有红色边缘反馈。
- **三形态常驻格**：散光 / 束光 / 回照 + 护盾 / 冷却 / 独奏状态；回照＝把光收回脚下，不再靠猜。
- **返听可视化**：耳朵标记 + 倒计时环；移光累计 ≥8m 或 7 秒自动挣脱，并给「挣脱返听」提示。

### 读得懂

- **非数字人气读数**：四区亮灯比例、趋势箭头、空位/第二排剪影、「人气快见底」预警；局内仍然 0 数字。
- **安可窗口**：人气归零先弹「人气告急（安可 / 继续独奏）」，不再突然空场；安可把人气拉回峰值的一部分、四区热度各 +1。
- **序曲 0–30s 三步教学**：散光养人 → 束光烧人 → 点击点燃，直接叠在演出上，不打断。
- **卡效果真正生效**：第二排 +5/30s、合唱墙 1:4 唱化、引线招灾 ×2、回照护盾都有消费方；HUD 与结算统计同源（`emptySeats`/`secondRowEmpty` 与 `RunResult` 一致）。
- **卡面精简**：删掉 3 个装饰旋钮、卡文压到 2 行，显示「还需 N 张支援」进化进度；暂停面板与 HUD 核心同源。

### 操作与无障碍

- **纯键盘可完整玩**：`IJKL` / 小键盘 / `Shift`+方向键移光，`Shift` 束光，`Enter` 点燃，数字键 `1/2/3` 选卡；QA 已用 **0 指针事件**完成 9:30（完成终曲 / C、峰值 170）。
- **失焦/切后台自动暂停**；`Esc` 暂停；`Tab` 真正打开构筑并聚焦；空场后也可暂停。
- 小窗口（<1024×640）Gate 可「仍然继续 / 回主菜单」；HUD 文字 ≥11px，关键文本对比度 7.64 / 10.66 / 5.76。
- 音频收尾：空场 0.22 独奏 + 心跳、Boss 静默 16s 兜底、合唱 0.38 + presence、升级 duck。

## 已知限制（P1 / defer）

- **90 秒真人门**（10 名新玩家 ≥7 主动移光）未做；**音频听感 / 盲听 A/B** 未人测；**性能**（集显 3 局、1920×1080、连续 3 局内存）未正式验收；**Firefox** 未实机。
- **峰值 >300 / S-A 可达性** defer：常规局常到 9 选、C；B 需终场 ≥300；评级刻度是刻意奖励养人/唱化，待数据。
- **2.5s 唱化**未调（12HP 底噪在 24dmg/s 下约 0.5s 死亡），避免破坏 F3/点燃手感。
- **卡 offer 随机**：第二排 / 合唱墙 / 引线在单局可能抽不到（两张复测局均未 offer），只能由单测确认；P1 考虑调权重/进化提示。
- **断线方位 / 点燃视觉**：断线只有文字提示，无方位箭头；点燃命中拍点主要靠音效，瞄准点无短闪。
- **W 边界构图**：提亮后光池/观众可见，但舞台后侧画面底部仍偏暗（未专门调整）。
- H2 荧光棒使用 back-right 第一排最右 1.7m 等价钩子（固定相机看不到第 24 排）；whiteout 临界动画峰值 0.957–1.000。
- 仅桌面，不做移动端/触屏/手柄。
