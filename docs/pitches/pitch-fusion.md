# 别关灯

> **一句话：一支叫「空场」的地下乐队，用一束只能照亮一个人的追光，跟一屋子想被听见的东西抢一首还没写完的歌。**
>
> 你越响，它们越多。灯一灭，你就被忘记了。

---

## 0. 开场：第一次上台之前的三十秒

凌晨一点，B1 的空调坏了。

你站在台口，鞋底粘着上一支乐队留下的啤酒。三百人的场子塞了七百个人，门外的队伍还在拐角。空气里全是汗和松香和发胶的味道，闷得像一块湿毛巾。

你回头看了一眼鼓手。她没看你，她在数拍。

吉他手在调弦，手在抖。贝斯手站在最右边，一动不动，像一根还没通电的柱子。

灯亮之前，这间屋子里所有的声音都是别人的。

**灯亮了。**

第一束追光打在你身上。台下有人的手机举起来，像一小片会呼吸的星星。你张开嘴。

从这一刻开始，你有两个选择：让他们听见你，或者让他们忘记你。

而在这间屋子里，被忘记的意思，就是**死**。

---

## 1. 那个瞬间

我想要的「哇」，发生在一局游戏的第七分钟，第三次副歌结束之后。

**歌停了。**

不是渐弱，不是过门，是有人把电源拔了。所有声音在同一帧里被切断——鼓、贝斯、你的嗓子、台下七百个人的呼吸。灯也灭了：舞台顶上的四盏，观众区两排安全出口，连你的 HUD 一起。屏幕黑到你能看见自己脸上的反光。

只剩下一种声音。很轻、很低，从台下传上来。

**是呼吸声。**

成千上万个人的呼吸，此起彼伏，像海。你刚才亲手把它们从暗处叫醒、照进光里、变成观众。现在它们坐在黑暗里，一起等着。

再等一拍。

再等一拍。

你听见自己的鞋底在地板上挪动了一毫米。你听见耳返里自己的心跳，一下，一下，大得像有人在敲你的肋骨。屏幕右下角浮出一个极小的白点，跟着心跳收缩、放大、收缩。整个游戏就剩这一个白点。

然后你按下了**空格**。

——不是技能键。是**起拍**。

白点炸开。你选了一个人，把全场唯一的一束灯给了他。

如果那是鼓手：她抬起手，一记军鼓砸下来。然后是踩镲。然后是她的整个身体。灯从她头顶泼下来，鼓皮上的灰尘在光柱里飞成一片星云。

如果那是吉他手：她终于抬眼。第一个和弦是一个被人掐着脖子喊出来的音，尖、亮、脏。

如果那是贝斯手：地板先响。你的脚底麻了一下，然后是胸口，然后是牙齿。

如果那是你自己：你张开嘴，唱出这首歌的第一百三十七个小节——那个你写了三个月都没写出来的小节。

**而就在这一下，台下所有东西同时张开了嘴。**

刚才那些从角落里爬出来、没有脸、想把你撕碎的空壳——那些被你照过、被你叫醒、被你请进观众席的东西——它们不是要杀你。

它们在跟唱。

你教过它们的那一个和弦，一模一样。几百个、上千个声部，从那一片黑里升起来，笨拙地、认真地对上了拍子。你听见自己的歌被一首你不认识的合唱团唱了回来。

你的角色站在原地，回头看了一眼台下，愣住了。鼓手在耳返里骂了一句：

> 「喂……它们在跟拍。」

然后副歌进来了。

---

我没有见过这个瞬间。

不是「清屏大招很爽」，不是「音乐游戏卡点很爽」。是——**你花了七分钟把敌人变成观众，然后在两秒钟的绝对黑暗里，听见它们一直在等你开口。**

这两秒钟里，玩家什么都没做。这是全游戏最安静的地方，也是全游戏最想让人尖叫的地方。

## 2. 第一次玩的三分钟

我不想要教程弹窗。我想让玩家在玩的过程中，自己发现三件事。

**0:00 — 你只有一盏灯。**

灯在你手里。不是在舞台顶上，是在你手里——一根线垂下来，末端是个旧调光台。B1 太穷了，没有灯光师。

> 所以你只能照亮一个地方。

灯照在你身上，你唱。屏幕上开始有东西从台口的阴影里浮出来：人形，穿着和台下一样的衣服，没有脸。它们不快，它们不叫，它们只是往前走，像一屋子还没睡醒的人。

**0:35 — 它们不是来杀你的。**

你本能地把灯往它们身上扫。灯柱扫过去的一瞬间，它们停住了。

不是被击退，不是被烧。是**停住**，像被人叫了名字。

光照满一秒半，最近的那个抬起头，脸上的空白裂开一道缝，张开嘴。

「啊——」

一个音。准的，是你刚才唱的那个音。它退到台下，站好，不再往前。

你下意识把灯又扫向另一只。第二个音。第三个。

**你发现你不是在杀它们。你是在请它们入座。**

**1:20 — 你开始听出和弦。**

第三十个观众出现的时候，你的耳返里多了一层东西。不是音效，是**和声**。

你突然意识到：每一只被你转化的东西，音高是不一样的。站在左边那些，声音低；右边那些，声音高。你把灯往左扫，低频就厚一点；往右扫，高频就亮一点。

**你在用敌人的站位作曲。**

你开始不自觉地赶它们。把它们往左边赶，堆成一坨闷闷的低音；把它们往右边赶，让高音尖起来。你不是在玩游戏，你是在**摆一个合唱团**。

**2:40 — 你第一次受伤。**

你漏了一只。它爬上舞台，手指碰到你的脚踝。

不是掉血。是**掉声部**。

你听见你的歌突然空了一块——贝斯没了。整整两小节，低频整片塌下去，鼓声变得像在敲纸箱。屏幕上，你的灯暗了一格。台下有几个人转身走了。

你慌了，往回跑，把灯举高。

贝斯回来了。你听见它回来。

**3:00 — 第一次黑场。**

歌停了。屏幕黑了。你听见呼吸。

你愣了大概半秒，不知道自己该干什么。然后你看见那个白点。

你按了空格。

你没有选人——你只是把灯往前一推，照在了自己身上。

你唱了。

台下所有东西跟着你唱。

你后来跟别人描述这个游戏的时候，会说：「就是……你唱一句，一屋子怪跟你和声。你懂吗？」

## 3. 核心：一束灯，四个人

这是整款游戏的**唯一**核心机制，其他一切都从它长出来。

> **你只能照亮一个地方。**
>
> **而你身后有四个人，台前有一千只东西，都在等这束光。**

灯可以给：

| 光落在谁身上 | 你会得到什么 |
| --- | --- |
| **你（主唱）** | 你自己的麦克风变成音波武器；移动最快；但三个乐手停摆 |
| **吉他手** | 高频斩击，穿透一整排；但你的移动变慢，低频消失 |
| **贝斯手** | 低频震地，全场减速，脚步会把地板的节奏变成伤害；但你听不见高音，看不见快速接近的东西 |
| **鼓手** | 节拍强化：攻速、起拍窗口、转化效率全部提升；但输出最钝 |

一束灯，四个选择，每 3–5 秒重选一次。

**这就是「选角色」被拆碎的样子。**

一般游戏让你在开局菜单里选一个人，然后用四十分钟。这个游戏让你每四秒选一次，而且每一次都要付出代价——因为灯移开的瞬间，被留在暗处的那个人，**会掉拍**。

吉他手在暗处弹错一个音。贝斯手在暗处什么也不弹。鼓手在暗处数错一拍。

不是数值惩罚。是**你听得见**的惩罚：你的歌里少了一个人。

> 这是我对「少女乐队」最诚实的一次翻译：
>
> **聚光灯只有一个。四个人都想要。而你是那个握着开关的人。**

在 B1 这种地方，没有灯光师。所以灯在你手里。你一边唱，一边决定谁被看见。

这是乐队最不敢说出口的事，我把它做成了一个按键。

## 4. 系统草图

### 4.1 灯 / THE FOLLOW

- 鼠标就是灯。移动鼠标 = 移动追光。左键 = **收束**（灯圈变小，转化速度翻倍，适合救急）；松开 = **散开**（范围大，转化慢，适合铺场）。
- 灯照**空壳** = 转化（1.5 秒填满，变成观众，退到台下）。
- 灯照**队友** = 供给。被照亮的队友积攒「被看见」，满了之后可以打出一段**段落技**（副歌爆发）。
- 灯照**地面** = 什么都不发生。这是玩家的「休息」，也是玩家的「失误」。
- 灯有惯性，有延迟，有一个 0.15 秒的「拉丝」。它不跟手，它像真的追光一样笨重。**你要提前想。**

### 4.2 观众 / THE HOUSE

- 观众不是分数。观众是**你的血、你的和弦、你的护甲**。
- 每 50 名观众 = 一个声部。声部越多，你的歌越厚，你的伤害越高，你的转化越快。
- 观众会**饿**。热度会掉。掉到 0，灯灭，你被忘记。
- 观众会**抢**。数量超过某个阈值，前排的观众会开始推挤，试图爬上台——**你养的观众会变成新的敌人**。你越强，你越危险。
- 观众会**走**。安静超过 8 秒，最后排的人开始离场。你听得见他们的脚步。
- **这是整个游戏里最吸血鬼的一处：你是被自己喂饱的东西养着的，而它们永远吃不饱。** 你越喂，它们越想要；它们越想要，你越亮；你越亮，来的人越多。

### 4.3 空壳 / THE HOLLOW

- 它们不是怪物。是**没有人看过的人**。
- 它们不会攻击没有光的地方。它们在黑暗里只是站着。
- 一旦被光照到并转化失败（比如你在它张嘴之前把灯移走了），它会「醒得太早」——变成**跑者**：快、哑、不会唱，只会撞。
- Boss 是**一个坐满人的观众席**：不攻击，只是坐在那里，等你唱。你唱得越好，它越沉；你唱砸了，它整排站起来。

### 4.4 歌单 / THE SETLIST（就是 BUILD）

升级不给你「+15% 伤害」。

升级给你**一小节**。

- 每升一级，你从三个「乐句」里挑一个：一段贝斯过门、一个双踩、一段和声、一记镲、一句吼。
- 你把它**拖进歌单**——一条从左到右滚动的时间轴。你决定它出现在第几段、第几拍。
- 战斗就按这条时间轴演奏。**你是在作曲，战斗是这首曲子的演奏结果。**
- 歌单越长，歌越满，**空壳越多**。你的 BUILD 就是你的难度。

这解决了一个老问题：幸存者的升级是一串无聊的百分比。这里的升级是**听得见的**。你加了一段镲，下一轮副歌你就真的听见那段镲。你会为了听那一下，重开一局。

### 4.5 掉拍 / THE DROP

- 每 90 秒一次，歌会「掉拍」：所有声音、所有灯、所有 HUD 一起消失，**2 秒**。
- 这 2 秒里你能走，不能攻击，不能转化。你能听见整个场馆的呼吸（音量跟你的观众数量成正比）。
- 2 秒结束，白点出现，你按空格——**起拍**。
- 起拍成功：灯爆亮，全场合唱，所有空壳被音浪掀翻一次，你获得一段 10 秒的「副歌时间」。
- 起拍失败：灯不亮，观众开始离场，歌单跳回上一段，你要从头把气氛焐热。
- **起拍的时机是随机的**，白点会提前 0.3 秒闪一下。老手闭着眼也能按。
- 这不是 QTE。这是**呼吸**。

### 4.6 终曲 / THE LAST CHORD

一局游戏不是「活到 20 分钟」。一局游戏是**把这首歌唱完**。

- 歌单有最后一段，叫**终曲**。你可以随时按下 `Tab` → 「就到这儿吧」，主动进入终曲。
- 进入终曲后，所有还没转化的空壳会一次性冲上台，你必须在它们淹没舞台之前唱完最后 16 小节。
- 唱完 = 这首歌又多写了一段，存档。
- 没唱完 = 灯灭，观众散场，这首歌停在这里。
- **你可以在任何时刻决定「这就是最后一段」。** 这是一个赌：早切，安全，但歌短；晚切，歌长，但你可能会死在倒数第二小节。

幸存者游戏从不让你决定什么时候结束。这里，你是那个说「好，就唱到这儿」的人。

### 4.7 安可 / THE ENCORE

一个和弦落下去。最后一个和弦。

所有灯在同一秒熄灭。舞台、观众席、你的 HUD。你站在全黑里，听见自己的呼吸。

**然后是三秒钟的安静。**

这三秒是整个游戏里最长的三秒。你不知道自己唱得怎么样。你不知道这首歌够不够。你不知道刚才那七百个人是在鼓掌，还是在穿外套。

**三秒之后，如果台下有人喊了一声「再来一首」——**

第二个人。第三十个。最后一排。全部人。

灯从观众席的方向亮起来，打回你身上。鼓手把鼓槌在裤子上蹭了蹭，重新握紧。吉他手看了你一眼，笑了。

**这就是赢了。**

不是「通关」。不是「存活」。不是「S 评价」。

**是有人不想让你走。**

如果三秒之后什么都没有——灯不亮，场馆安静，只有保洁阿姨在门口搬椅子——那就是这一局的结束。不叫失败，叫**这首歌还没到能留住人的程度**。

两种结局，同一首没写完的歌。

> 我想要的最终情绪不是「我变强了」，是「他们还想听」。
>
> 而这件事你没办法用数值买到，你只能一遍一遍地写，一遍一遍地唱。

## 5. 歌就是存档

主菜单是一张谱纸。

被咖啡渍泡过，边角卷起来，上面有铅笔写的、划掉的、又写回来的东西。那不是装饰，那是你的存档。

**每开一局，你都在接着写同一首歌。**

- 第一次玩，谱子上只有两行：主歌，副歌。
- 死了一次，谱子上多了一行字：「第二段副歌，待定」。
- 第五次，谱子上有一段被红笔圈出来，旁边写着「这里她哭了」。
- 第十次，谱子写满了。这首歌可以演了。

**你的进度不是等级，是这首歌的长度。**

主菜单没有「继续游戏」。只有「**接着写**」。

这带来一个副作用，我非常想要：玩家会开始**在乎这首歌**。

他会在第三局的时候发现，上一次死掉的地方，这次他写过去了。他会在结算界面看到那句「第二段副歌，待定」被划掉，换成新的一行。他会想：「再来一次，我想把桥段也写出来。」

——**这是把「再玩一局」从数值驱动，变成创作驱动。**

而且它天然解释了一件事：为什么这支乐队一直在同一个地方，唱同一首歌。

因为这首歌没写完。

## 6. 操作表（桌面键鼠，一只手都能玩）

| 输入 | 行为 |
| --- | --- |
| `WASD` | 在舞台上走位。舞台是实体，有边缘，掉下去会掉拍 |
| `鼠标移动` | 移动追光 |
| `左键（按住）` | 收束光斑：小、亮、转化快、伤害高 |
| `右键（按住）` | **清唱**：让全场观众闭嘴，只留你的声音。怪会被吸过来（它们想听清），但你没有任何和声 |
| `空格` | 起拍（掉拍时刻）/ 段落技（灯满时） |
| `Shift` | 收声：降低存在感，怪不追你，但热度掉得飞快 |
| `Tab` | 歌单（暂停 + 编曲界面，游戏时间冻结） |
| `1 / 2 / 3 / 4` | 快速把灯切给某个人（老手用，新手用鼠标就行） |

**没有技能栏。没有冷却图标。没有蓝条。**

因为所有的资源都长在场景里：灯的位置、观众的站位、歌单的进度、还有那两秒的黑。

## 7. 反套路七条

1. **敌人不是被杀的，是被请进来的。** 你的 DPS 其实是「入座率」。
2. **你最怕的不是怪多，是安静。** 安静 = 没人记得你 = 灯灭。所以你必须主动制造噪音，而噪音就是难度。
3. **升级不给数值，给一小节音乐。** 你的 BUILD 是一首歌，不是一棵树。
4. **你的最强操作是「减法」。** 右键清唱、松开左键、把灯从队友身上移开——都是放弃。
5. **选人不在开局，在每一秒。** 灯给谁，谁就是这一局的主角。
6. **你可以决定什么时候结束。** 终曲是玩家主动按下的，不是时间到了自动播的。
7. **死亡不是重来，是这首歌还没写完。** 存档是一张谱纸，不是一串数字。

## 8. 为什么是少女乐队，为什么是幸存者

**为什么必须是少女乐队？**

因为「一盏灯照四个人」是乐队最真实的物理事实，也是这个题材最核心的情感事实。

主唱永远在最亮的地方。吉他手永远在侧光里。贝斯手常常在黑暗里站一整场。鼓手在最里面，被自己的镲片挡着。

偶像题材讲的是「被看见」。而这个游戏的机制就是「被看见」的分配问题。

去掉少女乐队，你可以做任何「聚光灯」题材——但只有乐队，才有那种「四个人一起，但只有一个人被记住」的酸。而且只有乐队，才有**安可**这种东西。

**为什么是幸存者？**

因为幸存者的核心循环本来就是「你越强，来的越多」。

这句机制描述，放到舞台上就是「你越响，来的越多」。

它不是嫁接，它是同一个句子的两种说法。

而且幸存者天生允许一屏几百个单位。几百个单位，就是几百个观众。几百个观众，就是几百个声部。

**几百个声部，就是一款真的会唱歌的游戏。**

**一句话总结这次融合：**

- 幸存者把「变强」翻译成「更多敌人」；这里把「变强」翻译成「更多人听你」。
- 音乐游戏把「你要跟上音乐」当规则；这里把「音乐跟上你」当奖励——你按下的每一个起拍，都会变成下一小节的拍点。
- 少女乐队题材习惯把「被看见」写成剧情；这里把它写成一个真的可以按下去的资源。

三者共用同一个动词：**照**。

## 9. 为什么它能做出来（技术直觉，不是方案）

- **灯**：一个 SpotLight + 一个程序化光锥网格 + 一个屏幕空间的径向渐变，够了。不需要实时阴影。
- **观众**：InstancedMesh。一个实例就是一个人形 + 一个张嘴的动画帧。上限由技术方案定，但视觉上「多」比「精」重要。
- **合唱**：不要每个观众一个振荡器。用 8–12 个固定声部（按音高分组），每个声部的音量/声像由该组观众的**数量和站位**驱动。听起来是上千人，算起来是十几个节点。完全可行。
- **掉拍**：`AudioContext.suspend()` 或者一条总线增益拉到 0，加上 CSS 黑场。成本近乎为零，效果是最贵的那一档。
- **谱纸菜单**：一张 CanvasTexture。三行代码。
- **歌单**：一个数组，一次映射到音频调度器。这是整个游戏最复杂的系统，也是最值钱的。

**最贵的东西不是画面，是「时间」**。所有的灯光、合唱、掉拍，都是把已有的声音在正确的时刻打开和关上。这是音频调度问题，不是渲染问题。对 Three.js 来说，这是好消息。

## 10. 最大风险

**风险一：那两秒的黑，可能什么都不是。**

如果玩家在掉拍时不知道该按空格，那两秒就是「游戏卡了」。如果起拍的音乐不够炸，那两秒就是「故弄玄虚」。

这个瞬间必须成立，否则整个游戏就是一堆好听的设定。

**必须成立的前提：**
- 掉拍前的 8 秒，音乐必须一路往上推，推到你觉得「要来了」。
- 那两秒的呼吸声必须是真的由观众数量驱动的——人越多，呼吸越响。玩家要能听出「这是我养的」。
- 起拍的第一下必须**比玩家预期的更响**。响到他会不自觉地把音量调小，然后再调回来。
- 起拍失败必须**不羞辱玩家**。灯不亮，但音乐继续，只是薄了一层。你要能爬起来。

**风险二：一束灯，可能不够玩。**

幸存者的深度来自「一边跑一边躲一边升级」。这里多了一个「控灯」，但如果灯只是一个「切换目标」的按钮，玩两局就腻了。

**必须成立的前提：**
- 灯必须**有物理**：有惯性、有延迟、有拉丝、有光斑边缘。它得像一件乐器，不像一个光标。
- 灯的三个用法（照怪、照队友、照地面）必须互相冲突。你永远在放弃某一边。
- 观众必须**会反噬**。你养的东西最后会爬上台。否则「养观众」就只是「攒经验」。

**风险三：它可能太安静了。**

这个游戏最好的时刻是安静的，但幸存者玩家要的是「爽」。

**必须成立的前提：**
- 副歌必须真的吵。吵到玩家想站起来。
- 转化观众的那一下必须有「啪」的实感：一道光、一个音、一个人坐下。
- 歌单必须在 30 秒内让人听懂：你加的那一小节，真的出现在歌里了。
