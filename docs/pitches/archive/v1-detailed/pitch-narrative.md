# 《Girls Band Live：不齐》

> 作者：planner-narrative ｜ 一句话卖点：三个从来不合拍的人，被噪音逼成一个拍子。
> 字数：约 1,790 中文字（不含表格）

## 1. 核心循环

玩家从祁铃、苏弦、小满里选一人上场，在 Livehouse 守一场十分钟、票还没卖完的首秀；另外两人站在台上当乐手——不是背景板，是三个可拉近也可推远的关系槽。核心动词是**「合拍」**：一边躲怪潮，一边把三个人的拍子拧到同一个方向。

拧法很具体：用谁的乐器打中敌人，谁的「同频槽」就涨；满了，她下场替你打十秒；三个都满，灯下发生一次**三重奏**，全屏清场、音乐加到第五层。冷落谁太久，她就停下手里的声音：BPM 掉下去，舞台变暗，敌人变慢。

于是每局都在两难里：**抢拍**换收益，还是**保拍**换性命，以及要不要回头救那个被你冷落的人。

**三条缝，三根线。**铃与苏弦争"这首歌听谁的"：一个要唱给台下，一个要唱对和弦。苏弦与小满争"按谱还是凭感觉"：小满一次即兴加花，毁了苏弦唯一一次重要试音。铃与小满争"要不要逞强"：铃受伤从不说，小满不用嘴问，只靠鼓点听出来。缝住它们的是三件小事：苏弦是唯一听过铃独唱的人；小满每天在苏弦琴盒里放一个甜甜圈；铃只在鼓点慢下来时才肯承认疼。

## 4. 敌人与 Boss

**噪音**是城市里所有"听不见你"的东西：它们不恨音乐，只是把音乐磨平。敌人一律**去色**，让台上三个女孩成为画面里唯一的颜色。

| 名称 | 行为 | 威胁 | 视觉一句话 |
| --- | --- | --- | --- |
| 沙沙虫 | 直线爬行、成群涌来 | 数量压制 | 灰白短圆柱 + 两片抖动的纸片 |
| 失真蛛 | 跳跃突进，起跳前抖 0.4 秒 | 预判失误掉半管血 | 八条歪扭的线材腿 |
| 回授犬 | 追踪绕圈，速度随 BPM 提高 | 逼你放弃站桩 | 细长四足，头顶旋转的喇叭 |
| 跑调合唱团 | 五只一组，互相加护盾 | 必须整组击杀 | 五只并排的扁圆锥，张着嘴 |
| 低音炮 | 远程发射慢速冲击波 | 封走位 | 黑色圆球 + 橙色橡胶边 |
| 节拍盗 | 命中你时偷走 6 点 BPM | 悄悄拖垮节奏 | 瘦长人形，握着节拍器指针 |
| 混响傀儡 | 复制你上一把武器的招式 | 用你的声音打你 | 半透明人形，模仿你的动作 |
| 静音者（精英） | 展开 3 秒静音领域，领域内音乐层关闭、血条不可见 | 强迫走位 | 黑雨衣的高个子，没有脸，头顶"-∞" |

**Boss：静默制作人**（9:00 登场）。它从不出声，只用推子，把所有声音调成平均值。一阶段**调音**：全场灯灭，只留一束追光，四道音墙交替推来，打掉场边"推子"可停音墙十秒。二阶段**静音**：BPM 归零、音乐全停，只剩心跳，它用混响傀儡复制你的武器，你只能靠屏幕边缘的心跳判断来敌。三阶段**压制**：BPM 拉满 180，全屏敌人一起冲，弱点只在**合奏状态下**显形——关系系统是胜利条件，不是装饰。10:00 未击杀则狂暴，12:00 硬结算。

## 6. 升级、构筑与元进度

升级三选一，卡池三类：**武器卡**、**被动卡**（8 选 4：失真、推子、节拍器、混响、采样器、舞台烟雾、耳返、观众）、**共鸣卡**（只加某位成员的同频槽并播一句台词）。武器 4 把、被动 4 个；满级加指定被动后，下一次升级必出金色进化卡。

三条路线：**低音压场**（地脉低音 + 一束，泡减速区）、**高频爆发**（撕裂和弦 + 暴走节拍，BPM 140 后滚雪球）、**场地控制**（把怪引进灯里）。

**分歧事件**是唯一的剧情机制：5:00 三人吵起来，苏弦要按谱收工，铃要加演唱第三段，小满只敲了一个三连。二选一——「按她的谱」让后四分钟更密更快；「唱完它」让敌人更少但更强、苏弦沉默一整段。它不改结局，只改这一局的性格。

元进度 P0 只存 `gbl.save.v1`：设置、最佳记录与静音；解锁留到 P1。

## 7. 舞台、灯光与音乐如何改变玩法

音乐在这里是一张**全局参数表**：BPM 只驱动四个变量——敌人移速、技能冷却缩放、掉落量、音乐层厚度；限速 ±8/秒。四层音乐各有主人：鼓属于小满、贝斯属于苏弦、和弦属于合奏、主旋律属于铃。**谁倒下，那一层就被压掉**（低通 + 音量降到 20%）；三个人都在拍上时五层齐奏。

灯光同样是信息：追光咬住最高威胁，灯架颜色对应谁的同频槽已满，舞台边缘的 LED 条就是 BPM 节拍器——不看 HUD 也知道自己在不在拍子上。

## 8. 美术与音频方向

视觉关键词：**低多边形、霓虹纸片、廉价烟雾机**。夜蓝底 `#101A2E`，成员色铃=洋红 `#FF3E8A`、苏弦=青蓝 `#35D0E0`、小满=琥珀 `#FFB03A`；敌人一律去色，只在受击瞬间闪一次成员色。舞台是俯视 3/4 的 Livehouse：程序化棋盘地胶、四个灯架、观众是剪影。角色用球头加锥裙加乐器方块拼，靠轮廓与配色区分。UI 走**调音台语言**：推子、旋钮、VU 表、磁带进度条。

音频关键词：**车库流行，干净的鼓、脏一点的吉他**。全部 WebAudio 合成，BPM 由游戏状态驱动而非定时器；命中按武器分音高、升级用琶音、Encore 触发全场混响、成员倒地时那一层"掉针"。零外部素材。

## 9. MVP 范围

**必须做（P0）**：3 名成员（攻击 / 被动 / Encore / 台词 / 配色）；6 武器各 5 级加 6 进化；8 敌人加三阶段 Boss；同频槽、合奏、救场（被击倒后 15 秒内按住 E 拉起来，否则她那一层音乐整局熄灭）、一次分歧事件；BPM 四参数系统；4 层音乐与倒地压制；全套 UI；存档；键鼠加触屏；单文件离线。

**砍掉**：① 分支剧情与多结局——每多一个分支，卡池与波次表就翻倍；② 心结三格槽——用"同频槽空置 45 秒"触发唯一分歧事件代替；③ 成员完整 AI——降为合奏窗口内的跟随加自动攻击，不做寻路；④ 观众情绪条——砍成纯视觉；⑤ 立绘、过场、配音——P2；⑥ 角色与武器解锁——P1。

## 11. 为什么必须是少女乐队

因为核心动词是**合拍**，而合拍至少需要三个人。换成孤胆英雄，同频槽没有对象，救场没有成本，分歧无从谈起。换成男团，就是偶像企划，廉价烟雾机和甜甜圈都没了。换成任何别的题材，"用彼此的声音把对方拉回拍子上"都不成立。

更关键的是：BPM 作为全局参数，只有在台上有个鼓手、且她愿意为你放慢时才成立——这不是设定，是机制。敌人是噪音，是所有不被听见的声音；只有还在唱的人能反驳它们。

## 12. 与 P0 基线的对照

- **3 角色**：祁铃 / 苏弦 / 小满，各带攻击、被动、Encore、配色与台词，差异一句话可说出（爆发 / 场控 / 节奏）。
- **6 武器 + 6 进化**：断线、低频炮、双踩、回声、波形、一束，各 5 级、各 1 进化，条件为满级加指定被动。
- **8 敌人 + 1 Boss**：8 类噪音（含精英静音者）加静默制作人三阶段。
- **1 舞台 / 3 阶段**：同一张 Livehouse 靠灯光、观众剪影与地板颜色切换开场 / 升温 / 高潮。
- **10 分钟**：0–2 排练、2–5 试音、5–9 升温、9–10 Boss；10:00 狂暴，12:00 硬结算。
- **三选一 / Encore / 键鼠加触屏 / React + TS + Three.js 离线单文件**：全保留；Encore 绑 Space 与屏幕按钮。
- **未覆盖项**：无。关系系统（同频 / 合奏 / 救场 / 分歧）在 P0 内实现，不新增依赖与素材。
