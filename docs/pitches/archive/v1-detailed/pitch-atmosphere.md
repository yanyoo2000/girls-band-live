# 《追光安可》 / Spotlight Encore

> 作者：planner-atmosphere ｜ 一句话卖点：把追光灯当武器，踩准节拍点燃观众，在灯灭前唱完最后一首。
> 字数：约 1 660 中文字（不含表格）

## 1. 核心循环

你在 Livehouse 的舞台上**守住一场演出**：武器按乐句自己开火，灯光按小节扫过地面，你要做的只有三件同时发生的事——走位、踩拍、选光。踩拍击杀把观众热度（Hype）顶上去，热度换来更密的怪、更快的成长和更厚的编曲；站进追光能打得更痛，也会把精英怪引到身边。每 8 小节一个乐句，音乐提前一小节用加花预告副歌，副歌一到，怪潮按拍点成组涌出。HP 归零就是「演出中断」，结算三秒后可直接重开；一局只有一条命、一次构筑、一首歌，值得认真打完。

## 2. 三名乐队成员

一支叫「薄荷余震」的三人乐队，一台灯、三件乐器，就是全部家当。

| 名字 | 乐器/定位 | 性格 | 基础攻击 | 被动 | Encore 大招 | 战斗角色 |
| --- | --- | --- | --- | --- | --- | --- |
| 岑霓 | 主唱 / 立式麦克风 | 明亮莽撞，把每场演出当最后一场 | 前方音波扇形，贴身更痛 | 「追光体质」：光中伤害 +30%，同时更容易被精英锁定 | 「最后一句」：全场灯灭 1.2 秒，敌人失去目标；灯亮瞬间对光中敌人爆发伤害 | 以身入光的近战核心 |
| 陶祺 | 鼓手 | 冷静毒舌的节拍警察，用鼓点算账 | 鼓槌节拍拳，每 4 拍一次范围重音 | 「节拍层」：连续踩拍命中叠层（最多 5），每层攻速 +6%、移速 +3% | 「过门」：双倍 BPM 打出 12 连鼓浪，前方锥形击退 | 滚雪球加速与控场 |
| 苏曳 | 贝斯 / 合成器 | 慢性子、冷幽默，总站在舞台边上 | 低频环扩散，命中减速 | 「低频共振」：受减速敌人额外承受 10% 伤害 | 「次声海啸」：8 米环形低频墙，推开并眩晕 1.5 秒 | 保命、清场、新手友好 |

三人共用同一套舞台规则，但「怎么用光」完全不同：岑霓往光里冲，陶祺把光当节拍器，苏曳在光外面收场。

## 4. 敌人与 Boss

全世界的怪物只有一种名字：噪音。它们统一「怕光」——在光束里会被灼烧并减速 20%，这让灯光成为真正的地形。

| 噪音 | 行为 | 威胁 | 视觉一句话 |
| --- | --- | --- | --- |
| 杂音爬虫 | 直线追人，成群 | 数量压位 | 白色六边小虫，身上噪点闪 |
| 回授尖啸 | 停在 6 米外放扇形音波 | 打断走位、逼你换线 | 细长菱形，边缘一圈洋红 |
| 哑音海绵 | 走向最近灯座，掐灭 6 秒 | 拆掉你的光地形 | 多孔方块，吃到光就变灰 |
| 拍手虫群 | 只在拍点上跳一步，强拍冲刺 | 节奏式围攻，读拍可躲 | 4–6 只小手，同步跳 |
| 低音假面（精英） | 低频冲击推人，护盾减伤 50% | 只有小节第一拍能打碎护盾 | 大音箱脑袋，胸口低频膜 |
| 回声双子 | 成对行动，死一只另一只狂暴 | 逼你同时处理两个方向 | 镜像半透明，一明一暗 |
| 追光蛾 | 飞向最亮的灯，撞灯造成爆伤 | 同时威胁你和灯 | 白蛾，翅膀是两片发光面 |
| 线缆缠绕者 | 沿途留下减速线缆区 | 压缩走位空间 | 细长蛇形，尾巴拖线缆 |

Boss 是「静默制作人」：他从头到尾不说一句话，只用指挥棒和调音台关掉你的声音。**阶段 1「数拍」**（9:00–9:25）：他站在调音台上，每小节第一拍落一次静音脉冲、熄灭一束光；他只在小节第一拍受到双倍伤害，其余时间减伤，逼你把输出压到强拍上。**阶段 2「消音」**（9:25–9:45）：全场只剩一束追光，离开光 4 秒开始持续掉血；他召唤哑音海绵去掐灭这最后一束光，你必须边打边救灯。**阶段 3「反拍」**（9:45–10:00）：音乐切 half-time，他进入狂暴，观众灯海全亮，最后 8 小节你的伤害翻倍、Encore 不限次数——集火终结，灯全开的瞬间结算。

## 6. 升级、构筑与元进度

升级三选一从四类池里抽：新武器、武器升级、新被动、被动升级；进化卡在满级且持有对应被动时才进池，7:00 后提高权重，保证每局至少一次成型高光。三条路线各自成立：**光核近战**（岑霓 + 破音吉他 + 追光灯控台 + 耳机/踏板）、**节拍滚雪球**（陶祺 + 镲片飞轮 + 琶音阶梯 + 节拍器/音序器）、**低频控场**（苏曳 + 低频脉冲 + 尖啸麦克风 + 音箱/调光器）。元进度只写 `gbl.save.v1`：设置与最佳记录（最长存活、最高 Hype、最高击杀），P0 不做解锁。

## 7. 舞台、灯光与音乐如何改变玩法

**音乐在本作里是时钟，不是氛围。**一个 conductor 同时喂音频与逻辑：128 BPM、4/4、8 小节一乐句，`beat` 事件带 `bar/beat/phrase` 三个下标；刷怪、开火、Boss 阶段、灯光换色全部取整到 16 分音符格。永远不会出现「音乐在唱、怪在乱」。

**Hype 是玩家自己拧的难度旋钮。**踩拍命中（±110ms）涨 Hype，脱拍命中不涨；Hype 四段各改四个数：刷怪密度、经验倍率、灯海亮度、编曲层数（鼓/贝斯→和弦→主旋律→观众合唱）。Hype 过 60，下一个小节线进入 8 小节副歌：怪按拍点成组刷出，音乐提前一小节用加花预告——**玩家用耳朵预判危险**。

**光是地形，也是仇恨。**场地常驻 3 束扫动追光：金色伤害 +30%，青色移速与冷却，洋红经验与 Hype。光里敌人被灼烧减速，但精英与追光蛾会被最亮的灯吸引——进光等于加火力也加仇恨。哑音海绵走到灯座前把光掐灭 6 秒；三束全灭触发「静音」：15 秒内伤害 -30%、刷怪 +50%，直到灯自动复明。于是每个小节都有一次小决策：留在哪束光里、要不要回头救灯。

Encore 也吃同一个拍点：踩中拍子释放，增益 +40%；没踩中照常放，只是少这口增益。节拍必须看得见：地板网格按拍脉冲、HUD 有拍点条、Encore 按钮有充能环；另有「辅助节拍」自动对齐最近拍点。闪烁只做在四分音符（2.13Hz）上，绝不走 8/16 分，满足无 3Hz 以上闪烁。

| 表现目标 | Three.js 实现 | 预算 / 降级 |
| --- | --- | --- |
| 地板按拍脉冲 | 程序化 CanvasTexture 网格贴 `MeshStandardMaterial`，用 `onBeforeCompile` 注入共享 `uBeatPhase`；所有脉冲材质引用同一 uniforms 对象，每帧只写一个 float | 1 draw call；低画质关脉冲，只留 HUD 拍点条 |
| 可见光柱 | `ConeGeometry(1.6, 9, 12, 1, true)` + 自写加法混合 `ShaderMaterial`（底亮顶淡、径向 alpha、`depthWrite:false`）；3–6 束合一 `InstancedMesh` 并挂实例属性 `aIntensity`，灭灯就是把它降到 0 | 1 draw call；低画质只留 2 束 |
| 真实照明 | 仅 3 个 `SpotLight`（`shadow=false`、`penumbra=0.6`）跟随光柱底；判定复用同一份 `{center, radius, color}`，保证「看到的光=吃得到的增益」 | 3 个实时灯；低画质降到 1 个 + 环境光补 |
| 灯架灯泡阵列 | 约 40 个 `IcosahedronGeometry(0.12, 0)` 实例 + `MeshBasicMaterial`，只在 `beat` 事件里按 pattern 改 `instanceColor`（约每秒 9 次） | 1 draw call；低画质减到 16 个 |
| 观众灯海 | 约 180 个合并的极简小人 `InstancedMesh`（≤60 面/个）+ 荧光棒 `InstancedMesh`；矩阵按 ≤10Hz 的 sin 摆动更新，Hype 换段时改 `instanceColor` 与摆幅 | 2 draw call；低画质 80 人 |
| 敌人与受击 | 每种敌人一个 `InstancedMesh`（8 个 draw call），`setMatrixAt` 写位置朝向；受击闪白只改 `instanceColor`，限 60 次/帧 | 8 draw call；实例硬上限 250 |
| 节拍粒子 / 纸屑 / 爆点 | 单个 `Points` 池（1200 粒）+ `ShaderMaterial`，用 `gl_PointCoord` 画软圆点（零贴图），属性 `life/vel/size` | 1 draw call；低画质 600 粒、关纸屑 |
| 屏幕反馈 | 屏震只偏相机；闪光用一层 CSS 叠加 div（React 事件驱动）或一张加法混合全屏面片 | 不增 Three draw call；减少动态时全关 |
| 角色与乐器 | 每名成员 ≤7 个低模网格（头/发/身/裙/腿/乐器/背带），静态件 `mergeGeometries` 合并成 1–2 个，脚下加成员色 `Torus` | 三角色合计 ≤12 draw call |
| 后处理 | 不做 Bloom：靠加法面片、`emissive` 材质与 CSS 光晕模拟辉光 | 省掉整条后处理链，是 60fps 的关键取舍 |

## 8. 美术与音频方向

视觉关键词：霓虹黑胶、雾、荧光粉/电光青/琥珀金、低多边形剪影、灯比人多。角色辨识靠「一色一乐器一轮廓」：长杆麦克风、双镲、斜挂贝斯，远看也能分开。UI 像调音台：HUD 是推子与拍点条，升级卡是 setlist 卡片。音频全部 WebAudio 合成：4 层编曲 + 观众层，8 个关键 SFX（命中、踩拍命中、升级、进化、Encore、灭灯、Boss 阶段、结算）；网格、雾、噪点贴图一律 CanvasTexture 现画，零外部素材。

## 9. MVP 范围

必须做（P0）：conductor 与武器 pattern、踩拍判定与辅助节拍、Hype 四段与副歌触发、3 束光地形与灭灯惩罚、3 角色/6 武器/6 进化/6 被动/4+4 槽、8 敌人 + Boss 三阶段、单舞台三阶段灯光、4 层音乐与 8 个 SFX、拍点 HUD 与结算、键鼠/触屏、暂停与失焦、减少动态、`gbl.save.v1`。

明确砍掉：多舞台与巡演（一张舞台足够，多场景只是复制工作量）；多首曲目与选曲（一首 8 小节循环 + 编曲变奏，多首会撕裂节拍实现）；角色/武器解锁（P1，P0 全开更利于评审与新手）；商店与局外养成（与 10 分钟一局冲突）；剧情播片与羁绊事件（P2，用 3 句台词和结算卡承担）；Bloom 与动态阴影（吃掉一半性能预算）；长按与滑键音游判定（只保留 Encore 踩拍与命中踩拍加成）。

## 10. 风险与对策

| 风险 | 概率 | 影响 | 对策 |
| --- | --- | --- | --- |
| 节拍与音频漂移，手感崩 | 中 | 高 | 音频 lookahead 调度 + 单一 conductor；逻辑消费 `beat` 事件而非自己数时间；窗口 ±110ms；失焦即暂停；AudioContext 不可用时退化为纯视觉节拍 |
| 光柱 + 粒子 + 观众导致掉帧 | 中 | 高 | 假光柱（实例化加法面片）+ 仅 3 个真实 SpotLight + 无 Bloom；观众 ≤10Hz；InstancedMesh 与对象池；低画质逐项降级 |
| 踩拍门槛劝退休闲与静音玩家 | 高 | 中 | 踩拍只是加成不是门槛；可视化拍点；辅助节拍自动对齐；Hype 也随击杀缓慢累积 |
| 灯光与特效应接不暇，战场不可读 | 中 | 高 | 敌人统一深剪影 + 亮边；光柱 alpha ≤0.25 不挡视线；高亮粒子不加在敌人头顶；飘字限条数；减少动态开关一键降噪 |
| 三套系统叠加导致做不完 | 中 | 高 | 优先级：节拍 > Hype > 光束地形；光束可退化为「3 束常亮 + 精英追光」；每系统预留降级方案，M5 前只做 P0 |
| 原创与合规（旋律、造型、命名撞车） | 低 | 高 | 旋律用自定音阶 + 固定动机程序化生成；角色造型取自几何体与灯光语言；发布前发行经理逐项复核 |
| 零素材下单文件氛围不足 | 中 | 中 | 一份共享 shader + 一套 CanvasTexture 工具箱集中在 `three/fx.ts`；靠色彩、光、剪影三件事撑氛围 |

## 11. 为什么必须是少女乐队

追光、观众、安可、合唱，以及「静默」这个敌人，只有在演出里才成立。舞台天生是一个「被看见」的地方，而噪音要做的正是让你不被看见：它灭灯、消音、掐掉你的声音——这是表演者独有的恐惧，换成机甲或骑士，敌人就只剩「打你」这一种语言。Hype 不是连杀值，是观众的反应；武器不是枪，是乐器和灯控台；失败也不是死亡，是演出中断。三名成员的关系也长在这套语言上：只在音乐地标（副歌、进化、Boss 阶段）各说一句台词，且与各自战斗方式一致。去掉音乐与灯光，这个方案会立刻退化成一款普通的割草游戏，这正是它必须是乐队的原因。
