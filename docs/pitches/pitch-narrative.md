# 《不散场》 / LAST SET

> 「所有幸存者游戏都在问你能杀多少。这个游戏问你：你能听见多少？」

**一句话**：今晚是「空耳」的最后一场演出；怪潮从台下涌上来，你只有一首歌的时间，把四个已经决定离开的人，一个一个听回来。

**类型**：少女乐队 × 幸存者 · 桌面键鼠 · React + TypeScript + Three.js · 一局 = 一首歌，约 12 分钟

---

## 那个瞬间

第二首歌，第二次副歌。

你正把「回授」往台口推。屏幕右下角是混音台——五个推子，五个人的声音。这里没有队友血条，因为队友不掉血。你只是余光扫到：

**沅的推子，在自己往下走。**

没有警报。没有红色描边。没有"队友即将离队"的提示。她的低频一点一点消失：先是脚底发麻的感觉没了，然后军鼓变得很干，吉他突然悬在半空。你回头。她还在弹，只是手指越来越轻，眼睛看着后台那扇门。背带上挂着一张末班车的票根。

那一刻你才明白：她不是被打倒的。她是在把自己调小。

你可以继续打。台口的杂音正厚，连杀数在涨，下一段副歌马上到。你也可以现在转身，穿过整个舞台，按住 `Space`，在她把最后一个音弹完之前，听她弹完那段从来没弹给别人听的旋律——然后用走路，把那句旋律走一遍，还给她。

如果你不回头：下一段副歌没有贝斯。铁会用底鼓去补那条根音，一遍一遍，像有人在黑暗里替你数拍子。歌还在，但你会一直听见那个洞。

**画面**：五个推子，其中一个在自己往下滑；舞台灯是四个人的颜色，蓝色那一盏先暗了半格。
**声音**：低频消失的一瞬间，整首歌像被抽掉地板；你第一次听清军鼓弹簧在响。
**操作**：你按住唯一的主动键「听」，攻击停止，世界降速到 40%，地板亮成五线谱——她的旋律是一条路，你得走上去。
**情绪**：不是"队友濒死"，是"她已经在告别，而你差点没看见"。

整个游戏的设计，就是为了让这个瞬间成立。

## 这台戏是什么

「空耳」是一支成立了三年、换过九个成员的地下乐队。你是第九个，编号**玖**，加入第十四天，第四把吉他。她们不太记新人的名字，只给编号，因为人总在换。如果今晚足够好，也许会有人第一次叫你的名字。

今晚是她们在「底噪」Livehouse 的最后一场。明早，钥匙要还给房东。墙上的钟指向 21:47，场地方的租约写到 22:00。这十二分钟，就是你们剩下的全部时间。

台下的人不知道这是最后一场。台上的四个人知道。她们各自决定了要离开，但没有人打算在演出中间宣布。**她们只会用各自的方式，把自己一点一点调小。**

**怪潮不是来杀你的，是来让你听不见她们的。** 从台口、侧幕、后台门涌上来的「杂音」——回授、已读、账单、亲戚的语音、末班车、别人家的孩子、"你们这样能当饭吃吗"——它们打你，也吵你。你的任务不是消灭它们，是在这片噪音里，把一首歌完整地弹完。

你留不住任何人。你只来得及听完她们，然后把最后一个和弦弹完。

你加入第十四天，你还没有资格说"别走"。你只有资格听。

**这不是一个关于"永远在一起"的游戏。这是一个关于"好好结束"的游戏。**

## 一局的样子

这是幸存者，不是视觉小说：怪潮、经验、升级、重开都在，只是它们长在一首歌上。你每 60 秒都在做三个决定——往哪走、站在谁旁边、什么时候停下来听。

一局 = 一首完整的歌，七个段落。每个段落有一个人的心事、一种新的杂音、一次"听"的机会。

| 段落 | 焦点 | 台上发生什么 | 你要做的事 |
|---|---|---|---|
| 试音 | 教学 | 四个人各弹一个音，你跟着弹；台下还在进场 | 认识四种音色和四个推子 |
| 《底噪》 | 沅 / 贝斯 | 台口第一次被撞开；她的根音开始变简单 | 第一次「听」：走她写的旋律 |
| 《把耳朵借你》 | 灯 / 主唱 | 副歌的高音上不去；麦克风越拿越远 | 替她把那个音顶上去 |
| 《十四天》 | 铁 / 鼓 | 鼓独奏；杂音最密；她开始抢拍 | 停手，陪她数完八小节 |
| 《今晚不关灯》 | 纱 / 键盘 | 她弹错一个音，反复弹；手机反扣着一直亮 | 把她的错音留下来 |
| 终曲《不散场》 | 所有人 | 「谢幕」来了：巨大的幕布和一群礼貌的引导员；它们不攻击你，只是把你往台下请 | 在最吵的时候把副歌顶住 |
| 22:00 断电 | 观众 | 场地方拉闸。放大器全死，杂音也死了。只剩台下的人 | 用拍手把最后一段接下去 |

**名场面 · 替她唱**

灯的嗓子坏了。医生让她一年别唱，她谁也没说，只是把每首歌都降了半个调。副歌第二次，她把麦克风从嘴边拿开一寸——不是换气，是身体先知道的退让。高音没有出来。前排有人笑了一声。你把琴推到最高把位，推弦，把那个音顶上去。长按。你听见自己手指摩擦琴弦的声音，比那个音还响。她愣住了，回头看你，然后把麦克风重新举起来——她没有唱那个高音，她唱了低三度的和声。你的琴在她的声音下面，替她唱完了她唱不上去的半句。

**从那以后，每一遍副歌，那个音都是你的。她再也没碰过它。**

如果你没接住：她把麦克风放回架子上，像放下一件太重的东西。后面的歌变成纯器乐。台下开始替她唱——很多人其实不会词，只是哼。全场一起哼错，居然比原版好听。

**名场面 · 断电**

22:00，场地方拉闸。灯全灭，音箱全死，杂音也跟着死了——它们本来就是电。黑暗里只剩观众。有人开始拍手：一下，两下，四拍。整个场子跟着数。你们在黑暗里，用拍手把最后一段弹完。

**名场面 · 补位**

如果沅走了，下一段没有贝斯。铁会用底鼓去踩那条根音，踩着踩着，鼓手变成了贝斯手，节奏又笨又烫。如果灯走了，纱会在高音区替她唱，唱得很小心，像怕碰碎什么。**缺一个人之后，另一个人会长出她的声部。** 这不是补偿，这是乐队。

（对了，底噪有一只店猫叫**推子**。它会在第三段跳上键盘，踩出一串音。如果刚好踩在拍子上，全场会欢呼。它不参与叙事，它只是提醒你：这还是个好玩的地方。）

## 系统：关系就是编曲

**1. 队友没有血条，只有推子。**
HUD 是一个混音台。五个通道：灯（人声 · 玫红）、沅（贝斯 · 深蓝）、铁（鼓 · 琥珀）、纱（键盘 · 薄荷）、玖（吉他 · 白）。她们的状态不显示为 HP，而是显示为电平：走神时音量会自己往下掉，生气时会爆表，撒谎时会有细小的毛刺。**她们不会喊你。她们只会把自己调小。** 你要学会看推子——不是看血条。

```
灯  ▮▮▮▮▮▮▯▯
沅  ▮▮▮▯▯▯▯▯   ← 没有敌人在打她
铁  ▮▮▮▮▮▮▮▯
纱  ▮▮▮▮▮▮▯▯
玖  ▮▮▮▮▮▮▮▯
```

**2. 你的自动攻击是弹琴，你的走位是编曲。**
你的琴自动扫弦，音色和节奏由脚下的效果器决定（失真、延迟、合唱、八度……）。但真正决定强弱的，是你离谁更近：站在铁的鼓旁边，你的攻速跟着军鼓走；站在沅的低频里，你的击退变强；纱的键盘给你护盾；灯的声音让你的和弦多一个泛音。**靠近队友是最强的，也是台口最危险的地方。** 这是幸存者类最基本的贪与怕，只不过这一次，贪的是"在一起"。

```
        后台门 —— 她们可以从这里走
   ┌─────────────────────────┐
   │ 铁(鼓)          纱(键盘) │
   │        灯(主唱)          │
   │ 沅(贝斯)      玖(你)     │
   └────────── 台口 ──────────┘
              ↑ 杂音从这里爬上来
   ░░░░░░ 观众 / 人浪 / 手机的光 ░░░░░░
```

**3. 战斗的手感：你不是在清屏，你是在把歌推向它该去的地方。**
鼓点就是你的节拍器；每一次副歌，灯把麦克风指向观众，全场的声音变成一道横着推过来的墙，把杂音压回台口。你打得越准，编曲越满；编曲越满，怪越疯。**这首歌会因为你的杀敌数变得更复杂**——但太复杂的时候，你会听不清队友在说什么。

**4. 升级不是选属性，是选"这一段谁做主旋律"。**
每段之间没有菜单，只有一次短短的对看：四个人看着你，等你决定这一段谁做主旋律。你推动一个推子。她亮起来，她的攻击变强，她的推子被你推高——另外三个人的推子会悄悄低一格。**你的 build 就是你的关系。** 你把升级全给了主唱，就别怪贝斯手在下一段走。

**5. 主动技只有一个：「听」。**
按住 `Space`：你停止攻击，世界降到 40% 速度，所有杂音被压成一条底噪。她的旋律出现在地板上——舞台变成一张五线谱，音符是发光的地标。**你用走路把她的旋律走一遍。走完，就是回答。** 走错，那个错音会留在编曲里，变成下一段的动机。你不能既听她又打她；听，就是把自己交出去。

**6. 四种关系，四种语法。**
不是每段关系都用同一套对话。灯需要你**替她唱**（长按，把那个音顶住）；沅需要你**跟她走**（走完她的旋律）；铁需要你**陪她数**（八小节不插手，第一拍准时回来）；纱需要你**陪她错**（踩在错音上别动，等它变成一个和弦）。你学会的不是四个选项，是四种听法。

**7. 失败不是死，是散场。**
体力归零，不会出现"你死了"。会出现的是：场灯亮起，观众开始收拾东西，有人上来拔掉你的线。结算页是一张被划掉的歌单。如果人走了歌还在，那是另一种失败——你会带着一个洞把歌弹完。**没有"正确"的结局，只有"说出口"和"没说出口"。**

## 为什么必须是少女乐队，不是别的皮

因为"乐队"本来就是一种**把四个人的私心调成一个声音**的技术。排练室里所有没说出口的话，最后都会跑到编曲里：谁的声音被推高，谁的段落被砍掉，谁在副歌里偷偷加了一个花。这个游戏只是把这件本来就在发生的事，做成了能被听见的机制。

因为"最后一场"是乐队故事里最真实的时刻。不是打败魔王，不是拯救世界，是明早钥匙要还，末班车要赶，有人要去念书，有人要去做幕后，有人只是唱不动了。**长大不是解散，长大是学会好好散场。**

还因为「空耳」这个名字。它本来指"听错"。最后一晚，台下的人跟着唱，唱错了词，没有人纠正。你站在台上想：**被听错，也是一种被听见。**

## 它把幸存者推到了哪里

- 从"你能杀多少"到"你能听见多少"。怪潮的功能不是消耗你的血，是消耗你的注意力——这是幸存者类里最稀缺、却几乎没人拿来当资源的货币。
- 从"队友是武器"到"队友是声部"。失去她不是掉一个 buff，是歌少了一条腿；你会在耳朵里失去她，而不只是在数值上。
- 从"安全区里的对话"到"炮火下的真话"。所有心事都发生在你最忙、血最少、怪最多的时候；想听，就得停手。**叙事的代价第一次和操作的代价是同一件事。**
- 从"失败=重开"到"失败=另一种编曲"。人走了，剩下的人补位，歌变形，局继续。失败长出内容，而不是抹掉内容。
- 从"升级=变强"到"升级=把话筒给谁"。你的构筑就是你的关系；你的偏爱会被听见。
- 从"舞台是背景"到"舞台是一条防线"。台口是你要守住的那条线，观众在台下，噪音从台下爬上来。
- 二周目不靠变强，靠**知道**。第二遍你会记得沅的旋律、灯的换气口、铁抢拍前的小动作。游戏没有给你新数值，是你变成了一个会听的人。

## 我愿意冒的险

**我赌"停下来听"比"再多杀一百个"更爽。**
在一个以杀戮密度为爽点的类型里，我要求玩家主动放弃输出、放弃走位，把角色交给一段旋律。这要么是整个类型最动人的一次呼吸，要么是最烦人的一次打断。我认为前者概率更大——因为人真正记得的从来不是杀敌数，是"那一次我停下来，听见了什么"。

**我赌玩家愿意接受"救不回来"。**
不是所有关系都能修好。有人就是要在今晚离开，你能做的只是让她把话说完。没有"全员存活"的真结局；最好的结局是四个人都站在台上，把最后一个音弹完，然后各自走下台。这需要玩家放下"通关"的执念——但这也是这个题材真正值得做的地方。

**我赌"缺声"比"掉血"更疼。**
我们没有做队友血条，因为血条会让玩家去救数值；推子会让玩家去救**声音**。当低频消失的时候，玩家不需要任何文字提示，就知道自己失去了什么。这是音频叙事最便宜、也最狠的一张牌。

**我赌"错音"可以变成内容。**
走错一个音，它不会消失，会留在编曲里，成为下一段的动机。没有"重来一次弹对"，只有"带着这个错继续弹"。这是我对音乐游戏最大的反叛：**这里没有错误的音符，只有不同的编曲。**

## 最大的风险 / 必须成立的前提

1. **音乐必须真的好听，而且"缺一块"真的会疼。**
   整个设计押在程序化音频上。如果合成出来只是一个能听的循环，推子往下滑就只是 UI 动画。必须先做一首 90 秒的垂直切片：五轨、可增减、可变形，然后找十个人听"少一轨"的版本，看他们会不会皱眉。**这是项目的生死线，不是打磨项。**

2. **"听"必须立刻给回报。**
   玩家在最忙的时候停手，如果只换来一段文本，他会骂人。听的价值必须是操作性的：一次合奏清场、一个新声部、一个只有你们两个人能打的段子。故事是奖励，但首先是武器。

3. **十分钟内让人在乎四个人。**
   没有过场、没有配音、没有设定集。只能靠：一个降调、一张票根、一次抢拍、一个反扣的手机。每一句台词都要能被动作替代，每一个动作都要能被听见。

4. **"走人"不能随机，也不能纯脚本。**
   她走之前，推子必须先动；玩家必须有至少一次可以干预的窗口；干预失败也必须产生新的东西。她要像一个人，而不是一个计时器。

5. **走路听旋律必须一眼就懂。**
   地板上出现一条发光的谱线，玩家要在三秒内明白"踩上去、跟着走"。如果玩家第一次看不懂，这个游戏最核心的时刻就没了。教学必须放在试音段，用最安全的方式教会。

6. **一首歌要撑住十二分钟。**
   靠段落、动态、密度和音色变化，不靠堆怪。M3 可以砍到八分钟，但不能砍成"循环播放 + 换皮怪"。

## 如果明天就要做（最小可玩）

- 一张舞台，一个 Livehouse，一首 8–10 分钟的歌，五个声部。
- 四个成员 + 你，每人一套低多边形剪影 + 一种颜色 + 一种乐器。
- 三段"听"：沅的旋律、灯的高音、铁的独奏（纱留到完整版）。
- 两种杂音 + 一个「静音」精英怪（会随机掐掉一个声部，逼你去看推子）。
- 三个效果器升级 + 每段一次的"主旋律给谁"。
- 结局只有两种：断电后把最后一个和弦弹完 / 没弹完就散场。
- 不做：多场地、多首歌、二周目存档、观众个性化、角色换装。**如果只能保一个东西，保"推子"和"听"。**

## 最后

我做这个游戏，不是因为我想看四个女孩哭。
是因为我见过太多乐队在最后一首歌里，谁也没有看谁一眼。

我想做一个游戏，让玩家在怪潮最厚、血最少、最不该停下来的那一刻，按下一个键，然后**停下来，听一个人把话说完**。

然后你发现，你按下去的不是暂停。
是把耳朵，借给了她。
