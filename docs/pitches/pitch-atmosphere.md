# 《满弦》 / TAUT（工作代号）

> **一句话**：凌晨四点半，散场后的 Livehouse 只剩你一个人和一把六根弦的巨型木吉他——冲上台的人从四面八方涌来，你唯一的手段是**弹**：把台下的椅子坐满，把台上的人找回来。

---

## 序 · 现在，你就是那个人

开场没有过场动画。

你睁开眼，头顶那盏没关的顶灯正照着你，声音很轻，像有人在隔壁敷着一层棉花敲东西。你站的地方不是地板——是一把琴。

你低头，能看见木纹，能看见六根从你脚边横穿出去、一直伸到黑暗里的粗弦，能看见那些弦底下的金属品丝，一条一条，像梯子。你脚下这块面板大得像一条街。你往旁边看，几个人影在舞台边缘站着——眼睛是黑的，嘴张着，没有声音。他们不是来伤害你的。他们是**想上台**。

再往外，是一排一排的空椅子。还没开灯。

你的手上有老茧，你的耳朵里有回响。你知道，再过一秒，就要开始弹了。

---

## 一、那个瞬间

> 具体到帧。这一段请用耳朵读。

**出现时间：开场第 2 分 40 秒左右。玩家大概已经散场过两次。**

你已经学会了唯一一件事：**踩住一根弦，弦会凹下去；松开，它会抽回来。**

现在，全场最粗的那根低音弦就在你脚边。你按住 Shift，它被你踩下去，凹成一个 V。低音开始“嗡”——不是响，是**地板在抖**，抖得屏幕边缘发红。你动不了。

那些黑眼睛的人，被这个“凹”吸了过来。一个、三个、十一个……他们撞在弦上，卡住，挣扎，发出细碎的、掉在地上的声音。**每一次撞击，那个“嗡”就厚一层。** 十一个用不同频率在震颤的身体，把一根弦加厚成了一个和弦。

十九个。三十一个。你的手在抖。

**松开。**

- **0.00 秒**：**全屏静音。** 不是变小，是**抽走**。所有声音被一把收干净，你只能听见一声极轻的心跳——一个底鼓，闷在胸腔里。
- **0.15 秒**：弦抽回来。“嘣”的不是一个音，是**三十一个音在同一瞬间一起松开**。一堵由三十一个身体组成的和声，正面拍在你脸上。镜头震十二度，画面裂出红蓝色差。
- **0.30 秒**：三十一个人被这根弦抛到半空。在半空中，**他们身上的颜色回来了**——从灰白，一个一个变成彩色的，像有人挨个把他们拧亮。他们的嘴闭上了。
- **1.10 秒**：他们落地。没有尸体。他们转过身，走向台下，找到位置，坐下，开始鼓掌。
- **1.20 秒**：你抬起头，才第一次往台下看——那里已经坐了四百个人。而且开始有人喊你的名字。

**这一秒的全部情绪，是一句话：**

> “原来我不是在杀他们。我是在让他们**听见**。”

从这一秒开始，玩家会换一种玩法。他会开始在意人群的形状，会开始在松手前数人数，会因为舍不得而多踩半拍——而**多踩的那半拍，就是他最危险的半拍**。

这半拍，就是整个游戏。

## 二、一根弦就是一条命

### 你只有三个动作

**踩（Hold）**：站在弦边按住 Shift。弦被你压下去，形成一个 V 形的凹槽。它成为一个漏斗——人群被吸进去，卡在弦上。同时，那根弦发出一个持续音，**卡上来的人越多，音色越厚**（这是你唯一的“血量条”：你能听见自己现在有多强）。

**放（Release）**：松开。弦回弹，把挂在上面的一切甩出去。**这是你全部的暴力。** 没有任何别的攻击手段。

**拨（Pluck）**：站在弦边，鼠标左键朝一个方向划。弦从你指尖传出一道波，沿着弦跑到黑暗里，把沿途的人掀翻。距离远，清不了场，只能“清出一条路”。

再加一个：**调（Tune）**。按住 R 零点八秒，把跑掉的弦拧回去，弦的张力恢复。**这零点八秒你不能动，你的手离开地面，你什么都做不了。**

**敌人就等在这零点八秒。**

### 六根弦，四个人

这把吉他走音了。被人改过，被雨淋过，被遗弃在这里。它的调弦不是任何书本上写的那种。

**所以这把吉他上所有的和弦，都是错的。全世界只有你们四个人会弹。**

开局，只有**三根低音弦**能发出声音。它们又粗又钝，只能推，不能刺，音色像捂着嘴说话。你一个人站在台上，能用这三个音勉强撑住一个节奏——**这就是一个乐手独自面对全场的样子**。

然后，你在人群里看到了她。灰白色的，鼓手，**闪**。她也被淹了。她还在走，但眼睛是黑的。

你在她身边踩弦。一次、两次、五次。人群被震开又合上。第七次的时候，她抬起头。

**第八次弦响，她的颜色回来了。**

她走上台，在你身后坐下，第一下鼓点砸在你心口——**台上多了一根弦，音乐多了一个声部**。

> **找回来一个人，就是点亮一根弦。三个人，六根弦，一把完整的吉他。**
>
> 一个人只有半把琴。四个人，才是一首歌。

这是整局的成长曲线，也是这个游戏唯一想说的话。不需要解释，玩家在第八次弦响时会自己明白。

### 断

弦会断。

被咬、被反复猛拨、被你在错误的时候硬撑——张力掉到零，它**啪**地一声，真的断了，瘫在地上。断了就是断了，不会自己回来。

断了的那根弦不会消失，它会留在地上，变成**地形**：一道绊脚的坎、一条能挡一下的线、一个你再也弹不了的、躺着的伤口。

而**断了的那根，只有回到台上的人才能替你重新装上去。** 你自己装不了——你腾不出手，你还要弹。这一条，是我最想在游戏里守住的东西。

于是这个游戏的曲线是**往下走**的：

**六个音 → 五个音 → 三个音 → 一个音。**

幸存者类从不这么干。你通常越打越强。这里你越打越**穷**，你失去的不是数字，是**音域**。当你只剩一根弦，音乐会变得极其朴素——**只剩一条线，还在响。**

而这是设计的目的：让你在最后时刻，无比清楚地意识到自己还剩什么。

### 你本人没有血条

敌人碰到你，不会让你掉血。他们会**掐断离你最近的那根弦**。

你的生命，就是**你还能发出多少种声音**。

当最后一根弦断掉，你什么也做不了，只能走。你会站在台上，看着那些黑眼睛的人涌上来，越过你，越过你的琴，灯光熄灭。

没有死亡画面。

屏幕上只有一行字：

> **「今晚，到这里。」**

三秒后，第一排有人喊：“再来一首。”

菜单出现：**[ 再来 ]**

## 三、这一整个游戏，只有一个声音

这是我最想要的那条规矩，也是我最怕做不好的那条：

**除了那把吉他，游戏里不存在任何声音。**

- 没有打击音效。人被弦打中，发出的就是**那根弦被拨响的声音**，只是更闷、更短。
- 没有击杀音。人坐下的时候，是从一个音里剥离出来的一个泛音。
- 没有 UI 音效。菜单的“确认”，是你手指在琴身上敲了一下。
- 没有敌人脚步声。**那些冲台的人，是完全无声的。**

所以在这个世界里，**你听得见的，全都是你自己。**

而这也让唯一一次“别人发出声音”，变成了整局最重的一击——

## 四、几个我希望能被人复述的名场面

### ① 她回来了（约第 4 分钟）

你已经打了很久，只有三根弦，一直在推人。鼓手 **闪** 在人群里被你踩了八次。

第八次，她恢复颜色，走上台，坐下。

**她敲响的第一下，不是音效，是低频。** 你能感觉到椅子在震。从这一秒开始，整局的音乐有了心跳。玩家会突然发现——刚才那三分多钟，原来一直是**没有鼓的**。他一直在一个没有心跳的歌里硬撑。

那一刻不需要台词。玩家自己会鼻酸。

### ② 观众替你打拍子（弦断了以后）

你的第四根弦断了。全场有半秒钟的死寂。

然后，第一排有人开始拍手。第二排跟着，第三排，全场。**他们在替你打拍子。**

你没有那一根弦了，但你有节奏。你可以在这片掌声里走位、调音、重新布防。**台下的人接住了你。**

这是这个游戏最“少女乐队”的一刻：**演出不是你一个人的事。你站在台上，是因为有人愿意替你数拍子。**

### ③ 六弦齐鸣（终局）

扫弦（**Space**）需要**六根弦全部亮着**才能用。你整局都在为它攒。

当你把三个人都找回来，台上第一次站满四个人的那一秒——

你按下 Space。六根弦同时被扫响，整个场地的光从红变白，屏幕上所有还在往台上爬的人，在同一帧里被这道声浪推回去、变成彩色、坐下。

这不是“大招”，这是**一首歌终于完整了**。

### ④ 最后一声“啊”（结算）

一局结束，台下坐满了。全场五百个人。

整局游戏里，你没有听到任何一个人说话、唱歌、喊叫——他们都是无声的。

然后，在你放下琴的那一秒，**五百个人一起“啊”了一声。**

那不是欢呼，也不是合唱，就是五百个人同时发出的、很轻的一个元音。像一整栋楼同时松了一口气。

**一局游戏，你只听到一次人声。就是这一次。**

## 五、为什么它必须是少女乐队

把任何一个元素换成别的题材，这个东西会立刻塌掉：

- **“六根弦、四个人”** —— 一个人只能弹三根，四个人才能弹满。这不是数值成长，这是**“一个人做不成”的具体形状**。换成“收集三块宝石升级武器”，这个结构就死了。
- **“找回来的人露出颜色”** —— 这是乐队里那个“她一开口，整个团才成立”的瞬间。是关系，不是装备。
- **“观众替你打拍子”** —— 只有台上的人，才知道这有多救命。这是 Livehouse 的地板，不是地牢。
- **“你们弹的和弦是全错的”** —— 因为吉他走音了，全世界只有这四个女孩会弹这些错和弦。**不标准，但是我们的。** 这是这类题材最核心的那句话。
- **“失败是散场”** —— 乐手最怕的不是死，是**没人再听**。

如果这是一个骑士的故事、一个太空的故事，以上每一条都要重新找理由。**在这里，一条都不用找。**

## 六、它把“幸存者”推到了哪

| 类型惯例 | 《满弦》 |
| --- | --- |
| 武器自动开火，玩家只负责走位 | **走位就是弹奏**。你的位置决定音高，你的停顿决定和弦，你的移动本身就是谱面 |
| 血量是数字，掉到 0 就死 | 血量是**你还能发出多少种声音**。失去的是音域，不是生命值 |
| 击杀敌人，敌人消失 | 击杀敌人，敌人**坐下**。战场会越打越满，而你数得清台下有多少人 |
| 成长曲线单调向上 | 曲线**向下**：六个音 → 一个音。你在失去，而不是在变强 |
| 暂停开卡片选强化 | **没有暂停菜单**。成长发生在台上：你救谁、在哪根弦上救 |
| 音乐是背景 | 音乐是**状态直读**。场上弦的凹陷程度，就是你听到的和声密度 |
| 威胁 = 敌意 | 威胁 = **热情**。他们不是要杀你，他们只是想上来 |

最后一行是我最得意的：**这个游戏里最恐怖的东西，是一群太想上台的人。**

## 七、我押上去的三个赌注

### 赌注一：没有升级菜单

幸存者类的“暂停 → 三选一”是它的骨架。我要把这块骨头抽掉。

成长只有一种形式：**你在台上把人找回来，而这一步发生在战斗中间、在弦的响动里、在你可能被打断的时候。**

这意味着所有选择都必须在实时中完成，没有安全的思考时间。这很危险——它可能让玩家觉得“我不懂我做了什么”。

**但我愿意赌**：因为如果成立，它就再也不是“一个每 20 秒弹一次窗的游戏”。

### 赌注二：敌人是无声的

在一个由声音构成的世界里，让主要的威胁完全静音。这违背了“敌潮要吵”的直觉。

**赌注在于**：当全场只有你的声音时，你制造的每一次响，都会显得极其重要。玩家的耳朵会被训练得非常敏感——然后在第 4 分钟，你第一次听见鼓声、在第 12 分钟第一次听见人声。

所有的音量都花在这两次上。

### 赌注三：一局 = 一首属于你的歌

一局打完，系统会把你这一整局做过的事（拨了几次、踩了多久、救了谁、断了哪根弦、什么时候松手）翻译成一段二十秒的音乐，放在结算界面。

**你自己的这一局，就是一首能听的曲子。** 而且它每次都不一样。

这是“可传播”的钩子：截图不够，你会想把它发出去。

**风险**：这可能很贵，可能很难听。所以它是 P1，随时可以砍成“一段波形图 + 三个数字”。

## 八、最大的风险，和必须成立的前提

### 风险 A：手感（最高优先级）

“踩下去—抽回来”是物理的。如果弦凹下去没有重量，回弹没有爆发，这个游戏就会像在**拖一根塑料绳**，一切全垮。

**必须成立的前提：以下五件事必须在同一帧里发生。**

1. 弦的几何形变（V 形下凹，且凹得越多，音高越高）；
2. 音色的加厚（卡上来的人越多，声音越脏——玩家能“听见”自己攒了多少）；
3. 松手瞬间的 **1 帧白闪** + **12 度相机抖动** + **0.4 秒色差**；
4. 低频在地板上的共振（用底鼓同频，让窗户抖）；
5. 被甩出去的人在半空变色的那 0.8 秒——**这是情绪的窗口，不能短于 0.5 秒**。

**少一件，这个机制就只是一根会动的线。**

### 风险 B：声音的质感

全游戏只有一把吉他，而且是程序合成的。

如果它听起来像电子琴、像 8-bit、像“嗒嗒嗒的玩具”，**整个世界的庄严感会瞬间消失**，因为它承载了全部的情绪。

**必须成立的前提**：用物理建模（Karplus-Strong / 延迟线波导），而不是振荡器。噪声脉冲进延迟线，反馈衰减——出来的声音会有真实的“木头感”和“弦的摩擦”。这条路我验证过，是唯一能让六根弦听起来像**六根不同的弦**的方法。

### 风险 C：构图

俯视角看一把巨吉他，很容易被误读成“一块木板”。

**必须成立的前提**：第一眼就要能认出来。音孔是纯黑的一个洞（也是 Boss 出来的地方）、品丝是一排有金属反光的横条、琴身有木纹和磨损、六根弦有自己的粗细与光泽。**玩家在屏幕里待了三十秒，如果说不出“这是把吉他”，这个方案就输了。**

### 风险 D：范围

“六根弦 × 三位队友 × 多个敌人类型 × 一个 Boss”不小。

**P0 兜底方案（砍到骨头也依然成立）**：一个舞台、三根弦、一个队友、一种敌人、一个从音孔里爬出来的 Boss、一首“全场五百人一起啊”的结尾。**这依然完整地表达了上面所有的话。**

## 十、它长什么样、怎么响（技术草图，只为证明能做）

- **视角**：3/4 俯视，跟随玩家。低多边形，木色 + 霓虹补光，夜色但不黑。
- **舞台**：一块巨大的木板（吉他的面板），中间一个音孔（Boss 出口），六条横贯的弦，一排排品丝。**全部用 Three.js 基础几何体 + CanvasTexture 程序生成纹理**，零外部素材。
- **弦**：自定义 BufferGeometry 的管状体，顶点每帧按“玩家位置 + 张力 + 最近的撞击”做局部凹陷，不需要物理引擎。六根弦就能撑起全部战斗。
- **人群**：`InstancedMesh`，单批几百个。坐下的人切换到另一个静态 InstancedMesh（**观众席**），只保留位置和颜色——所以他们可以多到“坐满”，而几乎不耗性能。
- **变色**：`instanceColor` 从灰到彩的 0.8 秒插值。这是本作最便宜、也最值钱的一行代码。
- **声音**：WebAudio 手写一个六弦 Karplus-Strong 合成器 + 一个完全由玩家事件驱动的鼓机。**没有音频文件，没有版权问题，且天然与玩法帧同步。**
- **操作**：WASD 移动 / Shift 踩弦 / 松开施放 / 左键划弦 / E 靠近队友 / R 调音 / Space 扫弦（六弦全亮） / Esc 暂停。**仅键鼠。**
