# 《第一排》

> **一句话**：你打散的每一只噪音，都会变回一个观众；你唱不下去的时候，是第一排的人先开口。
>
> 少女乐队 × 吸血鬼幸存者 ｜ 仅桌面键鼠 ｜ React + TypeScript + Three.js ｜ 离线单文件 ｜ 一局 = 一场演出
>
> 工作名、乐队名与角色名暂定，M3 查重后定案。
>
> 作者：planner-liveops（长线与元进度方向）

## 0:52

第一只「走音」在你面前散开时，你以为它会掉经验。

它没有。它身上那层灰白的静电像一件太大的外套，从头顶滑到脚边。静电下面站着一个女孩，手里还攥着手机，屏幕亮着，上面是一条没发出去的消息。她愣了两秒，看看你，看看自己的手，然后打开手电筒，举过头顶，朝舞台晃了一下。

没有「粉丝 +1」的提示。场子里只有她一个人，像一根刚被点着的火柴。

她后来会坐在第一排。你会在今晚散场时给她起名字；你随手打下的两个字，会变成这间仓库后来所有故事的开头。

## 3:47

副歌前，阮枝的线被拽掉了。

贝斯从歌里消失的那一下，比掉血更难受。整个房间的低频被抽走，观众席的灯浪矮了一截，小满的鼓突然像在空屋子里敲。你冲过去，踩住插头，重新插上。音箱「啪」地亮了一格。人群回来了。

就是这时候，第一排有人举起一块纸板，荧光笔的字歪歪扭扭：

**「把麦克风给我们。」**

是 0:52 那个女孩。她还没有名字——名字是你今晚散场时才给她起的——但她举牌的样子，你认得。

你按下空格。迟野把麦克风往麦架上一放，朝护栏推过去。

镜头没有切。它只是**转了 180°**。

从迟野的肩后，越过她的头发、返听音箱和舞台边缘——你第一次站进了观众席。你看见自己的乐队在台上，三个人小得像三枚钉子；舞台灯从她们背后打过来，把她们压成剪影；你看见仓库的天花板，看见音箱堆，看见第一排的脸。

音频也翻了。舞台监听被压成一条闷闷的线，观众的呼吸、脚步、衣料摩擦涌上来，仓库的混响突然变得很大。然后，第一排先开口，第二排跟上，整个场子——那天晚上一共四十来个人——开始唱。

他们唱的是你二十秒前刚弹过的那七个音。不齐，有一点跑调，拍子也拖了半拍。啸叫变成的那个女孩高音会破，断频变成的那个家伙总是慢半拍，底噪变成的大叔只会低低地哼。他们不会唱词——没有人写词——他们只唱「啊」和你给的那几个音。可四十个人一起「啊」的时候，声音是暖的、脏的、活的，比任何词都更像合唱。

声音从每一张嘴里出来，汇成一道很宽、很暖的浪，往前推，把已经压到护栏的噪音整片推回门口。

这十四秒里，你控制的不再是迟野，是**观众**。鼠标左右扫，哪一片人唱得最大声，浪就往哪边推。你拿一屋子人当乐器。

十四秒之后，纸板翻了个面，背面早就写好了：「再来一首。」

镜头转回来。你的歌里多了一层人声——他们唱过的那七个音，变成一条一直在的合唱层，直到这场结束。

**这是全篇最重要的十四秒：你不再是主角，你成了自己演出的第一个观众。**

## 一局到底在玩什么

它仍然是一款幸存者：怪潮、自动攻击、升级构筑、一局一命、重开。改动只有一处——**你的场地里坐满了人。**

一句话：**守三个人，喂一屋子人。**

场子很简单：舞台在最里面，观众在中间，噪音从大门的方向涌进来。观众不是背景板，是一个有厚度、有情绪、会挡住噪音的实体。他们兴奋的时候一起往前顶，把噪音卡在人堆里；他们泄气的时候往两边让，噪音就顺着人缝摸到舞台边。

噪音先挤开的是后排的新观众；第一排是最旧、也最硬的那道墙。所以，**观众就是你的血条**——只不过这条血条由几百个人组成，而且不显示数字：你从人群的厚度、灯浪和低频里听出来它还剩多少。

三个女孩，三条声音，三个系统：

- **迟野（主唱 / 节奏吉他）**：她的声音是「钩子」。她踩过的拍子、打散的噪音，会在一条看不见的磁带上落音。一局结束时，副歌那八小节里最反复的几个音，就是今晚这首歌。
- **阮枝（贝斯 / 键盘）**：她是「记性」。她撑住低频，也记住你们唱过的所有歌。她在，观众才想得起以前的歌；她的线一断，场子先失去地板，再失去记忆。
- **小满（鼓）**：她是「心跳」。鼓决定观众跟不跟得上拍。她在，灯浪跟着拍子走，热情涨得快；她不在，观众会慢慢找不到拍子，开始散。

迟野怕安静，所以她一直唱；阮枝什么都记得，所以她最怕忘；小满坐不住，所以她是第一个听见观众的人。

三个人各有一根**乐器线**，插在舞台的音箱/接口上。同一时间你只能控制一个人——另外两个会自己站在位置上弹，但线会被噪音拽掉、接口会被踩松。谁的声音没了，对应的系统就塌一块，而且是**直接从音乐里听得见的**：贝斯没了，歌会变轻；鼓没了，人群会乱；迟野没了，歌就没有主旋律。

**你只有一个人，但你得同时当三个人。**这是这支乐队最穷、也最真的地方。

还有一条规矩：**离接口超过线的长度，你会自动脱插。** 脱插不是惩罚，是选择。脱插之后你进入「独奏」：攻击更猛、音色更脏，但没有观众加成，也没法给人群充电。你可以为了清一波怪主动拔线，扎进前排 solo，再踩着拍子冲回来插上。线在舞台上拖来拖去，是这场演出的心电图。

然后是**升级**。

没有「+10% 攻速」的卡。每次升级，三张牌是**你刚刚弹过的三段乐句**：左边那张可能是你 2:31 连着打散噪音时的那串上行音，中间是你躲技能时无意弹的半音，右边是你上一场留下的老歌 hook。每张都能试听，都写着它会长成什么攻击：上行 = 一道从地面爬起来的音墙，重复音 = 扫射，下行 = 砸地的低频波。如果今晚的 setlist 里有老歌，池子里还会混进它们的变奏。

你选的不是数值，是**你刚才做过的事**。一局打完，你记得的不是「我拿了三张蓝卡」，是「我那晚弹了一句很凶的，后来它救了全队」。

走位为什么会变成旋律？因为游戏每一拍读一次你的移动方向：往上，音往上跳；停住，音就拖长；冲刺，就是一个重音。它自动收在一个调里，不会难听。**你躲得越漂亮，歌越好听。**这是幸存者最核心的动词——走位——第一次直接变成了作曲。

输呢？

**输不是死，是安静。**

三个人都被拔线、观众被推散、场子安静超过几秒，演出就结束了。灯会亮起来，没有人喝倒彩；第一排会有人还举着灯，等你返场。结算是一张今晚的曲目单：唱到几分几秒，第几位观众加入，哪一句被留了下来。

**你倒下的那一场，歌不会消失。** 观众已经听过了；它会进他们的曲库，也进你的曲库。下一场，你可以把它排进 setlist，让满场的人替你唱。失败只是把这首歌交出去，不是把这一晚删掉。

## 一张草图

```
        大门 / 噪音涌入
              ↓
   [ 观众席：越打越厚，会挡住噪音 ]
      后排：新来的
      第一排：最早听见你的人
   ───────── 护栏 ─────────
      阮枝        迟野        小满
      └───── 三根乐器线 ─────┘
             [ 舞 台 ]
```

- 观众厚度 = 血条；三根线 = 三条系统；线长 = 活动范围。
- 键鼠：WASD 走位，1/2/3 换人，E 插线，空格递麦，递麦时鼠标指挥观众，Tab 打开今晚的 setlist（也是暂停）。
- 不做触屏。一只手在键盘、一只手在鼠标，像在调音台前调一场演出。

## 为什么以前没有

幸存者类的场地通常是空的：敌人从屏幕边缘刷出来，死了变成经验和粒子，地图永远干净。这里的场地会**长人**：你每打散一只噪音，就有一个人站起来，走进观众席。你的击杀数不是数字，是一排一排亮起来的手机灯。地图越打越满，越满越难，也越满越强。

更过分的是：你打散的是什么噪音，台下就多一个什么样的人。啸叫变成那个高音会破的女孩；底噪变成那个一直安静拍手的大叔；断频变成那个总是慢半拍、但每次都来的家伙。**你的观众，是你今晚打败过的所有噪音。**他们的声音会失真、会跑调、会抢拍——但那是你的场子的声音。

音乐游戏通常让你跟着谱子弹；这里反过来——**你先弹，观众后学**。你走位、出手、踩拍，游戏把这些收敛成一小段能哼的旋律；下一场，观众会把它唱回来。你练的不是角色的等级，是**一屋子人的记忆**。

元进度通常是「数值变大」；这里是「**你的歌变多，记得你的人变多**」。最终战不是打一个更大的 Boss，是把你所有写过的歌一次性唱完。

还有摄像机翻转的那十四秒。大多数游戏都在强调「你是主角」；这个游戏想说，一支乐队只有在被看见的时候才存在。你把控制权交给观众，也把「主角」的位置交了出去。

所以它把四件事推到了别处：

- 幸存者的场地第一次有了居民，你的结局不是分数，是一间屋子记住了什么；
- 演奏第一次不是跟谱，是写谱，然后教会一屋子人；
- 元进度第一次不是角色变强，是**你的歌变多、记得你的人变多**；
- 失败第一次不是清零，是发行。

## 为什么必须是少女乐队

因为只有「一支很穷、很怕没人来的小乐队」，才会把一屋子观众当成命。

因为只有乐队这种形态，可以把主唱、贝斯、鼓直接写成三条系统，而不是三个换皮职业：主唱负责「被听见」，贝斯负责「被记住」，鼓负责「一起动」。这三件事，恰好就是一个小乐队全部的生存问题。

因为只有站在台上的人，才会在唱到一半的时候，想把麦克风递出去。

她们不是英雄。她们是三个会在上台前互相检查指甲、会在第一排看见熟脸就弹错的女孩；她们的全部本事，就是让人愿意留下来听。

**这不是一个「我要成为最伟大的乐队」的故事。这是一个「我想让这间屋子坐满人」的故事。**Livehouse 就这么大；你最后想填满的，就是你眼前这一间。

## 长线：我们不运营玩家，我们运营一间会记住你的房间

这里没有货币、体力、每日任务、通行证、签到。没有「上线领 100 粉丝值」。我们不打算用数值留住你。

我们只做一件事：**让这间仓库记住你。**

每一场演出结束，房间会变一点。墙上多一张曲目单，上面是今晚的真实数据；吧台后面多一个名字；音箱上多一张贴纸；某一根线被胶带缠过，因为那晚被人踩断了。这些不是装饰，是存档。**你下次打开游戏，不是打开一个菜单，是回到一个地方。**

观众也是存档。每一个被你救回来的人，都有名字、有第一次来的那晚、有最喜欢的那首歌。你的第一批观众永远站在第一排。第一场开场只有她一个人；后来她旁边多了人；再后来，第一排挤满了人。演出前你可以走到护栏边，看见某个眼熟的人举着一块牌子，牌子上写着你们上一场唱砸的那首歌——她在点它。

（第一晚结算时，系统会让你给第一位观众起名字。你随手打下的两个字，会变成这间屋子里最老的那块牌子。）

曲库是存档。每一场留下的 hook 都会成为一首有名字的歌（系统会起一个，你也可以改）。歌不是收藏品：**它们是你的技能池**。开演前你排 setlist，最多带几首老歌上台；带了哪几首，今晚的升级池里就会出现哪几首的变奏，观众也才唱得出来。你越玩，你的池子越像你——不是数值像你，是**声音像你**。

最后，会有一场「静默场」。

那是你和你所有观众的终场。对手叫「静默」：它不咬人，它只做一件事——**从观众的记忆里，一首一首地删掉你的歌。**

它先删掉最新的一首，墙上那张曲目单变白，人群里有人愣住，跟着哼的声音没了；再删掉那首你第一次返场时唱的，第一排有人低下头，像忘了一个很重要的名字；最后它要删掉今晚这首，删掉「接触不良」这四个字。

你要做的不是打败它。你要在它删掉之前，**把每一首歌重新弹一遍，教回来**。你弹一句，人群跟一句，曲目单一张一张重新显影，名字一个一个亮回来。全部亮回来的那一刻，整间仓库会一起唱你写过的所有歌——你所有的失败、所有只来了三十个人的晚上、所有你以为是白费的演出，全部变成最后一场的武器。

**这就是我们的「长线内容」：不是我们每个月更新一个活动，是你每多活一晚，终场就多一首歌。**

而且它真的很便宜：终场的每一「阶段」，都是你存档里一首歌的变奏。你玩得越久，Boss 战越长、越像你。这是单机游戏能做出的、最不讲道理的长线。

你离开的时候，灯不会关；你的观众还在那儿，不催你。你回来的时候，他们还在第一排。

这大概是唯一一种不需要服务器的 live-ops：我们不追留存率，我们只负责让这间屋子值得回来。

## 还有几个画面

- **第一排的牌子**：第二晚开场前，第一排那个女孩举着一块新牌子，上面是你第一晚给那首歌起的名字。你今晚没打算唱它。你唱了别的，她一直举着。直到你返场，前奏一响，她把牌子翻过来，背面写着：「我就知道。」——那个瞬间比任何成就都重。
- **人墙**：观众兴奋到顶的时候，你可以把人群「劈开」——他们自己往两边让出一条路，再一起合上，把噪音整片夹在中间。这不是技能特效，是几百个人真的跑起来。然后你再把麦克风递出去，让他们唱。这是全游戏最贵、也最值的十秒。
- **她不记得你，但她记得副歌**：静默场里，第一排那个女孩会有那么一瞬间被删空：她看着你，眼神是空的。但当迟野弹起那首歌的前三个音，她的嘴先动了。她先想起旋律，再想起你。那一刻我希望能让玩家鼻子一酸：**原来我们留下的不是名字，是歌。**
- **把音箱搬到人堆里**：终场最后一首，第一排会爬上台，把音箱扛下去。舞台跟着人群走，线拖在地上，你们在观众中间唱完最后一段。灯从头顶打下来，整个场子围成一个圈。这是这个游戏最后一张画面：**没有台上台下了。**

## 我愿意冒的险

这个提案的赌注只有一句话：**那十四秒必须是好玩的，不是好看的。**

「递麦」如果做成一个过场、一个 QTE、一个「按空格触发大招」，整个提案就死了。它必须是一套可以反复进入、每次都不一样的玩法：你控制观众当乐器，镜头翻转，音频空间翻转，舞台上的三个人真的会因为你把注意力给了观众而获得自由——平时你只能顾一个人，那十四秒里三个人都自由了，因为观众接过了那根线。它必须和日常的「守三个人、保三条线」形成对位，否则它只是一个漂亮的演出。

第二个必须成立的前提：**你即兴生成的那几个音，必须真的能哼、能认、能成为一首歌。** 如果每一场的 hook 听起来都一样，「观众记得你的歌」就是一句空话。这个不能等到最后再验证；原型阶段就要做两个版本：跑两场，生成两段 hook，让没玩过的人听一遍，第二天还能哼出来。哼不出来，这个方向就要改——改到能哼为止。

第三个前提：**几百个人在 60fps 里跑起来、唱起来，不能是幻灯片。** 技术上这反而没那么吓人：一间场、一套 InstancedMesh、一个固定 BPM 的 WebAudio 音序器、一份 localStorage 里的小 JSON，没有外部音频/模型/字体。难的是「人声」和「hook」的质感，不是渲染。

第四个，是气质：**不能拍成 MV，要拍成现场。** 观众唱你的歌，这件事很容易变得煽情、油腻、像一场强行感动。要让它成立，画面必须是脏的：仓库的水泥地、胶带、汗、走音的合唱、灯灭之后还亮着的几盏手机灯。越不精致，越真。

如果最后只能留下一个机制，我留**递麦**：一个人、三个音箱、一屋子会学歌的观众、一间会记住你的仓库。其他都可以砍。

M2/M3 可以砍房间、砍终场、砍到一个人；但有两件事不能砍：**递麦，和观众会记歌。**

但如果那十四秒不成立，这个提案就不成立。
