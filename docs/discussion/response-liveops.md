## 3. 两个融合方案（A + B）

1. **《四分钟，一首歌，一间会记住你的场子》** = 《啸叫》的音乐时钟（4 分钟/128 小节，升级改和弦）+《第一排》的观众记忆（重复才记住，第一排是存档）。核心循环：一晚一首四分钟的歌；老歌是和声段落；观众记不记得决定最后副歌递麦能否接住；安可即胜负。风险：固定曲杀死自由走位，递麦必须中段可操作。
2. **《一束光，两本账》** = 《别关灯》的「一束灯只照一人，暗处掉拍」+《看向我》的「注视有代价，噪音循光」。核心循环：一束光同时决定谁在演奏、谁被看见；照队友台下冷，照观众台上缺声；两本账＝队友声部+观众热度。风险：一个资源干两件事，认知负荷会爆；两本账必须视觉分开。

## 5. 我的提案会怎么改

1. **记忆改重复制**：观众不自动记 hook；重复够才进曲库；老歌要排练，第一排先会。
2. **曲目带和弦身份**：老歌各有调性；带它上台换和声池；升级落点是和弦；观众唱回「你的和弦」。
3. **长线降级+递麦可失败**：P0 只做一间场、第一排、一首有名字的歌、十四秒递麦；房间/曲库/静默场进 P1。递麦失去直接控制、观众可能接不住；借《满弦》：断线只能由回到台上的人装。

## 6. 希望评审回答的 3 个问题

1. 给评审/打分员：玩家真愿意反复演自己的老歌吗？若只想开新 build，曲库就只是博物馆——冠军是否只留「第一排」，不做 setlist？
2. 给可行性：60 秒切片里「少一轨疼」和「合唱能认出」必须同时成立吗？只能保一条时保哪条？
3. 给玩家价值：递麦该必胜还是可失败？可失败会破坏爽吗？必胜又怎么避免过场？
