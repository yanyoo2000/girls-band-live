# planner-arcade 的交叉讨论回应

> 阅读范围：`docs/pitches/` 全部 10 份 ｜ 立场：短局要能被独立评价。

## 1. 我最想偷走的 3 个设计

| 来源提案 | 设计点 | 为什么好 | 如何融入 |
| --- | --- | --- | --- |
| 《杂音》 | 拍线投影：高度＝还有几拍到达 | 把看不清的人潮压成一维可数，视线能离开战场 | 台唇加一条刻度，让「还能憋几拍」成为判断 |
| 《满弦》 | 断弦变地形；只有回到台上的人能装弦 | 损耗不是数字，是地图变窄，还必须依赖别人 | 每砸一次塌一块台唇，舞台越唱越小 |
| 《不散场》 | 推子自己下滑：先听见缺声，再看见人走 | 用耳朵代替血条，最便宜也最疼 | 鼓手敲鼓边有体力，憋过头她会停 |

## 2. 最致命的 3 个问题

| 来源提案 | 问题 | 为什么致命 | 补救 |
| --- | --- | --- | --- |
| 《别关灯》 | 灯四个去向、观众饿/抢/走、90 秒黑场、歌单拖拽，五套节奏叠在一秒 | 学不会肌肉记忆，深度压成「灯给鼓手还是给别人」 | 砍掉观众反噬只留终曲；照地面＝退出 |
| 《第一排》 | 失败即发行：歌进曲库，下局可排 setlist | 失败变成收益，「再唱一遍」被自己的长线吃掉 | 老歌只在最终战出现；一局要能独立打分 |
| 《啸叫》 | 「和弦可被听见」：Am7 与 Am(add b5) 的差别，玩家听不出强弱 | 听觉承诺落空，构筑退回选数值；作者说过这就只是皮 | 差别外化为音区、音色、厚度三种信号 |

## 3. 两个融合方案（A + B）

1. **《静场》×《杂音》：两种静默分层。** 空拍是武器，漏拍是惩罚，二者共用一套恢复仪式：假砸→全黑→心跳白线→空格打回来。风险：两套静默会混淆，必须一只有颜色、一只没有。
2. **《啸叫》×《第一排》：把「观众救你」改成「观众判你」。** 统一两案的声部与线为一张可断的网；高潮不由观众接住，而是安可值到 80 才给评级。代价：失败没有合唱兜底。风险：情绪从被爱变被审判，可能变冷。

## 4. 对 10 份提案的一句话判决

| 提案 | 判决 | 一句话理由 |
| --- | --- | --- |
| pitch-narrative | 保留 | 推子下滑是最会说谎的 HUD：先听见缺声，才看见人走 |
| pitch-roguelike | 合并 | 音乐时钟与固定谱面撞车；安可值到 80 的判决值得留 |
| pitch-atmosphere | 保留 | 不可替换性最强；但要证明「踩/放」不是一根会动的线 |
| pitch-fusion | 合并 | 系统最多；一束光只能留一次，与《看向我》二选一 |
| pitch-community | 保留 | 「注视有代价」最干净，空场结局最便宜也最好传 |
| pitch-arcade | 保留 | 语法反转最狠；但静场若不够忙，它确实只是罚站 |
| pitch-minimal | 保留 | 最小可玩内核；合唱补三个音是变厚而非变响 |
| pitch-liveops | 合并 | 递麦十四秒必留；房间、曲库、静默场三层要砍 |
| pitch-experimental | 合并 | 回录八拍＝构筑很硬；与《第一排》的观众记忆撞车 |
| pitch-newbie | 保留 | 三条戒律应升级为全项目的可读性预算 |

## 5. 我的提案会怎么改

1. **鼓手的数拍变成资源**（偷《不散场》）：她敲鼓边的次数有限，憋太久她就停——原本免费的可读性，变成要省着用的东西。
2. **每砸一次塌一块台唇**（偷《满弦》）：六分钟里你不是变强，而是越来越穷；评级奖励用最少的砸唱完。
3. **台唇投影刻度**（偷《杂音》）：把「还能不能再憋半拍」做成一维可数读数，静音也能玩。

不改两件事：不加升级树，不给观众加自衰减。短局卖手法不卖养成；观众的冷淡只能由我造成。

## 6. 希望评审回答的 3 个问题

1. 假砸要不要仪式化（全黑＋心跳打回来）？它更好学，但会拖慢街机的试错。
2. 六分钟一首歌，评审更看「重玩次数」还是「单次高光」？若是后者，我该做三首歌。
3. 我的砸按音频时钟判毫秒。若设备延迟不可控，允许改成视觉优先判定吗？
