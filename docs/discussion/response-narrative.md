## 2. 最致命的 3 个问题

| 来源提案 | 问题 | 为什么会杀死这个方案 | 可能的补救 |
| --- | --- | --- | --- |
| 《杂音》 | 「一拍一事件」与 4×4 循环器互斥：每拍往四声部之一落子，要读 16 格、拍线、人群 | 它自判的归零风险：一拍两判断 | 战斗只显示当前声部一行，4×4 只在段间编曲；或自动跟随最后点亮的人 |
| 《满弦》 | 向下成长（六音→一音）会收走动词：最后一根弦几乎无事可做，断弦只能等队友 | 纯失去会让后半局变成看戏 | 最后一根弦给一次独奏高光，把失去变孤注一掷 |
| 《不散场》（我） | 推子是单通道 HUD：怪潮里不会看右下角，错过她不是失误，是没看见 | 关系成视力测试 | 让她先走样（根音变简单/抢拍/错音）作预兆；推子做成脚下地灯；离开前给一次停顿 |

## 3. 两个融合方案（A + B）

两条 hybrid 都避开「观众救场」。

1. **《停一次，只能做一件事》**（《静场》＋《不散场》）：同一个按住—松开，瞄准她=听，瞄准台口=憋场；松开只能选一个。核心循环：8 小节战斗 → 她走样 → 按住瞄准 → 松开：清场或接回她的声部。风险：一键两义容易糊；两种反馈必须一样重。
2. **《缺弦》**（《满弦》＋《不散场》）：不搬巨吉他，只搬「人=弦」：四人=四弦/四音域；杂音先掐断最近的弦；断弦只有「回到台上的人」能接回，让她回来只能靠听。核心循环：守弦 → 断弦 → 听她 → 接弦或永远少一个音域 → 最后一个和弦由剩下的人完成。风险：「弦」只做 HUD 比喻会失去手感；做成真弦会吞掉 Livehouse 与人物。

## 5. 我的提案会怎么改

1. **换结局**：删掉「断电→观众拍手接住你」，改用《看向我》的空场——灯亮、人走、你一个人弹完最后一段。观众是见证者；赢是「弹完」。
2. **给「听」加失败梯度**：第一次错过，她只走音/缺席一段，错音留成下一段动机；第二次才走。
3. **砍到三人，升级移进演出**：留灯、沅、铁，纱的「陪她错」并入失败态；「给谁主旋律」从菜单改成段间 4 秒实时对看，超时默认给主唱。

## 6. 希望评审回答的 3 个问题

1. 「空场」是否比「观众救场」更适合冠军高潮？若坚持「被接住」，安可必须消耗观众。
2. 「听」是否必须给即时战斗回报才能过可行性？若必须，做成「停一次二选一」（憋场/听人），但关系会不会退化成资源管理？
3. 8–10 分钟，玩家是否可能在乎四个人？若不可能，砍到两人＋一个观众，还是保留四人、用推子/补位代替对白？
