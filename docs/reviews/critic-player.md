# critic-player 的评审意见（玩家价值与主题表达）

> 阅读范围：`docs/brief.md`（含 §2.1、§5 新 rubric）、`docs/templates/critic-review.md`、`docs/reports/m2-discussion.md`、`docs/concepts/hybrid-{a,b,c}.md`、`lineage.md`、`comparison.md`；回查 `docs/discussion/` 中主题、角色、传播段落。未读 archive。
> 口径：新 rubric（Fun 30 / Theme 20 / Originality 20 / Depth 10 / Polish 10 / Feasibility 5 / Scope 5，取消可行性否决）；不以“难/多”扣分；不打总分；模板“6 人”按 brief 的 7 人。

## 总览

1. A 想做完成品：把“停”做成手艺，6:30 固定谱面换手感与评级；最稳，也最不像少女乐队。
2. B 想做唯一的那一个：舞台是走音六弦琴、成长向下、敌人无声；机制与主题同构最硬，却把“少女乐队”拍成“一个人的后摇”。
3. C 想做最上头的那一个：养人—招灾—放手，正反馈加空场结局；最像少女乐队、最好传播，也最容易退化成“灯光秀”。
4. 三案缺口不在可行性，在“人”：只有 B 的“找回”把队友当角色，A/C 的队友仍是规则。
5. 倾向 C > B > A：C 赢在“五分钟内想讲给别人听”，B 赢在主题纯度，A 赢在交付——交付只占 10%。

## Hybrid A（稳妥/可行性优先）

- 一句话判断：最像完成品、最不像少女乐队——“停”是手艺，“人”是参数。
- 三个优点：
  1. “按住空格让全场安静，松手把一千人撞倒”，一句话就让人想试；6:30 最照顾短局玩家。
  2. “空拍必须最忙”是纪律：读鼓棒、贴台唇、赌半拍、左键清前排；成立即品类反转。
  3. 冷场最便宜最贴题：退场的人、手幅、扫地店员、最后拍手的人。
- 三个红旗：
  1. 角色缺席：4 人里 3 人是“炮台+一条规则”（`hybrid-a.md:90`），无面孔、关系、台词；§7 把叙事让给 B/C（`:143`），等于不承担主题。
  2. 对幸存者玩家不成立：零成长+固定谱面，拿掉的正是“越打越强”；目标玩家却含幸存者玩家。
  3. 静帧同质化：人潮+追光+过曝与 B/C 的暗场人群难分；A 无独占符号，8 帧砸必须靠视频。
- 三个必须回答的问题：
  1. 队友若只是规则，请给一个不靠立绘/台词的角色瞬间（如连续假砸后她 4 小节不打拍）；否则只是“乐队主题的节奏游戏”。
  2. 第二局与第十局的差别，请用玩家能感知的话回答；“更准”是设计师语言。
  3. 第一次在 4:12 冷场的人，会不会以为游戏坏了？
- Verdict：hold
- 风险等级：medium（主题 high／交付 low）

## Hybrid B（主题/原创优先）

- 一句话判断：唯一“机制即主题”，也唯一可能被读成“打粉丝”。
- 三个优点：
  1. 机制/主题/镜头同构最强：舞台=走音六弦琴、走位=弹奏、松手=把人弹回座位；换题材立刻塌。
  2. 向下成长是真反叛：六→一、断弦变地形、只有回到台上的人能装弦；把“失去”做成关系重量。
  3. 2:40 松弦回色：31 人同帧松开、半空变彩、落地坐下、400 人喊名字；唯一“角色与机制同帧”。
- 三个红旗：
  1. 基调错位：凌晨四点半、一个人、走音、庄严——brief 要明亮热血，B 给孤独微伤感；前 3 分钟看不到“少女”。
  2. “敌人=想上台的人”：冲台粉丝=要被弹回半空的怪；不给“被噪音操纵”解释，会被读成“打粉丝”。
  3. “少女”视觉资产最薄：巨吉他+600 人+灰彩色，没有一张脸、一句词；“找回之后她是谁”没回答。
  （口径：8:30 全亮、9:30 断，满配仅 60 秒。）
- 三个必须回答的问题：
  1. 前 3 分钟无鼓、无第二人、无台词，凭什么让玩家认定是“少女乐队”？请给 30 秒内的“其他人存在”证据。
  2. “弹回座位”如何不被读成“打粉丝”？若必须加设定，那句话是什么？
  3. 若玩家完美保弦、一根不断，“向下成长”还发生吗？是剧本还是代价？
- Verdict：advance
- 风险等级：medium（主题 low／乐趣中／工程不计）

## Hybrid C（乐趣/循环优先）

- 一句话判断：最像少女乐队、最好传播，也最容易玩成“一个人的灯光秀”。
- 三个优点：
  1. 主题最正：“被看见”是地下乐队唯一内核；光=注意力、观众=声音、人气=血，每层都说“他们在看你，你才有声音”。
  2. 传播资产最多：2:00 人浪（187→307）、6:30 静默、放下光、空场结局、结算“第二排，有 12 个空位”。
  3. 最合 brief 基调：荧光棒、合唱、安可、人浪；也是唯一标准幸存者结构。
- 三个红旗：
  1. 角色仍是工具：队友=三根可拽可插的“线”，四人关系压成“照顾三条线”；C 最像乐队游戏，玩家越期待“人”。
  2. “看”可能被动：鼠标移光+左键收束，序曲 90 秒无噪音，静帧像氛围 demo；门不过就是“好看但不知道玩什么”。
  3. 主题自拆：烧=快、唱化=慢（`hybrid-c.md:94`）；若“烧”更快，“烧掉未来观众”就是最优解，C 讲的就成了“为了赢放弃被看见”。
- 三个必须回答的问题：
  1. 终曲人不够时，玩家看到“我失败了”还是“我演完了”？这决定 C 温柔还是刻薄。
  2. 队友除三条线，有没有一个瞬间让玩家记住她？能否把“插线”改成有主语的动词？
  3. 空场是“失败的一种”还是“另一种完成”？
- Verdict：advance
- 风险等级：medium（乐趣中／主题中／工程不计）

## 交叉比较

- 差异真实，无换皮；但三案共享“暗场+一片人+一个动作”的舞台语法，静帧同质化高于文字差异；M4 须给冠军案独占视觉符号。
- 最适合 7 人工程+纯 HTML：A（风险集中在“那两秒”，音频可降级）；B 在音色/手感，C 在系统数量与 90 秒门。
- 最易“截图就有人想玩”：C（人浪、空场、结算空位）；B 的松弦回色是最强 GIF。
- 共同缺口：没有“排练室/后台/成员关系”；brief 主题含排练室与成员羁绊，三案只剩 Livehouse 一场演出——“乐队”被压成“演出”。

## 总推荐与红线

- 排序：C > B > A。若“原创/主题纯度”最高，B > C > A；若“必须交付”最高，A > C > B。三种都成立，说明三案真不同。
- 最大主题风险：角色工具化。三案都做得出“舞台上的少女”，做不出“四个人的关系”；brief 支柱 3 要求差异能被一句话说出，只有 B 的“找回”接近。M4 不补“角色瞬间”，冠军会被读成“乐队主题的幸存者”。
- 不可接受的红线：
  1. 角色：冠军案 M4 必须给出至少 4 个不靠立绘/配音、能被一句话记住的角色瞬间；给不出不建议推进。
  2. 暴力：不得出现“打粉丝/踩踏/受伤”读法；B 的“弹回半空”、A 的“按进地里”须用失重、光、颜色替代痛感。
  3. 主题自拆：C 若让“烧”成唯一最优解，或让“人气=价值”成明示价值观，须在 GDD 改写。
  4. 原创：M3 定案后 48 小时内查重标题/乐队名/角色名/曲名。
  5. 传播：冠军案必须有“不配字幕、30 秒看懂”的录屏片段；只能靠文案解释，说明“哇”还没做出来。
- 给打分员：先独立打分再读 `comparison.md` §6/§7；不要用“像不像幸存者”判死 B、“能不能做完”判死 C；不要用移动端/触屏或固定 P0 数量作维度。

## 按新权重复核（2026-10-28 用户指令）

> 上文已按新 rubric 判断；本节记录相对旧 rubric 的变化，只改权重理由，不改事实分析。

- 权重：Fun +5、Theme +5、Originality +10；Feasibility −15、Scope −5，取消否决。“能不能做完”从 20%+否决权降到 5%。
- A：旧权重靠 Feasibility+Scope 拿分并受否决保护；新权重这两项只剩 10%，而 Theme（角色缺席）与 Fun（对幸存者玩家不成立）被放大。verdict 维持 hold，风险 medium，含义变了：不是“做不完”，是“不够像少女乐队”。
- B：旧权重下“手感/音色难”会压到 hold/high；新规不得因难度扣分，Feasibility 只问“有没有路”，故 verdict 维持 advance，风险 high → medium；剩余风险是 Fun（前 3 分钟偏慢）与 Theme（“打粉丝”读法）。
- C：旧权重下“系统多”会被 Scope/Feas 扣分；新权重下不再是问题。verdict 维持 advance，风险 medium；真正风险是 Fun（“看”被动）与 Theme（烧 vs 唱化）。
- 排序：C > B > A 不变，但差距重排——B 与 C 缩小（C 靠 Fun 30，B 靠 Theme+Orig 40），A 与 B/C 拉大（交付优势只值 10%）。若只看“最好的游戏”仍 C 第一；若更看重原创，B 可能反超，取决于 Fun 打分。
