# 《谁在听》 / WHO'S LISTENING — v1.0.0

> 少女乐队 × 吸血鬼幸存者：你只有一束光——照向台下，他们为你燃烧，噪音也循光而来。整场演出你只做一件事：**决定看哪里。**

## 下载与运行

- **在线试玩**：https://yanyoo2000.github.io/girls-band-live/ （GitHub Pages，桌面浏览器 + WebGL2）
- 下载 Release 附件 **`girls-band-live.html`**（单文件、离线、零外部素材）。
- 双击或拖入 **Chrome / Edge / Firefox**；需要 WebGL2 与硬件加速，窗口 ≥1280×720（最小 1024×640）。
- 无需联网、无需安装；只在 `localStorage` 的 `gbl.save.v1` 保存设置与记录。
- 校验：`1,045,498 B`，SHA-256 `2d2d91c2670bb447ad27d27950a627502d1aa9e7ffbd6aa6bdf14768014e0079`。

## 这一版有什么

- **9:30 一局**：序曲 → 主歌 → 副歌 → 桥段/静默 → 终曲；三次人浪，三阶段 Boss「静默」。
- **一束有代价的光**：散光 / 束光 / 回照；照观众、烧噪音、照自己互相抢同一束光。
- **4 名乐队成员**、**768 席 / 4 座区 / 4 声部**、**24 卡池 / 单局 10 选 / 3 条互斥构筑 / 3 个进化**。
- **12 声部 WebAudio 合唱**、5 层程序化音乐、12 个 SFX；全部程序化，无外部音频/贴图/模型。
- 0 数字 HUD、白光人气、完整无障碍、本地存档、桌面键鼠。
- 单文件 **1,021 KiB**，`file://` 可直接玩；**零运行时网络请求**。

## 操作

`WASD/方向键` 移动 · 鼠标移光 · 左键按住束光 / 点击点燃 · `E` 插线 · 长按 `Space` 终曲放下光 · `Esc` 暂停 · `Tab` 查看构筑。

## 已知限制（P1 / 未人测）

- 90 秒真人门（10 名新玩家 ≥7 主动移光）未做；音频听感/盲听 A/B 未人测；集显、1080p、连续帧率未正式测；Firefox 未实机。
