## 0. 一句话与 30 秒规则

**一句话**：你只有一束光——照向台下，他们为你燃烧，噪音也循光而来；整场演出你只做一件事：决定看哪里。

**30 秒规则**：鼠标就是那束光。照观众，他们从灰变彩、跟着你唱；照噪音，你把它烧穿；照自己，你独奏。**你看谁，噪音就追谁。** 一局 9–12 分钟，唱完终曲，把光放下。

**为什么它是"乐趣/循环"那一案**：三案里只有它是**正反馈**——养人 → 招灾 → 化解 → 人更多 → 更危险；每分钟都在滚雪球，而且雪球有一个自己长出来的刹车（天花板裂缝）。另外两案一个没有成长（A）、一个成长向下（B），只有 C 会让人"越打越上头"。

## 2. 核心体验与循环

**体验一句话**：你不是在杀怪，你是在把一屋子还没决定喜不喜欢你的人，一盏一盏点亮。

```
照亮一区观众 ─→ 人亮、跟唱、人气↑（火力/护盾↑）
      ↑                        │
      │                        ▼
  人更多、天花板裂缝 ↑ ←─ 人浪（每 90 秒，观众自己撞进噪音）
      ▲                        │
      │                        ▼
  唱化：噪音减速、变色、坐下 ←─ 噪音循光涌来、覆盖观众
      │
      └── 光移开去救另一区 / 收束烧穿 / 照自己独奏
```

- **秒级循环（0.5–2 秒）**：光移到哪、散还是束、要不要把光收回脚下。
- **十秒级循环**：一区点亮 → 该区跟唱 → 噪音往这边聚 → 要么烧、要么让它唱化。
- **分钟级循环（90 秒）**：观众到阈值 → 人浪 → 一片噪音被唱成人 → 天花板裂开一道缝 → 噪音更多。

**这一案是正反馈 + 刹车**：人气越高，火力越强，但裂缝越多、噪音越多；停在一个区不动，人会冷却走掉。**推着你走的不是难度表，是你自己养出来的场子。**

## 3. 那个"哇"的瞬间：2:00 的人浪

**第 2 分钟**，你被噪音逼到舞台前沿，再退一步就是台下。你没有回头，把光整个甩向观众席正中央。

**0.00s**：一整片人站起来了。人浪从最后一排卷起来——真的像浪，一排推一排，从前排的缝隙里涌上来，越过舞台边沿，撞进噪音堆里。
**0.30s**：你以为会有一场爆炸。没有。人浪撞上去的那一刻，噪音停住了。
**0.80s**：它们开始跟着那个节奏点头，然后——**它们开始唱**。它们变成了人：边缘的黑色噪点褪掉，由灰变彩（0.8 秒），转过身，在第二排坐下，举起荧光棒，看着你。
**1.50s**：HUD 上观众数从 187 跳到 307。你多了一百二十个观众。
**1.60s**：天花板又裂开一道缝。**你变强了，麻烦也变强了。**

情绪落点：**"他们是因为我才被追的。"** 先是"我在被需要"，三秒后是"我在害他们"。

### 它如何在这一案里被保留

1. **人浪不是技能，是奖励**：观众到阈值自动发生，玩家只需要维持热度——所以它每次都比上一次大。
2. **0.8 秒变色是统一语言**：转化、唱化、安可回归全部用它；玩家一眼就能读出"这是自己人"。
3. **声音必须真的变厚**：每 8 个观众共享一个合成声部 + detune + 声像 + 房间混响；如果听起来只是"音量变大"，这一案的情绪核心就没了。
4. **它不是唯一的高潮**：终曲还有"放下光"，全案至少两个能被复述的时刻。

### 它如何避开"黑场→观众接住你"

这一案的高潮是**你在把人变成自己人**（人浪／唱化），不是观众在黑暗里把你捞出来。终曲的"放下光"确实是"把控制权交出去"，但它是**有代价、可失败**的：观众不够就是空场，你一个人把剩下的段落弹完。全案没有"停电 → 观众唱完最后一句"。

## 4. 关键机制

| # | 机制 | 规则 | 数值锚点（估计） |
| --- | --- | --- | --- |
| 1 | **光** | 鼠标跟随，0.15 秒惯性、有拉丝；散＝宽、转化慢、读场；按住左键＝束，窄、亮、转化快、能烧穿噪音 | 光锥 30°（束 12°） |
| 2 | **转化分两段到账** | 0.4 秒先"拉停"（人停住、转身）；1.5 秒才"入座"（举棒、加入）；中途移开保留 50% 进度 | 解决"密度不允许停 1.5 秒" |
| 3 | **热度 0–3** | 路人／抬头／举棒／合唱；离开光 3 秒开始**褪色倒计时**，12 秒掉一级；屏幕边缘四个色点，谁在等你谁闪；被噪音覆盖 −1 且荧光棒熄灭 | 合唱＝火力与安可的来源 |
| 4 | **人气＝血量** | 观众总数就是血量，不显示数字：白光从四边吃掉颜色；0＝演出中断 | 安可第 1 次 −15%，第 2 次需求 ×1.8，第 3 次 −45% |
| 5 | **四声部＝四个座区** | 前左／前右／后左／后右分别唱根／三／五／七；照亮哪区哪区响；四区各 ≥40 人→合唱墙（输出与护盾 ×1.5，全场变色） | 观众会替你补你唱不到的音 |
| 6 | **三根乐器线（身体那一半）** | 鼓＝热度衰减、贝斯＝低频护盾／减速、吉他＝高频穿刺；噪音会拽线；`E` 插线 1.2 秒，此时不能移动，但光还能动 | 让"看"和"跑"同时存在 |
| 7 | **烧 vs 唱化** | 烧：快、不可逆、清路；唱化：慢、把噪音变成新观众、但在和声场里才生效 | 一个快一个慢，两种解法 |
| 8 | **人浪** | 每 90 秒或观众到阈值自动触发：一片人撞进噪音，把整片唱化 | 全案的正反馈时刻 |
| 9 | **静默段（6:30）** | Boss 抽走音频总线 8 小节：全黑、只剩视觉节拍与波形；每撑过一小节，前排亮一排 | 失败不是死，是"被按了静音" |
| 10 | **终曲：放下光** | 长按 `Space`：镜头 180°，光从你手上交出去；人够＝观众的光照回台上；不够＝空场，你一个人弹完 | 唯一按键；可失败 |

**可读性预算（继承《杂音》，写入 M4 验收）**：
- 全场只有三种颜色：灰（还没决定）／彩（自己人）／黑（噪音）。出现第四种高饱和色＝ bug。
- **一拍之内只允许一个可读事件**；屏幕任何时候只要求你看一个地方（"目光—危险条"：左＝被照亮的人数，右＝循光噪音量，中间是安全阈）。
- 关掉声音也能玩：噪音方向、热度、插线状态都有同帧视觉等价物。

## 5. 预计内容规模（估计，M3/M4 锁定）

| 项 | 数量 | 为什么是这个数 |
| --- | ---: | --- |
| 角色 | **4**（1 可动主唱 + 3 位台上队友＝3 条系统） | 三条线是"走位要照顾什么"的最小集合；每条线一个系统（被听见／被记住／一起动），多一条就变成管四个闹钟 |
| 武器／升级 | **0 把武器；4 个声部 + 8 张升级卡**（光形 3／热度 2／和声 2／安可 1，各 1 级） | 一局 9–12 分钟约 8 次升级，正好走完一轮；重玩靠顺序、座区分布、养法，不靠卡池深度 |
| 敌人 | **4 类噪音 + 1 Boss**（底噪／啸叫／失真／静默） | 每一类对应一种"光"的应对：贴地要扫、直线要躲、吞光要收束、静默只能盲奏 |
| Boss | **「静默」**（3 阶段：抽总线／吞光／让观众冷却） | 它不攻击，只让"看"失效；三阶段分别拿走声音、视野、人 |

| 曲目 | **1 首 9–12 分钟的歌**（五段，BPM 随段落小幅变化） | "难度曲线就是歌的曲线"；不需要另做一套数值表 |
| 单局时长 | **9–12 分钟** | 需要 90 秒序曲让玩家主动发现光、2:00 第一次人浪、6:30 静默、8:30 终曲；短了装不下"养—招灾—放手" |

## 6. 一局如何成立

| 时间 | 玩家 | 系统 |
| --- | --- | --- |
| 0:00–1:20 序曲 | 黑场，一个人，学会走和看；台下 30 个人，暗着 | 只有底噪，没有噪音。第 40 秒，最后一排亮起一根荧光棒 |
| 1:20–4:00 主歌 | 第一次点亮一整片人；第一次被追；第一次看到"看哪里"能救命 | 观众增长，噪音出现，BPM 上升 |
| 2:00 人浪 | 第一次人浪 | 观众到阈值，噪音被唱化成观众，天花板裂第一道缝 |
| 4:00–6:30 副歌 | 第一次真正的人浪、第一次唱化 | 观众破阈值，和声场生效，噪音大规模涌入 |
| 6:30–8:30 桥段 | **声音没了**：全黑、只剩视觉节拍与波形，你必须盲奏 | Boss「静默」登场；总线增益 0，视觉补偿拉满；每撑一小节前排亮一排 |
| 8:30–终曲 | 全场站起来；唯一按键：放下光 | 人够＝观众的光照回台上；不够＝空场，你一个人弹完 |
| 结算 | 不是击杀数，是空位："你今天点亮了 743 个人。第二排，有 12 个空位。" | 观众记得的是你重复过的句子 |

**失败形状**：演出中断（人气归零，观众喊安可把你拉回来，但安可消耗人）／空场（没有安可，游戏不结束，你一个人弹完，黑屏一行字「今天，只有你听见了」）。

## 7. MVP 与明确砍掉项

**MVP**：一束光、两排观众、一根荧光棒、三种噪音、一次人浪、一个空场结局。**如果只能保一件事：光照到人 → 他亮 → 他唱你的音。**

- 六弦、踩弦、向下成长（留给 B）；
- 曲库、setlist、房间记忆、静默场长线（《第一排》的长线层）；
- 评论区、应援牌、观众起名（P2 不做，避免 UGC 与真实平台影射）；

## 8. 最大风险

**风险 1（最高）：没有攻击键 = 被动。**
玩家只做"走 + 看"，可能前 3 分钟就判定"这游戏不用我操作"。
**对策**：左键收束＋烧是主动输出；三根线要求你跑动插线；噪音只从光的方向来，所以"看哪里"直接决定危险从哪来。**验收**：第一次人浪之后，玩家能说出"是我把它养出来的"。

**风险 2：认知负荷。**
读场（哪片热／哪片冷）＋读光＋读噪音＋读线，一秒四件事。
**对策**：一拍一事件；三种颜色；大色块；序曲 90 秒无噪音；热度用"亮度＋动作幅度"双编码。

**风险 3：因果链不可见（看 → 招灾）。**
玩家可能只感到"莫名越来越难"，而不是"我把灾难招来的"。
**对策**：噪音出现时**从光的方向**爬进来；光移走时，被照区立刻变暗半格；"目光—危险条"把因果压成一维可读数。

**风险 4：90 秒的"主动移光"门。**
必须让玩家**出于好奇**把光移向观众席——因为那片黑里有一根亮着的，而不是因为教程。
**验收**：无 UI 提示下，10 个新玩家里 ≥7 个在 90 秒内主动照向观众席。

**风险 5：静默段被当成 bug。**
**对策**：Boss 出场时音频电平表当场被"拉平"；全黑里保留波形、光点、呼吸式明暗；叙事预告一次。

## 9. 如何收敛成仅桌面 React + TypeScript + Three.js 的可玩版本

- **光**：一个 `SpotLight` 打亮 + 一个加法混合的半透明锥体做可见近似（不做体积光 shader）；光与观众的交集用座位网格**桶查询**（O(格子数)，不是 O(人数)）。
- **观众**：`InstancedMesh` 一次 draw call；热度写进 `Float32Array`，颜色与发光强度写进 `instanceColor`；人浪是一个定义在座位网格上的**波函数**（每帧更新起身高度），不是动画。
- **噪音**：对象池 + `InstancedMesh`，200–400 个；"唱化"是状态转移（减速 → 变色 → 转为观众实例），纯数据操作。
- **线**：三条 bezier 线 + 插线判定；断线＝材质变暗 + 音频少一轨。
- **音频**：WebAudio 五条总线（鼓／贝斯／吉他／人声／观众）；观众越多，混响越湿、合唱层越厚；合唱用 8–12 个固定声部池，由该组人数与站位驱动音量/声像（听起来上千人，算起来十几个节点）。静默段＝主总线 gain 0；空场＝三个参数。
- **状态与 UI**：单一 store；React 只做菜单／HUD／结算；HUD ≤10Hz；结算显示空位与点亮的真实数据。
- **确定性**：座位布局、噪音刷点、颜色分配用种子 RNG；同一局可复现。
- **性能**：1008 个观众实例 + 300 个噪音实例在 WebGL2 上毫无压力；无阴影、无后处理；白闪/黑场用 CSS；1280×720 起 60fps。
- **里程碑**：M4 锁"三种颜色 + 一拍一事件 + 90 秒门"三条验收；M5 先做"一束光 + 两排人 + 三种噪音"的垂直切片（不接 Boss）；M6 接静默与终曲；M7 单文件。
- **一旦音频不成立**：观众合唱降级为"8 声部池 + 混响"；再不行降为"人气越高，底鼓越厚 + 环境声越湿"，把"变厚"从人声换成空间感——仍然成立，但情绪会掉一档。

## 10. 为什么必须是少女乐队

因为"被看见"是这个题材唯一的内核：一支地下乐队的全部焦虑是"有没有人在看"，全部恐惧是"没有人来"。因为台上台下天然是两张地图：台上一小块被灯打亮、危险、无处可躲；台下一片黑暗、坐着会动的人。因为只有乐队，才有"安可"——别的题材里死就是死，乐队里死是演出中断，观众会喊你回来。

## 11. 这一案留给评审的三个问题

1. "没有攻击键、只有走和看"能不能被接受？如果评审要求主动输出，左键"收束＋烧"够不够，还是必须再加一套攻击？
2. 一局 9–12 分钟里，观众从 30 涨到 800，这个数字是否可信、可读？如果不可读，应该压到 400 还是把镜头拉远？
3. 空场结局要不要做？它不加时长、不加平衡，只花 3 个参数和一行字，但可能是全项目最容易传播的 30 秒。
