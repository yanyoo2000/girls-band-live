## 2. 差异是真实的吗（三组两两对比）

### A vs B

- **共同点**：都靠"松开手"作为核心动作；都有几百人的观众；都没有传统血条。
- **关键差异**：A 的"松手"是**砸人潮**（时间轴上的准头），B 的"松手"是**把人弹回座位**（空间里的物理）；A 的歌是写死的、成长是零，B 的歌每局因调弦而变、成长是负。A 的观众是压力，B 的观众是想上台的人。
- **换皮判定：不是。** A 没有卡池、没有音域、没有断弦；B 没有谱面、没有砸、没有气口。把 A 的"砸"给 B，B 会变成另一个游戏（因为 B 的敌人是"想上台的人"，不是"压迫场子的人潮"）。

### A vs C

- **共同点**：都有"观众越多越强"的表层；都有"看／读"的压力。
- **关键差异**：A 的观众**不被转化**，只是压力与评分；C 的观众**就是弹药与血条**。A 的输入是"按住空格"，C 的输入是"移动鼠标的光"。A 的成长是零，C 的成长是雪球。A 的失败是冷场，C 的失败是中断/空场。
- **换皮判定：不是。** 把 A 的光照系统塞进去，A 的"空拍"就会被稀释成"看着玩的技能"；把 C 的按住空格塞进去，C 的"看"就不再稀缺。两案的动词互斥。

### B vs C

- **共同点**：都有"灰→彩"的变色；都有"一片人站起来"的画面；都在讲"被听见"。
- **关键差异**：B 的转化是**清场动作**，转完的人坐在台下、不参与输出，成长向下；C 的转化是**资源循环**，人越多输出越高，成长向上。B 的敌人完全无声，C 的敌人循光而来、会覆盖人。B 的终局是"你弹完最后一个音"，C 的终局是"你把光交出去"。
- **换皮判定：不是。** 变色是共享的"最便宜的一行动画"，两案用它表达相反的事：B 是"我把你弹回去了"，C 是"你加入我了"。

**结论**：三案可以同时进 M3 而不互相稀释。最接近的是 B/C 的视觉语言（变色），但动词、成长方向、失败形状全不同。

## 3. 对 M1 门禁五问的回答

### 问题 1：「黑场→观众接住你」是必留，还是必须打破？

**答：拆成三种语法，一局只准用一种；全项目只准一案"把控制权交出去"。**

| 案 | 静音的语法 | 谁付代价 | 观众做了什么 |
| --- | --- | --- | --- |
| A | **空拍是你的武器**（主动、可重复） | 你：气口、台唇、体力 | 被砸、被推、被留下或离场 |
| B | **敌人无声**（世界设定）；断弦后观众替你打拍子 | 你：音域 | 打拍子（节拍器），不救你 |
| C | **静默是惩罚**（Boss 抽走总线）；终曲你把光交出去 | 你：人气、控制权 | 够人就照亮你；不够就是空场 |

- "把控制权交出去"只在 C 的终曲出现一次，且**可失败**（空场）。
- 三条高潮都写清了"谁付、付什么、失去什么"；没有一条是"观众在黑暗里替你唱完，你退成观众"。
- A 的"售罄"断电段是唯一一次"静音反过来打你"，但它是同一个语法（空拍）被 Boss 夺走，不是新机制。

### 问题 2：冠军的主动词是哪一个？

**答：三案各自一个，互不替代——A 停/砸、B 踩/放、C 看/唱。** 另外七个动词的去处：

| 动词 | 原案 | 去向 |
| --- | --- | --- |
| 听 | 不散场 | 未进三案（关系叙事与单机短局冲突；只把"缺声"借给 B） |
| 蓄 | 啸叫 | 拆成 A 的"张力"（按住即蓄）与 B 的"弦的厚度" |
| 照 | 别关灯 | 未进三案（A 簇淘汰，见 §4） |
| 站 | 请全体起立 | 只把"四色声部"的思想借给 C 的座区；C 由光照亮哪区决定声部，不由玩家站位 |
| 递 | 第一排 | 变成 C 的终曲"放下光" |
| 留 | 回声四重奏 | 未进三案（音频调度风险最高） |
| 起拍 | 杂音 | 未进三案（BPM 锁定不可逆） |

### 问题 3：观众到底是什么？

| 案 | 主定义 | 副定义 | 技术上怎么建 |
| --- | --- | --- | --- |
| A | 压力与燃料（一个液体模型） | 评分对象 | 一个 `InstancedMesh` + 四个标量（总量/压力/前沿/热度） |
| B | 想上台的人（被弹回＝坐下） | 节拍器（断弦时） | 冲台人群 + 静态观众席两套实例，灰→彩 |
| C | 弹药与血条（人气） | 记忆（结算文本/空场） | 座位网格 + 热度数组 + 合唱声部池 |

**没有一案同时把观众当"血条 + 乐器 + 存档 + 道德对象"。** 每案一个主定义、一个副定义，这是 M1 报告要求的收敛。

### 问题 4：音频生死线怎么前置？

- **M3 之前必须做一次 60 秒垂直切片**（不是战斗原型）：五轨可增减、每轨可独奏、能听出"少一轨"、能让人隔天哼出来、静音也能玩。
- **三案各自的降级路线**：
  - A：主曲降级为"底鼓 + 节拍器 + 视觉等价物"，游戏仍成立（这也是 A 最稳的原因）。
  - B：Karplus-Strong → 2-op FM + 琴体 EQ → 预渲染的 6 个音色缓冲区（仍零外部素材）；如果三种都"像玩具"，B 应出局，而不是降级。
  - C：24 声部合唱池 → 8 声部池 + 混响 → "人气越高，底鼓越厚 + 环境越湿"（情绪掉一档，但游戏成立）。
- **通过线（建议）**：10 人盲听；能指出"少了一轨"；24 小时后还能哼出 ≥3 个音；关掉声音能玩一局；四条过三条 = 通过。
- **未通过时**：换实现、换冠军、或换概念——由制作人在 M3 门禁决定，而不是由文案说服力决定。

### 问题 5：一局的终点与失败形状？

| 案 | 终点 | 失败 | 重开理由 |
| --- | --- | --- | --- |
| A | 唱完 6:30；三秒安静后有人喊安可 | 冷场（气口归零） | 评级、准头、少砸通关 |
| B | 拨完最后一个音；500 人一声"啊" | 弦尽 | 换一组调弦、换找回顺序 |
| C | 终曲放下光；满场或空场 | 演出中断（安可耗人）／空场 | 换养法、换座区、追空场 |

三案都有 30 秒内可演示的"结束"与"重开理由"，M3 打分员不需要靠想象。

## 4. A 簇处理：《看向我》进 C，《别关灯》不进

M1 报告要求 M2 必须二选一或明确分工。**选择：《看向我》作为 C 的光；《别关灯》的"灯＝谁在演奏"不进三案。**

- **理由**：两案都是"一束光分配注意力"，同时进 M3 会互相稀释；《别关灯》的灯有四个去向（自己/吉他/贝斯/鼓）+ 观众饿/抢/走 + 歌单拖拽 + 90 秒黑场，一秒五件事，过不了"一拍一事件"这条可读性预算。C 的光只有三个去向（台下/噪音/自己）+ 两段到账，能过。
- **《别关灯》保留下来的东西**：①"升级＝给一小节音乐"进入 A 的编曲层（与《静场》的选择合并）；②"暗处会掉拍"变成 C 的"热度自衰减"（但不带队友灯）；③"终曲由玩家主动按下"变成 C 的"放下光"。
- **代价**：失去"灯给队友"的那层乐队关系。补偿是 C 的"三根乐器线"——**身体照顾队友，光照顾观众**；照顾不过来本身就是这层关系的玩法。
- **《看向我》被砍掉的部分**：评论区、应援牌、观众起名（UGC 与真实平台影射风险，P2 不做）；"照队友连携"（那是《别关灯》的灯，作者本人也已在互评中让出）。

## 5. 三案与 7 人工程团队

| | 最大工程量 | 最大技术风险 | 最早该做的原型 | 原型失败怎么办 |
| --- | --- | --- | --- | --- |
| A | 手感（8 帧）与 16 步表的调参 | 判定必须跟 AudioContext 时钟 | 一主唱 + 一空场 + 3 次砸（2 周） | 手感不成立 → 砍案；音频不成立 → 节拍器 |
| B | 弦的几何形变 + 程序化吉他 | 物理建模音色与构图可读 | 30 秒闭眼听 + 踩放手感（2 周） | 音色"像玩具" → 换实现；仍不行 → 砍案 |
| C | 光/座位/合唱的音频调度 | 90 秒门与因果可见性 | 一束光 + 两排人 + 三种噪音（2 周） | 90 秒门不过 → 砍案或加提示（不降概念） |

- **模块分配（估计，不是排期）**：三案都由"引擎/循环、Three 场景、战斗或人潮、成长或编曲、内容数据、UI、音频"七个模块构成；A 的成长模块最轻（4 次编曲），B 的成长模块并进战斗（无卡池），C 的成长模块最重（8 卡 + 声部）。
- **单文件与性能**：三案都能落在 2MB 目标内（零外部素材，全部程序化）；真正吃性能的是 A 的 1000 人潮 + 16 灯、B 的六根可变弦、C 的 1000 座 + 300 噪音——都在技术方案可评估范围内。

## 7. 自评：我会押哪一案

- **如果只问"我最想让它存在"**：B。它是十案里最不可替换的一个，"舞台是乐器、成长向下、敌人无声"这三件事换任何题材都会塌。
- **如果只问"7 个人能不能做完并且不丢人"**：A。它的风险几乎全在一处（手感），而且音频可以降级；这是最不会在 M6 崩掉的方案。
- **如果只问"哪一案最可能让玩家第二天还想再来一局"**：C。它是三案里唯一的正反馈；"养人—招灾—放手"这个循环自带重开欲望，而且它的名场面最便宜（人浪、空场）。

**我的实际倾向（作为创意总监，不是打分）**：先看 M3 前的 60 秒音频切片。
- 切片通过 → 我倾向 **B**（原创性与主题表达最强，且切片通过意味着它最大的死因被排除）。
- 切片失败但 A 的"节拍器降级"成立 → 我倾向 **A**（至少交付一个完整、独特、不丢人的游戏）。
- 切片通过、但玩法评审最看重"停不下来" → **C**。

**三案各自的死法（一句话）**：
- A 死于"那两秒真的只是罚站"；
- B 死于"弦摸起来像塑料绳、吉他听起来像玩具"；
- C 死于"玩家看了三分钟，不知道自己该干什么"。

## 8. 给评审与打分员的提醒

1. **不要用"黑场/静默"的数量判断原创性。** 三案的静音语法不同：A 是武器、B 是世界设定、C 是惩罚；只有 C 的终曲把控制权交出去，且可失败。
2. **不要把"没有攻击键"直接判死。** 先看 C 的 90 秒门：无 UI 提示下，玩家会不会因为"那片黑里有一根亮着的"而主动移光。会，就成立；不会，就砍。
3. **不要用"能不能做完"直接给 B 判死。** 先要它的两个 30 秒切片（踩—放手感 / 闭眼听的音色）；两个都过，再谈范围。
4. **不要用"像不像幸存者"当唯一尺。** A 是街机契约（固定谱面、评级、重开），B 是反幸存者（向下成长、无卡池），C 才是标准幸存者结构（雪球）。三案故意站在类型光谱的不同位置。
5. 请先回答三个问题，再看细节：**观众的主定义选哪个？一局时长下限是 5 分钟还是 8 分钟？60 秒音频切片通过线由谁签字？** 这三个答案会直接改变三案的排序。
