# Hybrid B ·《松手》/ LET GO

> **候选概念 B：主题 / 原创优先**
> M2 v2 融合稿，不是 GDD。所有数量都是收敛估计，M3 定案、M4 锁定。
> 骨架：《满弦》｜借层：《不散场》《杂音》《啸叫》｜工作名，M3 后统一改名并查重。

## 0. 一句话与 30 秒规则

**一句话**：凌晨四点半，散场后的 Livehouse 只剩你一个人和一把走音的六弦巨琴——冲上台的人从四面八方涌来，你唯一的暴力是**弹**：把台下的椅子坐满，把台上的人找回来。

**30 秒规则**：站到弦边按住 `Shift`，人会被凹下去的弦吸上来；松开，人被甩回半空、由灰变彩、走到台下坐下。你唯一的攻击方式就是"什么时候松手"。左键拨弦清一条路，`R` 调音，`Space` 扫弦（六弦全亮时）。

**为什么它是"主题/原创"那一案**：这一案不是"把乐器当枪"，是把**舞台本身变成乐器**：走位就是弹奏，成长曲线向下，敌人完全无声，全游戏只有一个声源。它把"四个人才是一首歌"写成一条能被手感觉到的规则，而不是一句设定。

## 2. 核心体验与循环

**体验一句话**：你不是在杀他们，你是在让他们听见——然后坐下。

```
走位到弦边 ─→ 按住踩弦（人吸上来、弦变厚、你不能动）
     ↑                              │
     │                              ▼
 下一波更挤 ←─ 台下坐满 ←─ 松手（甩回半空、灰变彩、坐下）
                              │
                    弦被咬 / 断 ─→ 音域消失 ─→ 找队友 / 调音
```

- **秒级循环（1–2 秒）**：踩多深、吸几个人、什么时候松；松早了人没卡住，松晚了弦被咬断。
- **十秒级循环（8–16 拍）**：一根弦的厚度＝你现在的强度；人越多音越脏，你越听得见自己攒了多少。
- **分钟级循环（找回一个人）**：人群里认出一个灰白的人 → 在她身边反复踩弦 → 第八次弦响，她恢复颜色、走上台、点亮一根弦、音乐多一个声部。

**这一案是负成长**：六音 → 五音 → 三音 → 一音。你越打越穷，穷到你听得清自己还剩什么。

## 3. 那个"哇"的瞬间：2:40 的松弦回色

> 这一段请用耳朵读。它是这一案存在的理由。

**0.00s**：你松开 `Shift`。**全屏静音**——不是变小，是抽走。只剩一声极轻的心跳（一个闷在胸腔里的底鼓）。
**0.15s**：弦抽回来。"嘣"的不是一个音，是**三十一个音在同一瞬间一起松开**。一堵由三十一个身体组成的和声，正面拍在你脸上。镜头震 12 度，画面裂出红蓝色差。
**0.30s**：三十一个人被这根弦抛到半空。在半空中，**他们身上的颜色回来了**——从灰白，一个一个变成彩色，像有人挨个把他们拧亮。他们的嘴闭上了。
**1.10s**：他们落地。没有尸体。他们转过身，走向台下，找到位置，坐下，开始鼓掌。
**1.20s**：你抬起头，才第一次往台下看——那里已经坐了四百个人，而且开始有人喊你的名字。

情绪落点：**"原来我不是在杀他们。我是在让他们听见。"**

### 它如何在这一案里被保留

1. **五件事必须同帧**（形状、音色、白闪与震屏、低频共振、半空变色），少一件这根弦就只是"一根会动的线"。
2. **变色窗口不能短于 0.5 秒**（目标 0.8 秒）——这是情绪的窗口，不是特效参数。
3. **它是每局第一个"哇"，不是全案唯一的"哇"**：第一次约在 2:40，教会玩家"我是在请人入座"；全案最后的高潮是六弦齐鸣 + 500 人一声"啊"，两者不重复使用同一个把戏。
4. **成本极低**：`instanceColor` 从灰到彩的 0.8 秒插值，是全案最便宜也最值钱的一行代码。

### 它如何避开"黑场→观众接住你"

这一案唯一一次"观众替你做事"是**断弦之后替你打拍子**——那是节拍器，不是救援：你仍然要自己走位、调音、重新布防。终局的 500 人一声"啊"是**你弹完之后**的声音，不是把你从失败里捞出来的合唱。全案没有"停电 → 观众唱完最后一句"。

## 4. 关键机制

| # | 机制 | 规则 | 数值锚点（估计） |
| --- | --- | --- | --- |
| 1 | **踩（Hold）** | 站弦边按住 `Shift`：弦凹成 V，成为漏斗，人潮被吸上来卡住；凹陷越深音越高，人越多音越厚。**你不能动，但 V 会沿弦缓慢滑动**——你得追着它走；人潮也能从两根弦之间钻过去。 | 0.2 秒进入持弦；单弦上限 40 人；V 每秒滑 0.4m |
| 2 | **放（Release）** | 松手：弦回弹，把人沿弦的法线抛出去；半空变彩；落地坐下。**这是全部暴力。** | 3 秒内结算完；1 帧白闪 + 12° 震屏 |
| 3 | **拨（Pluck）** | 左键朝一个方向划：一道波沿弦跑出去，掀翻沿途的人，只清一条路，不清场 | 冷却 2 拍；距离远、伤害低 |
| 4 | **调（Tune）** | 按住 `R` 0.8 秒把走音的弦拧回去；这 0.8 秒你手离开地面，什么都做不了——敌人就等这 0.8 秒 | 张力恢复 40%；被打断则 −20% |
| 5 | **六弦四人** | 开局三根低音弦；找回一人点亮一根；六弦全亮才可 `Space` 扫弦 | 3 + 3 = 6 |
| 6 | **断弦** | 张力归零就断，不会自己回来；断弦瘫在地上变地形（绊脚／挡线）；**只有回到台上的人能替你装回去** | 每局预计断 1–3 根 |
| 7 | **你本人没有血条** | 敌人碰到你，掐断离你最近的那根弦。生命＝你还能发出多少种声音 | 六弦全断＝散场 |
| 8 | **每局调弦不同** | 这把琴被改过、被雨淋过：每局从 4 组"错调弦"里抽一组（音程关系不同）→ 同样的手法给出不同的和弦与连段 | 4 组 × 种子偏移＝重玩空间 |
| 9 | **失败＝散场** | 最后一根弦断：没有死亡画面，只有一行字「今晚，到这里。」三秒后第一排喊"再来一首" | 菜单只有一个按钮：[再来] |

**两条兜底**（回应 M2 对"向下成长会雪崩"的批评）：
- **第一根断弦脚本化、可救**：2:40 之后的第一根断弦必定发生在"你刚学会松手"之后，且队友离得最近，装弦只需 1.5 秒——让玩家先学会"失去可以被修回来"。
- **最后一根弦给独奏高光**：只剩一根时进入"独奏"——全场静音，只有这根弦；每一次拨弦都命中，音准由你按拍决定。穷不是罚站，是孤注一掷。

## 5. 预计内容规模（估计，M3/M4 锁定）

| 项 | 数量 | 为什么是这个数 |
| --- | ---: | --- |
| 角色 | **4**（你 + 3 位待找回的队友） | 六弦＝四个人；每找回一人点亮一根弦并带来一个声部；少一个，"四个人才是一首歌"就不成立 |
| 武器／卡池 | **0**（无升级菜单、无卡池、无掉落） | 成长只发生在台上；卡池会把"实时选择"变回"暂停三选一" |
| 弦 | **6 根**（＝6 个音域／6 种手段，不是 6 把武器） | 六根弦是"一把完整的琴"的物理事实；弦数多了手管不过来，少了撑不住向下曲线 |
| 动作 | **4 个**（踩／放／拨／调） | 每个动作对应一种"手在乐器上的姿势"；再多就变成搓招 |
| 敌人 | **3 种行为 + 1 Boss**（撞弦／爬台／咬弦；Boss「回授」3 阶段） | 三类人只有一个差别：他们对弦做什么。Boss 是场馆自己的声音，三阶段分别堵弦、拔品、断你最后一根 |
| 关卡 | **1 座场馆**（吉他＝地图，音孔＝Boss 出口）+ 3 段（空场／找回／坐满） | 所有张力在"台上三米"；换场景不加玩法 |
| 曲目 | **1 首骨架**，每局由调弦生成变体 | 不是多首歌，是同一首歌在不同调弦下长出的不同形状 |
| 单局时长 | **10–12 分钟** | 8 个剧情节点（2:40 第一次大松手 → 4:00 找回鼓手 → 6:30 断弦 → 8:30 六弦全亮 → 11:00 一声"啊"）各需要呼吸空间；短于 9 分钟装不下"向下" |

## 6. 一局如何成立

| 时间 | 台上 | 台下 | 玩家在想什么 |
| --- | --- | --- | --- |
| 0:00 | 一个人，三根低音弦 | 空的，灯没开 | "我为什么要踩这根弦" |
| 1:00 | 学会踩—放 | 第一排坐了几个人 | 第一次松手被震了一下 |
| 2:40 | 第一次攒到 20 人以上 | 四百个人 | **"原来我是在让他们听见"** |
| 4:00 | 鼓手回来，第一声鼓 | 台下开始跟着晃 | "前面三分多钟原来一直没有鼓" |
| 6:30 | 第四根弦断了，变成地上的一道坎 | 有人开始替你打拍子 | "我还能撑" |
| 8:30 | 三位队友都回来了，还替你把断掉的弦装上 | 坐满了 | "还差最后一次" |
| 8:30 | **六弦全亮，第一次按 `Space`** | 全场站起来 | 手在抖 |
| 9:30 | 最后一根弦断掉，进入独奏 | 全场安静，只有你 | "只剩这一根了" |
| 10:40 | 你拨完最后一个音 | 五百个人一起"啊" | 事后再也忘不掉的十秒 |
| 10:50 | 「今晚，到这里。」 | 灯灭 | 立刻点"再来" |

**失败形状**：弦尽。没有死亡画面，只有一行字和第一排的一声"再来一首"。失败不是被打败，是**你已经没有声音了**。

## 7. MVP 与明确砍掉项

**MVP**：一个舞台、三根弦、一位队友、一种敌人、一个从音孔里爬出来的 Boss（一阶段）、一首"全场一起啊"的结尾。**如果只能保一件事：踩—放与松弦回色。**

**P0**：4 角色、6 弦、4 动作、3 敌人行为、Boss 三阶段、断弦地形、装弦、每局调弦、独奏段、结算与重开、暂停/设置、`gbl.save.v1` 只存设置与最佳。

**明确砍掉**：
- 升级菜单、卡池、进化、数值成长（这是这一案最想守的骨头）；
- 观众记忆、曲库、setlist、房间长线（《第一排》的长线层）；
- 一束光、递麦、观众替你唱完（留给 C）；
- 多场馆、多首歌、角色换装、结算导出曲子（P1 再谈）；
- 敌人的攻击数值（它们只做一件事：弄断你的弦）。

## 8. 最大风险

**风险 1（最高）：手感。**
"踩下去—抽回来"必须是物理的。如果弦凹下去没有重量、回弹没有爆发，整个游戏就像在拖一根塑料绳。
**验收**：五件事同帧；闭眼能听出"卡了多少人"；30 秒内玩家能说出"这是把吉他"。

**风险 2：声音的质感。**
全游戏只有一把程序合成的吉他。如果它听起来像电子琴、像 8-bit、像玩具，庄严感瞬间消失。
**验收**：物理建模（Karplus-Strong／延迟线波导）而不是振荡器；六根弦必须听起来像六根不同的弦；先做 30 秒闭眼听的 loop，不通过就换实现，不换概念。

**风险 3：构图与可读性。**
俯视一把巨吉他很容易被误读成"一块木板"。
**验收**：音孔是纯黑的一个洞、品丝有金属反光、六根弦有粗细与光泽；30 秒内说不出"这是把吉他"就重做构图。

**风险 4：没有升级菜单 + 向下成长，可能被判"不是幸存者／没有 build"。**
**对策**：重玩性放在"每局调弦不同 + 找回顺序不同 + 断弦位置不同"；深度放在"实时选择"（踩多深、救谁、先装哪根弦）。M3 若认为深度不够，先加"调弦家族"而不是加卡池。

**风险 5：范围。**
六弦 × 四位队友 × 三种敌人 × 一个 Boss 不小。**兜底**：P0 砍到三弦、一位队友、一种敌人、Boss 一阶段，机制依然完整（《满弦》原案已给出这条兜底线）。

## 9. 如何收敛成仅桌面 React + TypeScript + Three.js 的可玩版本

- **弦**：自定义 `BufferGeometry` 管状体，顶点每帧按"玩家位置 + 张力 + 最近撞击"做局部凹陷；不需要物理引擎。六根弦撑起全部战斗。
- **人潮**：`InstancedMesh` 一批几百个（600–900）；坐下的人切到另一个静态"观众席" InstancedMesh，只保留位置与颜色——所以能"坐满"而几乎不耗性能。
- **变色**：`instanceColor` 灰→彩 0.8 秒插值；白闪用全屏 overlay；震屏用相机偏移；色差用 CSS/后处理二选一（MVP 用 CSS）。
- **音频**：WebAudio 手写六弦 Karplus-Strong + 一个完全由玩家事件驱动的鼓机；无音频文件。若 KS 成本过高，降级为"2-op FM + 低通 + 琴体 EQ"；再不行降为"预渲染的 6 个音色缓冲区"（仍然零外部素材）。
- **状态与 UI**：单一 store；React 只做菜单／HUD（弦的张力用 6 条细竖条 + 断弦留空）；HUD ≤10Hz。
- **确定性**：调弦、人群站位、断弦判定用种子 RNG；同一局可复现。
- **性能**：低多边形、无阴影、无体积光；1280×720 起 60fps；低画质降 DPR、减人数。
- **里程碑**：M4 锁"手感五件事 + 构图 + 音频"三条验收；M5 先做"三弦 + 一队友 + 一种敌人"的垂直切片（不接 UI）；M6 接 Boss 与终局；M7 单文件。
- **最早的死法**：第一个原型不是战斗，是"踩—放"的手感切片 + 30 秒闭眼听。两个都过，才允许做第二个队友。

## 10. 为什么必须是少女乐队

因为"一个人只有半把琴，四个人才是一首歌"是乐队的物理事实；因为"找回来的人露出颜色"是"她一开口，整个团才成立"的瞬间；因为"你们弹的和弦全错的，全世界只有这四个人会弹"是这类题材最核心的那句话——**不标准，但是我们的**。换成骑士或太空题材，以上每一条都要重新找理由，这里一条都不用找。

## 11. 这一案留给评审的三个问题

1. "没有升级菜单 + 成长向下"是否还能被算作幸存者？如果不能，你更愿意加"调弦家族"还是加"最小卡池"？
2. 手感（踩—放五件事同帧）与音色（Karplus-Strong）哪个应该先做垂直切片？如果只能保一个，保哪个？
3. 10–12 分钟里，"六弦全亮"在 8:30 是否足够早？如果评委认为满配期仍然太短，应该把终点提前还是把找回节奏压紧？
